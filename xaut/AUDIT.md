## 本校与模板不同的地方（分析）

1. 上游只 GET 课表页。学期下拉框 `select#xnxq01id` 和课表 `#timetable` 都在这一页。不请求教学周历，也不为了换学期再 POST。
2. 节次时间不写死。行首同时有「(01,02小节)」和起止时刻时收成一节大节；时刻正好是 12:10-14:00 的整行跳过（`axisOf`）。周次串里的 `[01-02节]` 先读出小节号，再映射成大节（`mapBig`）。没有方括号时用这一行的大节。
3. 周次是文字。上游 `parseWeeks()` 只按逗号切数字，单双会丢。无逗号前置 `(单)1-8周(双)9-16周` 必须是 1-8 单周、9-16 双周；后置 `1-8周(单),10-16周(双)` 与无逗号后置 `1-8周(单)9-16周(双)` 也要各跟各的。「共 N 周」只剥备注，「第1-第8周」按一段。
4. 没有周历时，开学日按提取日推到最近的周一，总周数按 20，两条都提醒。上游不给这两个数。
5. 上游弹窗选学期，非默认项再 POST `xnxq01id`。改为只读选中项。
6. 登录页、站点根路径、认证页、门户页不发请求。
7. 教师「未知」、教室「待定」留空，并按类型汇总。

### 节次时间

不内置时刻表。冒烟用的四节（08:00-09:40、10:00-11:40、14:10-15:50、16:00-17:40）只是合成数据，不是学校公布的真实作息。真页面以行首读到的为准。读不到任何大节时，按「第 n 节为 7+n 点的 00 分到 45 分」补，并提醒。补到第 16 节是当天最后一档。

## 读了什么、交出去什么

读取面只有这些：

- 地址的协议、主机、路径（不要查询串）。
- `select` 里 id 或 name 含 `xnxq` 的选中项：学期代码与显示文字。
- 课表 `#timetable`（没有则 `#kbtable`，再退到最近一张含 `kbcontent` 的表）：每个格子的网格列号、跨列数、去掉 `item-box` 之后的可见文字、类名正好是 `kbcontent` 的 div 的原始 HTML（同样去掉 `item-box`）。不读 `kbcontent1`。

不读学号、姓名、身份证号、手机号、隐藏令牌。`item-box` 在副本上删掉再读文字，不改页面本身。

`extract.js` 交出去的字段：`source`、`pageUrl`、`now`、`term.code`、`term.name`、`screenTermMissing`、`cols`、`calendar`（固定空）、`rows`（格子只有 `col` / `span` / `text` / `parts`）。

`parse.js` 交出去的载荷：学期名、开学日、总周数、大节节次时间、课程的课名 / 教师 / 地点 / 星期 / 节次 / 周次段。教师、地点没有就是空，不写「未知」或「待定」。

## 上游里删掉或改掉的

| 上游 | 本件 | 理由 |
|---|---|---|
| `showSingleSelection` / `prompt` 选学期，非默认项 POST `xnxq01id` | 只读选中项，不 POST | 移植约定不弹窗问学年学期 |
| `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / toast / `notifyTaskCompletion` | 删除 | 空课自己组载荷，脚本只读 |
| `parseWeeks` 只认逗号和数字区间 | `weeksIn` 按段判断单双 | 否则单双周变成每周都上 |
| 教师默认「未知」、教室默认「待定」 | 空值，并按课汇总提醒 | 这两个词会被当成真名 |
| 没有时间信息的块直接丢掉 | 计数并点名 | 不能静默丢课 |
| 按大节去重的 `Set` | 安排完全相同才去掉 | 同一节的重复行不会叠成两门；不按课名排序合并 |
| 在页面上 `createElement` 再解析一块 HTML | 把原始 HTML 交给 `parse.js` | 取数只搬运，解释放在纯函数里 |

## 已知风险

- 没有本校账号，真页面没验过。行首若没有「(数字小节)」加时刻，节次时间会变成临时补的，并提醒到学期管理核对。
- 上游不提供开学日和总周数。按提取当天推最近的周一、总周数按 20，都可能和学校实际学期不一致，只靠提醒说明。
- 方括号里的小节号在大节表里对不上时，这门课会跳过并点名，不会猜一个节次。
- 占位节次从第 1 节的 08:00 起排，只在整张表都读不到大节时刻时使用。
