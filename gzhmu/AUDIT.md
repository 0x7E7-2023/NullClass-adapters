## 2. 模板选择与不同构之处

选 **`hnptc`**（同批次十六已审计的强智件）当模板，入口判断（登录页 / 首页 / 其它页面不发请求）照 `hunau`，WebVPN 路径前缀写法参考 `gdust` / `czimt`：

- 请求与本校**逐路径相同**：`GET/POST /jsxsd/xskb/xskb_list.do` + `POST /jsxsd/jxzl/jxzl_query`；网格列号 `col` / `span` 的交法、星期表头对齐、周历开学日口径、H3 节次补齐、周次逐段判单双、
  提醒限长出口、只在本人课表页读屏幕课表、隐藏元素不读，都是批次十六的最新写法。
- 不选 `gdcp`：它是上游自称的参考件，但 `gdcp` 要判校区 / 早晚班，这一层本校没有。
- 与 `hnptc` 不同构、要自己改的几层：
  1. **没有简表（`div.kbcontent1`）**：上游只读 `.kbcontent`，所以 `hnptc` 里「简表与详表按课名 + 周次 + 教室择优」整套（`candidatesOfBlock` / `mergeCandidates` / `registerCandidate`）**整段删掉**；
     行表头里的「N-M节」也不再用来给没写节次的课补节次（上游缺节次直接报错，这里计数并点名丢弃）。
  2. **课名**取块里第一个**不带 title 的 `font`**（上游 `font:not([title])`）；`hnptc` 取裸文本节点。extract.js 仍把「不带标题的 font 的文字」交出去，裸文字只作兜底。
  3. **节次逐项列举**：`[01-02-03-04节]` 是第 1 至 4 节；`[01-03节]` 是第 1 节与第 3 节，不补成三节（上游 `split('-').map(Number)`）。`hnptc` 的 `[01-04节]` 是区间。
  4. **没有 GET 退路**：`hnptc` 在 POST 失败时退回带 `xnxq01id` 的 GET，上游本校没有，本件不加，请求体里也没有 `jx0404id`（上游没有）。
  5. **入口**：`loginUrl` 是 WebVPN 首页（不是教务地址），教务主机在 `allowHosts`；extract.js 按当前页面主机分类（见 §3 与 `locate`）。
  6. **节次时间**：16 节，上游写死（来源 `https://jwc.gzhmu.edu.cn/info/1118/5748.htm`，2018-2019-2 学期起执行）；课表行表头里有时钟（`(01,02小节)08:30-09:55`），上游逐行核对，本件同样核对。
  7. **周历**：上游要求第 1 周周一日期、周一必须是星期一、周次连续、年份与学期代码一致，否则整次报错；本件照常导入并出提醒（§8）。

## 3. 请求清单（与代码一致）

extract.js 只有一处 `fetch(` 字面量（`requestText`），运行时最多发出下面三种请求。地址 = 当前页面 `origin` + 「当前路径里 `/jsxsd/` 之前的前缀」+ 固定路径，所以全部落在**当前页面同源**，
`credentials: 'same-origin'`。校外页面（`webvpn.gzhmu.edu.cn/https/<代理标识>/jsxsd/…`）上请求留在 WebVPN 主机、保留 `/https/<代理标识>` 前缀；校内页面（`jwgl.gzhmu.edu.cn/jsxsd/…`）上直连教务。

| # | 方法 | 路径 | 请求体 | 何时发 | 作用 | 取不到时 |
|---|---|---|---|---|---|---|
| R1 | GET | `/jsxsd/xskb/xskb_list.do` | 无 | 当前页面没有学期下拉框或没有节次模式下拉框时（`fetchPageInfo`） | 读 `xnxq01id` 的选中学期和 `kbjcmsid` 的值 | 页面上有课表格子：学期取不到，载荷带 `screenTermMissing`，由提醒说明；没有课表格子：报「没找到学年学期」或「没找到节次设置」；回的是登录页：报「登录状态已失效」 |
| R2 | POST | `/jsxsd/xskb/xskb_list.do` | `cj0701id=&zc=&demo=&xnxq01id=<学期>&sfFD=1&kbjcmsid=<节次模式>` | 当前页面没有课表格子，或页面选定了某一周（`zc` 选了具体周次） | 整学期课表（上游 `gzhmuRunImport` 的 POST，请求体逐字一致） | 状态码 401/403 报「教务系统拒绝访问」，其它非 2xx 报「教务系统返回错误（代码 N）」；返回的学期与所选不符报「不是所选学期」；没有课程格子报「课表是空的」或「登录状态已失效」 |
| R3 | POST | `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期>` | 取得学期代码后每次提取（`fetchCalendar`） | 教学周历：第 1 周的日期与周号 | 不致命：请求失败、返回页上的学期下拉框选的是别的学期、表格认不出，都返回空周历，由 parse.js 按提取日期推算开学日并出提醒 |

- 页面上已有课表格子且没有选定某一周时，**不发 R1、R2**，只发 R3（此刻屏幕上的就是整学期课表）。
- `locate` 的分类：`*.webvpn.gzhmu.edu.cn` 子域名 → 报「暂不支持从这个 WebVPN 子域名页面导入」，**不发请求**；不是 `jwgl.gzhmu.edu.cn` / `webvpn.gzhmu.edu.cn` → 报「当前页面不是广州医科大学教务系统的页面」；
  路径里没有 `/jsxsd/`（WebVPN 首页等）→ 报「还没有进入教务系统」；`/jsxsd/` 根、含 `login`、以 `sso` 开头 → 报「当前是教务系统的登录页」；以上都不发请求。
  页面上有密码框、又没有课表格子 → 同样报登录页提示，不发请求。
- 请求体里只有学期代码、节次模式（都来自页面下拉框）和上游原样保留的空参数。不带学号、姓名、令牌，不读本地存储，不读 cookie。
- 上游静态扫描（手册 §5 的两条命令）：绝对 URL 只有注释里的入口（`https://jwc.gzhmu.edu.cn/info/1118/5748.htm`）；`fetch(` 一处（`gzhmuFetchDoc`），地址由 `window.location.origin` + 前缀 + `/jsxsd/…` 拼出；
  没有 `XMLHttpRequest`、`sendBeacon`、`new WebSocket`、`.src =`。

## 4. 读了什么、交出去什么

读取，只读，不写页面：

- **活页（`document`）**，只在当前页面路径在 `/jsxsd/xskb/` 下（本人学期课表页，`onKbPage`）时读：
  - 课表表格：`#timetable`，找不到取最近一张含 `.kbcontent` 格子的表（`findScheduleTable`；`#kbtable` 是教学周历，不当课表）。逐格读 `colspan` / `rowspan`、类名含 `kbcontent` 的 div（`partsOf`，**不读** `kbcontent1`）。
    **不转交 `innerHTML`**，`safeHtmlOf` 按严格白名单重新拼一份最小的明细：不带标题的 `font`（课名）、最外层文字（课名兜底、一格几门课之间的减号分隔线）、换行、标题含
    「周次 / 节次 / 教师 / 老师 / 教室 / 地点 / 课程」的 `font` 里**看得见的**文字（标题原样写回）；其它元素——悬浮详情 `.item-box`、`span`、`a`、`img`、输入框、脚本、标题不在白名单里的 `font`——
    连里面的文字一律不读；看不见的元素（`hidden`、`aria-hidden`、行内 `display:none` / `visibility:hidden`）一律不读；每段文字最多 100 字。
  - 没有课程明细的格子只交 parse.js 认得的标签（`labelOf`）：星期表头、行表头里的节次时钟（`(01,02小节)08:30-09:55`）、周号 / 日号；其它自由文字一律不交。
  - 学期下拉框 `xnxq01id` 的选中项（代码 + 选项文字，最多 40 字）、`kbjcmsid` 选中项的值、`zc` 是否选了具体周次。
- **R1 / R2 / R3 的返回页**：用 `DOMParser` 在离线文档里按同一套函数读，交出的形状相同。周历只交每格的 `col`、周号 / 日期文字与 `title` 里的日期（`calendarGrid`，`title` 只留日期那一段）。
- 页面上还会读：有没有密码输入框（`hasPasswordInput`，只看 `type`，不读值）。

交出去的（`payloadOf`，一个 JSON 字符串）：

| 字段 | 内容 |
|---|---|
| `now` | 提取当天的本地日期 `yyyy-MM-dd`（周历取不到时推算开学日用） |
| `term` | `{ code, name }`：学期代码与选项文字 |
| `screenTermMissing` | 屏幕课表页上没找到学期下拉框 |
| `cols` | 课表表宽（网格列数） |
| `calendar` | `{ found, rows: [[{ col, text, title }]] }` |
| `rows` | `[[{ col, span, text, th, parts: [明细 HTML] }]]` |

没有学号、姓名、身份证号、手机号、令牌。冒烟里假页面的悬浮详情 / 隐藏元素 / 页面其它位置放了假的个人信息，逐项断言没有出现在 extract.js 的输出里，也没有出现在请求里。

## 5. allowHosts

`["jwgl.gzhmu.edu.cn"]`。`loginUrl` 是 `https://webvpn.gzhmu.edu.cn/`（上游 `import_url`），它的主机自动在白名单里；校内直连的教务主机 `jwgl.gzhmu.edu.cn` 写进 `allowHosts`。没有通配。

上游还认 `*.webvpn.gzhmu.edu.cn` 子域名形式，但具体子域名不明、`allowHosts` 不许通配，所以这一形式**不支持**：在那种页面上点「提取课表」直接给大白话提示（从 WebVPN 首页进入教务），不发请求（冒烟场景 `vpn-subdomain`）。

## 6. 手册 §5 安全八条

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 不碰凭据 | 通过 | 不读 password / 令牌的值，不读 cookie、`localStorage`、`sessionStorage`。check.js 对 extract.js 里「password」字样出提示，来源是 `hasPasswordInput`：只读 `input.type` 判断「这是登录页」，不读 `value`，不外发。 |
| 2 | 不外发 | 通过 | `fetch(` 一处字面量（`requestText`），三种请求都是当前页面同源；没有 XHR、sendBeacon、WebSocket，没有图片 src 赋值。 |
| 3 | 请求域可控 | 通过 | 请求只落在当前页面同源；`locate` 只认 `jwgl.gzhmu.edu.cn` 与 `webvpn.gzhmu.edu.cn`，其它主机（含 WebVPN 子域名）不发请求；`allowHosts` 无通配。 |
| 4 | 只读课表 | 通过 | 只请求学生端课表页与教学周历；不请求成绩、学籍、缴费、个人信息页面。 |
| 5 | 不埋点 | 通过 | 没有统计、上报或遥测代码。 |
| 6 | 不 eval 远程代码 | 通过 | 两个文件都没有 `eval` 与 `new Function`；check.js 的词法扫描为 PASS。 |
| 7 | 不写页面 | 通过 | extract.js 只读：`safeHtmlOf` 遍历原节点读文字，不克隆、不改、不写；解析用 `DOMParser` 离线文档；没有 `innerHTML` 赋值、`appendChild`、表单提交、点击。 |
| 8 | 不依赖秘密 | 通过 | 没有硬编码的密钥、令牌、学号；学期代码与节次模式来自页面下拉框。 |

## 7. 节次时间（逐节，来自上游 `gzhmuTimeSlots`；parse.js 的 `SLOT_TIMES`）

出处：学校教务处 `https://jwc.gzhmu.edu.cn/info/1118/5748.htm`（2018-2019-2 学期起执行），上游写死。

| 节 | 时间 | 节 | 时间 |
|---|---|---|---|
| 1 | 08:30-09:10 | 9 | 14:45-15:25 |
| 2 | 09:15-09:55 | 10 | 15:35-16:15 |
| 3 | 10:05-10:45 | 11 | 16:20-17:00 |
| 4 | 10:50-11:30 | 12 | 17:05-17:45 |
| 5 | 11:35-12:15 | 13 | 17:45-18:25 |
| 6 | 12:20-13:00 | 14 | 18:30-19:10 |
| 7 | 13:00-13:40 | 15 | 19:15-19:55 |
| 8 | 14:00-14:40 | 16 | 20:00-20:40 |

- 课表行表头的时钟（`clockDifferences`）与它逐行核对：起点对第一节开始、终点对最后一节结束。不一致时（上游给对应课程写自定义起止时间；空课没有单门课的自定义时间）按学校公布的节次时间导入，
  并出提醒点名不一致的节次与两个时钟，请学生核对；读不到完整时钟也出一条提醒。
- 课表用到第 17-20 节：按「统一修订 H3」从第 16 节下课后课间 5 分钟、每节 40 分钟（上游 `defaultClassDuration` / `defaultBreakDuration`）顺推补上（17: 20:45-21:25，18: 21:30-22:10，19: 22:15-22:55，20: 23:00-23:40）并提醒；
  顺推会越过 23:59 的节次不补并说明（当前上限 20 节，实际不会触发，代码保留）。第 21 节及以后按脏数据丢弃并点名。
- 每次导入都出一条「节次时间按学校教务处公布的作息导入，学校如有调整，请在「学期管理」里核对」。

## 8. 与模板的差异、上游里被删掉或改掉的东西

| 上游 | 本件 | 理由 |
|---|---|---|
| `showSingleSelection` 弹窗选学期 | 取页面下拉框的选中项；`screenTermMissing` 时提醒 | 规范：不弹窗问学年学期；上游默认项就是页面选中项 |
| `showToast` / `showAlert` / `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / `notifyTaskCompletion` | 去掉；输出载荷 | 拾光界面调用，空课没有 |
| 缺教师 / 教室 / 课名 / 周次 / 节次字段时整次报错（`课程字段不完整`） | 缺教师、缺教室照常导入（null）按类型汇总提醒；缺课名 / 周次 / 节次的块不放进课表，计数并点名 | 规范：不许静默丢课，也不因一门课整次失败 |
| 周次格式不认 / 超范围 / 为空时整次报错 | 逐段解析；不认的备注忽略并提醒；超 30 周丢弃并计数；单双、隔周认不出按每周都上并提醒 | 同上；`(单)/(双)` 逐段归属、`共 N 周` 只剥备注、`第1-第8周` 都认（审计真抓到过的错） |
| 节次 > 16 整次报错 | 17-20 顺推补节次时间（H3），> 20 丢弃并点名 | 规范 |
| 周历周一日期不是星期一 / 周次重复 / 缺周 / 日期与周次不一致 / 年份与学期代码不符，整次报错 | 照常导入：对齐到周一并提醒；周历完全取不到时按提取日期推算开学日并提醒；总周数周历优先，课表更晚才抬高 | 同上 |
| 行表头时钟与公布的不一致时给对应课程写 `customStartTime` / `customEndTime`，不能确定时报错 | 按公布的节次时间导入并提醒学生核对 | 空课没有单门课自定义时间 |
| 登录页判断 `title` 含「登录 / 统一身份认证 / Login」或有密码框 | 只看密码框（无课表格子时），另外按地址分类 | 标题关键字容易误伤课表页 |
| `*.webvpn.gzhmu.edu.cn` 子域名 | 不支持：给提示、不发请求 | `allowHosts` 不许通配，具体子域名不明 |
| 星期固定按每行第 1-7 个 `td` | 按表头的星期名称对齐网格列（含 `colspan` / `rowspan`）；认不全按最右 7 列推断并提醒；`colspan` 跨天的格子放进跨到的每一天并提醒 | 不靠格子下标猜星期 |
| 读 `.kbcontent` 的 `innerHTML` | 白名单重拼，不转交 innerHTML | 手册 §5，学生信息不外带 |
| 上游单次整页流程 | `extract.js` 只搬数据，`parse.js` 做全部解释 | CI 只能跑 parse.js |

保留的上游行为：课程按（星期、课名、教师、教室）分组，记录每周上哪几节，再把每周的节次切成连续段、节次段相同的周次并到一起；节次逐项列举；周历 `#kbtable`；请求体逐字一致。
**与上游一致但值得说明**：连续节次不分午饭 / 晚饭，第 3-4 节与第 5-6 节同课同周会并成 3-6（上游按节次集合归并，fixture `merge` 钉住）。

## 12. 已知风险与未验证项

我们没有本校账号，真机没验过；以下都是读上游代码得出的结论。

1. **没有真实页面。** fixtures 与冒烟页面全部是合成数据（`_note` 字段标明）。`#timetable` / `#kbtable`、`div.kbcontent`、`font[title=…]`、`xnxq01id`、`kbjcmsid`、`zc`、周历的 `td[title]` 都来自上游代码，没在真实页面上核对。
2. **`*.webvpn.gzhmu.edu.cn` 子域名形式不支持。** 上游认，但具体子域名不明、`allowHosts` 不许通配；在那种页面上点提取会提示从 WebVPN 首页进入教务。若学校实际只提供子域名形式，学生需要换入口，可能需要后续补主机。
3. **WebVPN 前缀。** 路径里 `/jsxsd/` 之前的一段原样保留，只测了 `/https/<代理标识>/jsxsd/…` 这一种形状；经 WebVPN 打开时宿主是否放行 `webvpn.gzhmu.edu.cn`（`loginUrl` 主机）未验证。
4. **节次时间写死。** 2018-2019-2 学期起执行的 16 节（上游同样）；上游注释提到历史学期第 6-7 节曾是 12:20-13:45，学校以后调整，学生只能靠每次都出的提醒与时钟核对提醒自己核对。
5. **行表头时钟认不出。** 真实页面行表头写法若不是「(01,02小节)08:30-09:55」，会出「没能读到完整的节次时间」提醒，不影响课程导入。
6. **总周数。** 周历取不到时取课表里最晚的周次（上游同样），比学期实际周数小是常见的，已出提醒；超过 30 周的周次丢弃并计数。
7. **登录页判断。** 无课表格子时只看密码框与地址；会话过期时教务返回 200 加登录页，由 R1 / R2 的「登录状态已失效」接住。
8. **页面选了某一周的识别。** 只认 `zc` 下拉框；若真实页面用别的控件选周，仍可能把单周课表当整学期用（没有提醒）。
9. **白名单读不到的东西。** 悬浮详情、不认识的标签、标题不在白名单里的 `font` 一律不读；若本校的真实课程信息写在这些地方，会读不到，表现为「没认出课名 / 周次」之类的丢弃提醒。
10. **连续节次不分午饭 / 晚饭。** 上游就是这样归并的（见 §8），同课同周的第 3-4 节与第 5-6 节会并成一块。
11. **日期兜底。** 周历取不到时开学日按提取日期推算，已出提醒；学期中途导入而周历又取不到时，推算的开学日会差若干周，靠提醒让用户核对。
12. **多位教师** 原样放进 `teacher`（如「张某,李某」），与上游一致。
