## 本校与模板不同的地方（分析）

1. 节次时间是上游写死的 12 节（`QVTU_TIME_SLOTS`），时刻与 `zsc` 不同。逐节照抄，见下表。上游说明第 13、14 节（12:00-13:59）与晚上重叠，所以不提供；课表用到更晚的节次时按占位补并提醒。
2. 上游 `parseWeeks()` 整段只认一个「单周 / 双周」，再把括号内容整段删掉。`(单)1-8周(双)9-16周` 里两个标记都不是「单周」二字，删掉括号后会变成 1-16 每周都上。本件按段判断：前置无逗号时后一个标记归下一段，结果是单周 1-7、双周 10-16。后置 `1-8周(单)9-16周(双)` 仍各跟各的。
3. 「共 N 周」只剥备注本身；「第1-第8周」按一段读。这两条是模板已有的口径，本校上游没有，保留。
4. 教师、教室写成「未知」「待定」「暂无」（以及「未知教师」「未知地点」一类）留空，不写成名字。上游空教师会写成「未知教师」、空教室写成「未知地点」。
5. 上游弹窗选学期（当前项前后各 3 个）。改为读下拉框选中项，不弹窗。课表页和教学周历页都没有学期代码时，跟上游一样 GET 当前课表（不带请求体）。这一页仍没有学期代码就用「泉州职业技术大学当前学期」占位并提醒，不因此放弃导入。
6. 总周数：周历给出并且不少于 8 周就用周历；不足 8 周或没有周历时按 20 周。只有课表里的周次比这个更晚才抬高，并提醒。不把课表最大周当成学期长度。
7. 登录页、统一认证页、门户页不发请求。

## 请求清单

只在通过登录页判断之后发请求。取不到时的做法与代码一致（`fetchTerm`、`fetchCalendar`、`scheduleBody`）。

| 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|
| GET | `/jsxsd/jxzl/jxzl_query` | 无 | 读「学年学期」下拉框的选中项（`readTerm`） | 当作没有学期代码；屏幕上已有课表则用屏幕上的学期，否则改 GET 当前课表 |
| POST | `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期代码>` | 教学周历：开学日、周号（`fetchCalendar`） | 返回空周历，不抛错。开学日按提取日推算最近的周一，总周数按 20，都写进提醒 |
| POST | `/jsxsd/xskb/xskb_list.do` | `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=<学期代码>` | 已知学期代码、当前页没有课表格子时请求该学期课表 | 格子为空则报「课表是空的」；网络失败报「连不上教务系统」或「教务系统返回错误（代码 N）」 |
| GET | `/jsxsd/xskb/xskb_list.do` | 无 | 课表页和周历页都没有学期代码时取当前课表 | 页面像登录页则报「尚未登录」；没有格子报「课表是空的」；有课但仍没有学期代码则用「当前学期」占位并提醒 |

当前页已经有类名正好是 `kbcontent` 的课表格子时，不再 POST 课表。三条地址都是相对路径，主机是打开页面的 `jw.qvtu.edu.cn`。

登录页判断（`loginHint`，在任何 `fetch` 之前）：路径是 `/jsxsd`、`/jsxsd/`、`/jsxsd/index`、`/jsxsd/login`、`/jsxsd/xk/LoginToXk`，或主机不是 `jw.qvtu.edu.cn`，直接提示，不发请求。

## 读了什么、交出去什么

读取面只有这些：

- 地址的协议、主机、路径（不要查询串）。
- `select` 里 id 或 name 含 `xnxq` 的选中项：学期代码与显示文字。
- 课表 `#kbtable`（没有这个 id 时，退到最近一张含 `kbcontent` 的表）：每个格子的网格列号、跨列数、可见文字、类名正好是 `kbcontent` 的 div 的原始 HTML。不读 `kbcontent1`。
- 周历表：格子的列号、文字、`td` 的 title（日期）。

不读学号、姓名、身份证号、手机号、隐藏令牌。页面上即使有这些，也不放进交出去的对象。

`extract.js` 交出去的字段：`source`、`pageUrl`、`now`、`term.code`、`term.name`、`screenTermMissing`、`cols`、`calendar`、`rows`（格子只有 `col` / `span` / `text` / `parts`）。

`parse.js` 交出去的载荷：学期名、开学日、总周数、12 节（或补上的）节次时间、课程的课名 / 教师 / 地点 / 星期 / 节次 / 周次段。教师、地点没有就是空，不写「未知」「待定」「暂无」。

## 上游里删掉或改掉的

| 上游 | 本件 | 理由 |
|---|---|---|
| `showAlert` / `showSingleSelection` 选学期 | 读下拉框选中项 | 移植约定不弹窗问学年学期 |
| `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / toast / `notifyTaskCompletion` | 删除 | 空课自己组载荷，脚本只读 |
| `parseWeeks` 整段一个单双、括号整段删除 | `weeksIn` 按段判断单双 | 否则 `(单)1-8周(双)9-16周` 变成每周都上 |
| `mergeCourse` 同名同天同节次同地点合并周次 | 只去掉完全相同的重复块 | 不按课名把相邻节次并成连堂；同一节的重复行不会叠成两门 |
| 空教师写成「未知教师」、空教室写成「未知地点」 | 留空，并汇总提醒 | 「未知」「待定」「暂无」不能当成真名或真教室 |

| 第 13、14 节不提供时间 | 课表用到才按占位补并提醒 | 不补的话这些课画到课表外面；补了必须出声 |
| 登录页仍可能发请求 | 认出登录页、别的主机就只提示 | 移植约定 |

## 已知风险

- 没有本校账号，真页面没验过。行首标签若写成「第七大节（13,14 小节）」这种，行首补节次认不出，要靠周次串里的方括号。
- 占位第 13 节从 20:00 起，和晚上第 10-12 节（20:10 起）重叠，只靠提醒说明。
- 周历第 1 周没有「星期一」格时，会用第一个带日期的格子对齐到周一，或按提取当天推算，两种都会提醒。
- 上游把同一门课相邻节次合并成一条；本件不合并，同一门课占两行会是两条安排，不会丢课。
- 上游在完全没有学期下拉框时会 GET 当前课表。本件同样发这次 GET。返回页里若有学期代码，再用它去取周历；仍没有，就用「当前学期」占位并提醒，课不丢。
