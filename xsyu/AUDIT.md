## 0. 本校与上游的结构（分析，先于动手）

上游脚本的取数链路（`xsyu_01.js`，行号以上游快照为准）：

1. `extractPageParams`：GET `/admin/pkgl/xskb/queryKbForXsd`（课表页 HTML），从中取 `#xhid`（学生标识，86 字符加密串）、`#xqdm`（页面校区）、`#xnxq1`（学年学期下拉框）。注释明确写了：首页 `/admin` 的同名 `#xhid` 是**用户 ID**，误用会返回 `ret=-1`。
2. `chooseSemester`：`ASK_SEMESTER = true` 时弹窗让用户选学期（默认项是下拉框的当前选中项）。
3. `fetchCourses`：GET `/admin/xsd/pkgl/xskb/sdpkkbList?xnxq=&xhid=&xqdm=&xskbxslx=0`，课程**按小节**返回（`djc` 1~10）；`kcmc` / `tmc` / `croommc` 是 `<a>` 包裹的 HTML；`xqdm` 参数**不过滤**，真正的上课校区看每行自带的 `xqid` / `xqmc`。
4. `fetchTimeAndWeekData`：GET `/admin/api/getZclistByXnxq?xnxq=&xqid=`，返回周次表 `zclist`（第 1 周 `minrq` 即开学日、条数即总周数）与节次时间 `jcsjszList`（10 条）。
5. 失败回落：节次时间取不到 → 按校区名用 `FALLBACK_SLOTS`（雁塔 / 明德 / 鄠邑三张写死表，另有 `默认校区` 别名指向鄠邑）。
6. 保存：`saveCourses` / `saveTimeSlots` / `saveConfig`，写库后 `notifyTaskCompletion`。

与模板 `sxgcxy` 不同构的地方：

| 层 | 模板 sxgcxy | 本校 xsyu | 处理 |
|---|---|---|---|
| 学生标识 | 页面 `#encodeId` | 课表页 HTML 的 `#xhid`（需 fetch 课表页，不能读当前页，首页值是错的） | 按上游 fetch 课表页 |
| 学期 | 推算当前学期，取不到退一学期 | 课表页下拉框的当前选中项（教务给的） | 用下拉框，不推算、不退学期（规则 2） |
| 课程数据 | 单行 = 一条安排，含连续节次 | 单行 = **一个小节**，要在 parse 里合并连续节次 | parse.js 的 `merged` 段合并 |
| 上课校区 | 问用户「唐槐 / 龙潭」 | 课程行自带 `xqid` / `xqmc`，自动判断 | 自动；判不出且教务也没给节次时才问（规则 2） |
| 节次时间 | 写死两张表（按校区代号） | 教务接口 `jcsjszList` 优先；取不到按校区名回落写死表；再不行用空课默认 12 节 | 三级回落（见 §4） |
| 节次超出表 | 无 | 课表用到的节次可能超出 10 节（本次数据里 `djc` 11 等） | H3 逐节补齐（见 §4） |
| 开学日 / 总周数 | 只能推算 | 周次表 `zclist` 给出 | 优先用教务，对不上学期时作废（H1） |
| 登录页 | 无判断 | `/admin/login` 与 `slogin` 字样 | 给大白话，不发请求（规则 6） |
| 周次写法 | 逗号数字 + 区间 + 单双（后置） | 上游只认逗号数字；另有 `共 N 周`、`(单)` 前置、无逗号前置标记等防御写法 | 按「审计真抓到过的错」逐条覆盖，见 §4 |

**本校专属边界（用例覆盖，见 §6）**：
- `basic`：`#xhid` 学生标识不外泄；HTML 课名 / 教师；职称括号；畸形括号教师 `赵六,(,钱七,)`；「待定」教室；超出 30 周的周次；空课名行；教务校历给出的开学日与总周数。
- `odd-even`：`1-16周(双)`；段首标记 `(单)1-8周,(双)9-16周`（不被并到上一段）；无逗号前置标记 `(单)1-8周(双)9-16周`；后置标记 `1-8周(单)9-16周(双)`；`1-8周(共8周),9-16周`（只剥备注）；教务不给周次表与节次时间（推算 + 校区表回落）。
- `h3-fill`：教务节次表只有 8 节时，`djc` 9~12 逐节补齐（空课默认表能补的用默认时间）；连堂 11-12 节合并。
- `campus-asked`：校区名判不出 → 用户选「明德校区」；明德表 10 节之后顺推（第 11-12 节，越过上一节下课后 5 分钟、每节 45 分钟）；春季学期锚点（2 月 20 日）。
- `long-name`：提醒里的长课名截到 20 字，整条远低于 200 字；无校区、无节次 → 空课默认 12 节 + 提醒。
- `multi-campus`：跨校区课程（最多者决定节次校区，其余提醒）；教务校历开学日对不上学期 → 作废并推算；总周数超过 20 → 抬高并提醒。

## 2. 读了什么、交出去什么

**读取**：
- 课表页 HTML（只在 `DOMParser` 里解析，**不挂到当前文档**，也不执行其中脚本）：`#xhid`（只作请求参数，不输出）、`#xqdm`（只作请求参数，行上没有校区时才作为校区代号，不输出）、`#xnxq1` 的当前选中项 `value` 与 `textContent`。
- 课程接口：只取 `kcmc`、`tmc`、`croommc`、`xingqi`、`djc`、`zcstr`、`xqid`、`xqmc`（**字段白名单**，`extract.js` 的 `ROW_FIELDS`）。其余字段（学分 `xf`、学号 `xh`、姓名 `xm`、身份证 `sfzjh`、手机 `sjh`、人员 ID 等）**丢弃**，不带出 `extract.js`。
- 周次表：`zclist[].zc`、`zclist[].minrq`（白名单 `WEEK_FIELDS`）；`jcsjszList[].jc`、`kssj`、`jssj`（白名单 `SLOT_FIELDS`）。

**交出去的数据（`extract.js` 的输出，逐字段）**：

| 键 | 内容 | 是否个人信息 |
|---|---|---|
| `term.code` | 下拉框选中项的 value，如 `2026-2027-1` | 否 |
| `term.text` | 下拉框选中项的显示文字，如 `2026-2027学年第一学期` | 否 |
| `campus.xqid` / `campus.xqmc` | 上课校区代号与名称（课程行的 `xqid` / `xqmc`，或课表页 `#xqdm`） | 否（校区） |
| `askedCampus` | 用户在提问里选的校区名，或 `null` | 否 |
| `rows[]` | 白名单 8 个字段（见上） | 否 |
| `slots[]` | 教务节次时间白名单 3 个字段（`jc` / `kssj` / `jssj`），没有则 `[]` | 否 |
| `weeks[]` | 周次表白名单 2 个字段（`zc` / `minrq`），没有则 `[]` | 否 |

**学生标识 `#xhid` 不在输出里**（冒烟与桩跑都验过：输出字符串里找不到它）。

**载荷（`parse.js` 的输出）**：`specVersion`、`kind: "schedule"`、`ocrAssisted: false`、`warnings[]`、`terms[0]{name, firstDay, totalWeeks, periodTimes[{periodIndex,start,end}], courses[{name, teacher, note: null, blocks[{dayOfWeek,startPeriod,endPeriod,startWeek,endWeek,weekType,location}]}]}`。**学分不带**（上游有 `xf` 并写入 `credit`；`docs/jw-adapter-spec.md` 里的课程字段没有学分，所以不带出）。

## 3. 手册 §5 八条逐条

| # | 检查项 | 结论 |
|---|---|---|
| 1 | 不碰凭据 | ✅ 不读密码、登录表单、令牌、Cookie 内容；不写 `localStorage` / `document.cookie`。`#xhid` 是学生标识（不是凭据），只作本校同源接口的查询参数，不外发、不输出。 |
| 2 | 不外发 | ✅ 脚本里没有绝对 URL；没有 `sendBeacon` / `WebSocket` / `new Image` / `.src =`；`XMLHttpRequest` 只出现在请求头 `X-Requested-With: XMLHttpRequest` 的取值里（与教务页面自己的 AJAX 请求头一致），没有 XHR 对象。 |
| 3 | 请求域可控 | ✅ 唯一主机 `jiaowu.xsyu.edu.cn`，即 `loginUrl` 的主机，宿主本来就放行；`allowHosts: []`；无通配。 |
| 4 | 只读课表 | ✅ 只 GET 课表页、课程接口、周次表（`zclist` / `jcsjszList` 是教务的排课日历与节次表，不是个人信息）。不请求成绩、学籍、缴费、个人信息页。 |
| 5 | 不埋点 | ✅ 没有统计、上报、遥测。提醒（`warnings`）只在导入预览里给本人看，不离开设备。 |
| 6 | 不 eval 远程代码 | ✅ 没有 `eval`、`new Function`、动态插 `script`。 |
| 7 | 不写页面 | ✅ 不改 DOM、不改表单、不触发提交。课表页 HTML 只用 `DOMParser` 解析字符串，不挂到当前文档。唯一与用户交互的是**应用自己的**提问弹窗（应用 UI，不是教务页面）。 |
| 8 | 不依赖用户输入之外的秘密 | ✅ 无硬编码密钥、无他人学号、无固定令牌。学生标识现场从课表页取，取不到就**报错**，不填占位符、不猜。 |

## 4. 相对上游的改动（都会影响行为，逐条列出；与 `extract.js` / `parse.js` 文件头一一对应）

1. **切成两段**：取数在 `extract.js`，解析在 `parse.js`。`parse.js` 是纯函数（CI 用 Rhino 跑），不碰网络、不碰桥。
2. **学期不再弹窗**（`ASK_SEMESTER`）：取课表页下拉框的当前选中项（`readKbPage`），没有选中就取第一个有值的。与上游默认项一致，但不让用户在多个学期里挑。
3. **校区自动判断**：`pickCampus`（extract）挑课程最多的校区代号，只用于拼周次表请求；`parse.js` 用同一规则确定节次时间的校区名（`campusName`），并在多校区时提醒。只有「校区名判不出、教务也没给节次时间」时才 `__ncSelect` 问一次。
4. **节次时间三级回落**（`parse.js` 的 `serverSlotsOf` / `CAMPUS_PERIOD_TEXT` / `DEFAULT_PERIOD_TEXT`）：教务 `jcsjszList` 通过校验（从 1 连续、每节有开始有结束、不重叠）→ 用它；否则校区名命中上游写死的三张表 → 用它；否则空课默认 12 节。上游的「默认校区」别名**不照搬**：认不出的校区名不猜，走空课默认 12 节并提醒。
5. **H3 逐节补齐**（统一修订 H3）：课表用到的节次超出所用的表，对同号的空课默认节次，只在它的开始不早于上一节下课时才用；否则在上一节下课后课间 5 分钟、每节 45 分钟顺推；越过 23:59 就停，课照常导入，补不上的节次写进提醒。
6. **开学日 / 总周数优先用教务**：`zclist` 里 `zc = 1` 的 `minrq` 是开学日，条数是总周数。**H1**：教务给的开学日与学期锚点（第一学期 9 月 1 日，第二学期次年 2 月 20 日）相差超过 45 天，判为别的学期的校历，**整份校历（含周数）一起作废**，改为推算并提醒。推算规则：「之后的第一个周一」。
7. **总周数抬高**：课表最晚周次超过总周数，抬高到最晚周次并提醒（H2 口径，按来源分开写：校历给的 / 没给的）。
8. **周次解析**（`weeksOf`）：上游只认逗号数字。这里另认：区间 `1-16`、`第1-第8周`、`共 N 周` 备注（**只剥备注本身**，`/共\s*[0-9]+\s*周?/g`，不用上游式 `.*$`）、单 / 双标记在后（`1-16周(双)`）、在前（`(单)1-8周`）、在括号里（`1-16(单周)`）。段首标记不并到上一段（`(单)1-8周,(双)9-16周`）；无逗号的前置标记：本段以标记开头时，后一个标记归下一段（`(单)1-8周(双)9-16周`），后置仍读对（`1-8周(单)9-16周(双)`）。括号里只有数字的（`(1)`）是序号，整组摘掉并计数；含别的字的备注（`(3组)`）也摘掉并计数；都写进提醒。
9. **教师**（`teacherOf`）：沿用上游 `cleanTeacherName` 的「括号里是有效教师」处理（`赵六,(,钱七,)` → `赵六,钱七`）。**不同于上游的一点**：上游会把职称括号（`王建国（副教授）`）的内容也当成老师名，输出成 `王建国,副教授`；这里按职称丢掉（`TITLE_RE`），输出 `王建国`。
10. **占位词 → null**：教师 / 教室是「待定」「未知」「暂无」等占位词时写 `null`（上游教室会写「待定」）。缺教师 / 缺教室按课程汇总提醒（「有 N 门课没有教室信息（例如 …）」），不逐课一条。

13. **排序不用 `localeCompare`**（Rhino 与 Node 对中文排序不同）：改成码位比较。
14. **字典键**：分隔符用 `String.fromCharCode(0)` 运行时拼；字典用 `hasOwnProperty` 取，避免 `constructor` 之类的键从原型上摸出真值。

## 7. 与模板 `sxgcxy` 的差异（逐条）

1. **取数不是一个请求**：xsyu 要先取课表页（拿 `#xhid` / `#xqdm` / 学期下拉），再取课程，再取周次表。`sxgcxy` 只有一个 `sdpkkbList`，`#encodeId` 读当前页。
2. **学期**：`sxgcxy` 推算当前学期并退一学期；xsyu 取下拉框的当前选中项，不推算、不退。
3. **节次时间与校区**：`sxgcxy` 问「唐槐 / 龙潭」、作息表写死在 `parse.js`；xsyu 的校区自动判断，节次优先用教务接口，回落三张写死表，再回落空课默认 12 节；H3 逐节补齐（`sxgcxy` 没有 H3）。
4. **开学日与总周数**：`sxgcxy` 只能推算；xsyu 用教务周次表，推算只在取不到时用，并有 45 天锚点校验（H1）。
5. **周次与教师**：`sxgcxy` 周次只认逗号 / 区间 / 后置单双；xsyu 增加前置、括号、「共 N 周」、「第」字与无逗号前置标记的处理，并修掉段首标记并段的坑；教师增加职称括号与畸形括号处理，占位词一律 `null` 并汇总提醒。
6. **请求域**：两者都 `allowHosts: []`、相对路径，结构相同。
