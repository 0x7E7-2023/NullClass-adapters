## 2. 模板选择与不同构之处

任务卡给的候选是强智件 `hnptc` / `qfnu`，DOM 表格部分参考 `ecjtu` / `guc`。本校上游**只解析当前页的表格、不发任何请求**，
与 `hnptc` / `qfnu`（POST 课表 + 教学周历 + 学期下拉框）只在「都是强智表格」这一点上同族；与 `ecjtu`（只解析当前页
`#courseSche` 表格、零请求或少请求）形状完全一致。所以：

- **骨架（extract / parse 两段、提醒限长出口、周次逐段判单双、H3 节次补齐、总周数默认 20、开学日按提取日期推算）
  照 `ecjtu` 复制**（批次三十六刚复审过，含「短行当课程行」的修正：标题 / 图例 / 备注行不当课程行跳过，
  表头没认全时整行星期名的表头行也跳过，见 §6）；
- **表格网格与表头星期对齐**照 `hnptc`（`#kbtable` 就是强智的课表容器，它的「按表头星期名对齐网格列、认不全再按最右 7 列推」
  正是本校需要的写法）；
- 与两者都不同构、按上游重写的层：
  1. 取数是 `#kbtable` → `.table_border` → 任意含「星期」的表（上游同一顺序），**零请求**，`allowHosts` 为空；
  2. 一格里的几门课用 **5 个以上连字符**分开（`ecjtu` 是固定行结构、`hnptc` 是 `div.kbcontent`）；
  3. 每块的行是「课名 / 教师 / `1-16(单)[01-02节]` / 地点」，周次与节次写在**同一行**，节次在方括号里
     （`ecjtu` 是「周次（空格）节次」两段、`hnptc` 是带标题的 `font`）；
  4. 星期上游按「倒数第 7 列是周一」硬算，这里优先按表头星期名对齐（任务卡要求），两者不一致按表头为准并提醒；
  5. 节次时间先读课表页左侧节次列里的 `HH:mm-HH:mm`，没有才回落应用自带的 12 节（`ecjtu` / `hnptc` 都只用写死的表）。

## 3. 请求清单（全部）

**没有任何请求。** `extract.js` 全文没有 `fetch` / `XMLHttpRequest` / `sendBeacon` / `WebSocket` / 图片 src 赋值；
`allowHosts` 为 `[]`。上游同样只在当前页面读 DOM；`loginUrl` 的主机不在 `allowHosts` 里也不需要，因为不发请求。
浏览器冒烟逐场景断言「`page.goto` 之后再没有请求」（§10）。

## 4. 读取面（`extract.js` 到底读了什么）与交出去什么

只读、不写页面：

- 课表表格：`findTable` —— `#kbtable` → `.table_border`（本身是表，或容器里的表 / 最近的表）→ 文档里第一张含「星期」两字的表。
- 表格网格：`gridOf` —— 逐行读 `td` / `th`，算网格列号 `col` 与 `colspan`，`rowspan` 占住的列在后续行空出来
  （否则左上角节次列会把星期算错）；**跨列的合并格（`colspan > 1`）不交出去**：强智的课程格是一天一格，
  合并格常是整行备注（可能带姓名学号），列号照算。
- 格子文字：`cellText` —— 活页面的 `innerText`（本身不含 `display:none` / `hidden` / 脚本）；拿不到时退 `textContent`。
  按行清理，**带「姓名 / 学号 / 身份证 / 考生号 / 手机号 / 联系电话」字样的行整行不读**；每行最多 100 字、每格最多 40 行。
  属性（`title` / `onclick`）、隐藏元素、输入框的值、页面脚本一概不读。
- 学年学期：`readTerm` —— `id` 或 `name` 含 `xnxq` 的 `select` 的选中项文字与值（各截 40 字）。不弹窗问用户。
- 提取当天日期 `now`（本地），只给 `parse.js` 推算开学日用。
- 登录页判断 `hasPasswordInput`：只看页面上有没有 `input[type=password]`，**不读它的值**。

交出去的对象（字段白名单）：`now`、`term{code,name}`、`cols`、`rows[[{col,span,text}]]`。
`text` 是一格的可见文字（多行以换行分隔，课与课之间保留 5 个以上连字符），不含学号、姓名、身份证号、手机号。
冒烟里往页面放了假学号 / 假姓名 / 假身份证 / 假手机号（可见的「姓名」行、隐藏 `span`、带 `title` 的空 `span`、
`onclick` 属性、隐藏 `input` 的值、`colspan=8` 的备注行），extract 输出与最终载荷里一个都没有（§10）。

`parse.js` 的输出：`specVersion 1`、`kind schedule`、`ocrAssisted false`、`warnings`（≤20 条、每条 ≤200 字）、
`terms`（一个学期：`name`、`firstDay`、`totalWeeks`、`periodTimes`、`courses`）。

## 5. 手册 §5 安全八条

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 不碰凭据 | 通过 | 不读密码 / 令牌 / cookie / `localStorage` / `sessionStorage`。check.js 对 extract.js 的「password」提示来自 `hasPasswordInput`：只读 `input.type`，不读 `value`。 |
| 2 | 不外发 | 通过 | 没有任何网络调用（§3），没有第三方域，没有 `sendBeacon` / WebSocket / 图片 src。 |
| 3 | 请求域可控 | 通过 | `allowHosts: []`，零请求，无通配。 |
| 4 | 只读课表 | 通过 | 只读当前课表页的表格与学年学期下拉框；不请求成绩、学籍、缴费、个人信息页面。 |
| 5 | 不埋点 | 通过 | 没有统计、上报、遥测代码。 |
| 6 | 不 eval 远程代码 | 通过 | 两个文件都没有 `eval` 与 `new Function`；check.js 词法扫描 PASS。 |
| 7 | 不写页面 | 通过 | 只读 DOM；没有 `innerHTML` 赋值、`appendChild`、表单提交、点击；check.js 没有出「疑似写页面」提示。 |
| 8 | 不依赖秘密 | 通过 | 没有硬编码密钥、令牌、他人学号；学期来自页面下拉框。 |

## 6. 与上游的差异（删掉 / 改掉的东西及理由）

- 删掉拾光界面的 `showToast` / `showAlert`（确认弹窗）/ `saveImportedCourses` / `notifyTaskCompletion` / 电脑端
  `console.table` 兜底与 `alert`：空课有自己的导入流程，适配器只交数。
- 删掉 `Set` 去重，改成普通对象做字典（ES5 / Rhino 口径统一）。
- **周次逐段判单双**：上游 `timeRegex` 的 `(单|双)` 只有一个捕获组，整串只判一次，`(单)1-8周,(双)9-16周` 会退化成
  1-16 每段都按单周。本件按逗号分段各自判，前置 / 后置 / 无逗号紧挨下一段的写法都认（`weeksOf` / `glueMarkers`），
  「共 N 周」只剥备注本身。本校正则写的是 `1-16(单)[01-02节]` 这种「方括号前是周次」的形状，所以周次文字取方括号之前那段。
  括号里整段是周次写法时一并认（`(1-16周)`、`（第1-16周）`），分隔符认 `,，、;；`（`isWeekText` / `weeksOf`）。
- **表头 / 图例 / 备注行不当课程行**：`ecjtu` 的「短行」修正按本件的稀疏行适配 —— 只有一格且没有周次节次行的跳过；
  表头只认出 1-3 个星期标题时（`findHeaderRow` 不认它）整行非空字全是星期名的行也跳过（`rowHasWeekSpec` /
  `headerLikeRow`），否则表头文字会被算进「有 N 处课程没能解析出来」。
- **教师 / 地点不因「像区间」丢掉**：周次候选必须先有周次特征（整行是「周次[节次]」，或带「周」字的周次写法，
  `looksLikeWeekText`）；`1-101`、`3-204`、`1-16-201` 这类数字连字符地点按位置照认，不置 `null`。
- **缺教师 / 缺地点交 `null`**：上游写「未知」「未知地点」，「未知」会被当成真名显示；本件按类型汇总提醒。
- **不再 `lines.length < 3` 静默丢块**：认得出课名与周次就收下（缺教师 / 缺地点不影响导入）；认不出的块按处计数、
  点名课名截 20 字，进提醒。
- **星期按表头对齐**：上游一律 `7 - (cells.length - 1 - j)`（倒数第 7 列是周一）。本件优先用表头里的星期名称
  （`findHeaderRow` / `dayOfLabel`），表头认不全或对不上最右 7 列时按最右 7 列补齐并提醒。
- **表格还原成网格**：上游用「第几个 td」当下标，`colspan` / `rowspan` 会把星期算错；本件交 `col` / `span`。
- **地点**：上游只认周次行的下一行；本件还认周次行方括号后面的同一行文字（`1-16[01-02节] 教C303`）。
- **节次时间**：上游不写节次时间（交给拾光自己的作息表）；本件先读课表页左侧节次列，取不到回落应用自带的 12 节，
  每次导入都出一条「请核对节次时间」的提醒。
- **开学日 / 总周数**：上游没有；本件按提取当天回退到周一推算、总周数默认 20（课表排得更晚才抬高），各出一条提醒。

## 7. 节次时间（逐节）

课表页左侧节次列里有 `HH:mm-HH:mm` 时（一行一个节次号 + 一个时间范围），逐节读进 `periodTimes`；
页面没有时用应用自带的 12 节（与模板 `ecjtu` / `qfnu` 同一张表）：

| 节 | 时间 | 节 | 时间 |
|---|---|---|---|
| 1 | 08:00-08:45 | 7 | 16:00-16:45 |
| 2 | 08:55-09:40 | 8 | 16:55-17:40 |
| 3 | 10:00-10:45 | 9 | 18:30-19:15 |
| 4 | 10:55-11:40 | 10 | 19:25-20:10 |
| 5 | 14:00-14:45 | 11 | 20:20-21:05 |
| 6 | 14:55-15:40 | 12 | 21:15-22:00 |

课表用到的节次超出 12 节时按「统一修订 H3」顺推：上一节下课后课间 5 分钟、每节 45 分钟，顺推越过 23:59 就停并提醒。
**本校节次时间未经真机验证**：页面给了就以页面为准，没给时这张表只是应用自带的默认值，每次导入都会提醒学生核对。

## 12. 已知风险与未验证项

- 没有本校账号，没有访问真实教务系统，没做 Android 真机抽验；合成 fixture 与假教务站只证明转换逻辑，
  真实页面结构（`#kbtable` 的表格布局、左侧节次列有没有时间、学期下拉框的 id）未验证。
- 周次写法按上游正则的形状（`1-16(单)[01-02节]`）与公共说明里的两种单双标记写法造用例；真实页面若用别的写法
  （例如周次与节次分行、节次写成「第1-2节」）会表现为「认不出的块」提醒，不会静默丢课。
- 节次时间：页面没给时用应用自带的 12 节，**未与学校实际作息核对**；页面给时间时依赖「一行一个节次号 + 一个时间范围」的形状，
  若学校用「第1-2节 08:00-09:40」这种大节合并写法，会回落默认表并提醒。
- `parse.js` 对 `colspan > 1` 的格子一律不当课程格（`extract.js` 干脆不交）；若学校用合并格表示跨天连上的课，
  该课会少一个星期的安排（上游同样只按「第几个格子」算一天，口径一致）。
- 星期表头若只写「一」「二」这种单字（没有「星期」前缀），认不出表头，会按最右 7 列对齐并提醒。
- 学期名优先取下拉框选中项；没有下拉框时按提取日期拼「重庆城市科技学院 2026-2027 学年第一学期」并提醒。
