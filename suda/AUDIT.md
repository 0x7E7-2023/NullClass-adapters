## 0. 平台与上游

上游 `resources/SUDA/adapters.yaml` 只有一份：`adapter_id: SUDA_01`，`maintainer: BernardYan2357`，
`import_url: http://xk.suda.edu.cn/`，说明写「网页仅在校园网/连接校内VPN环境下可访问」。**没有第二个上游脚本可取舍**。

本校是服务端渲染的老式 JSP 选课系统：课表页里有一张 `<table id="Table1" class="schedule">`，每个上课格子放一个 `<a>`，
`<a>` 的文字按 `<br>` 分行，依次是「课程名 / 时间行 / 教师 / 地点」；时间行形如
`周一第3,4,5节{第1-17周}`、`周二第8,9节{第2-16周|双周}`。学期与学年是课表文档里的两个下拉框 `select#xqd`（1 / 2）与
`select#xnd`（如 `2025-2026`）。上游不请求任何接口，只读当前页面。

选模板：本批任务卡指定从 `jw-adapters/hnsf` 借骨架，只借解析层（周次解析、极大段切分、提醒限长出口、H3 节次补全、缺教师 / 缺教室汇总），
取数层按本校上游重写。hnsf 是已审计件、周次写法最全（含批次十 swu 的单双标记修正），和本校一样是「教务不给总周数、开学日要推断」的形态；
库里没有同平台的已移植件可借 DOM 取数层，DOM 取数按上游重写（见 §5）。

## 2. 读了什么、交出去什么（逐字段）

`extract.js` 交给 `parse.js` 的对象（`JSON.stringify` 后的字符串，`extract.js:215`）：

| 字段 | 内容 | 来源 |
|---|---|---|
| `term.year` | 学年下拉框值里的 4 位年份 | `select#xnd` 选中项 `value` 的第一个 4 位数字（`extract.js:194`） |
| `term.semester` | `1` / `2` | `select#xqd` 选中项 `value`，只认这两个值 |
| `term.yearLabel` / `term.semesterLabel` | 两个下拉框选中项的文字（如「2026-2027」「第一学期」） | `option.textContent` |
| `today` | 提取当天日期（本地日期，不用 `toISOString`） | 本机时钟（`extract.js:53`） |
| `rows[].name` | 课程名 | 课程格子的第 1 行 |
| `rows[].time` | 时间行原文 | 第 2 行 |
| `rows[].teacher` | 教师 | 第 3 行，没有为空串 |
| `rows[].location` | 上课地点 | 第 4 行，没有为空串 |

取数规则（`extract.js:111`–`156`）：从 `<a>` 起逐个子节点取**看得见**的文字 —— `<br>` 换成换行，
`hidden` 属性、`display:none`、`visibility:hidden`（内联或计算后）的元素整棵子树跳过，`script` / `style` / `noscript` 不读；
每个格子只交前四行，每行截到 120 字。学生个人信息即使被塞在课程格子里（隐藏元素、第 5 行以后的文字、`title` 等属性）也不会进输出：
冒烟里往格子里塞了学号 / 姓名 / 身份证号 / 手机号，输出与载荷里都找不到（§8）。

`parse.js` 是纯函数：不碰网络、不碰页面，输出载荷里的教师名只是课表本来就显示的任课教师，不含学生信息。

## 4. 给学生看的文字

`extract.js` 的报错与 `parse.js` 的 warnings 都按 `docs/ux-writing.md` 写：不出现「接口」「载荷」「上游」「脚本」「字段」「JSON」「HTML」
「null」「学期设置」「作息表」；时间表统一叫「节次时间」；改学期名、开学日、总周数、节次时间指向「学期管理」，改教师 / 教室指向「编辑课程」。
带课名的提醒（缺教师 / 缺教室汇总）课名截到 20 字、最多点名 3 门；认不出的时间原文同样截 20 字；每条都经过 `warn()`（`parse.js:159`）
再截到 200 字以内。fixture `long-warnings` 钉住这一点。

提醒清单（顺序固定）：① 学期来源（取自页面下拉框 / 按今天的日期推算）；② 开学日是推算的（上游不取，见 §5）；
③ 总周数（教务不给，按 max(最晚周次, 20) 导入）；④ 节次时间（照上游的 12 节表导入）；⑤ 表外节次的补齐（空课默认 / 顺推 / 补不了）；
⑥ 被跳过的行（缺课名 / 星期 / 节次 / 周次，分类计数 + 认不出的时间原文）；⑦ 缺教师 / 缺教室汇总；
⑧ 不相邻节次按首末节之间的范围导入；⑨ 周次里的序号括号 / 备注括号 / 越界周次 / 孤立单双标记 / 单双同写。

## 5. 与模板（hnsf）的差异

借的是解析骨架：周次解析 `weeksOf`（前缀 / 后缀单双标记归属、「第1-第8周」、「共 N 周」只剥备注、序号 / 备注括号、全角标点）、
`runsOf`、提醒限长出口 `warn`、H3 节次补全、缺教师 / 缺教室汇总。取数层与课程拼装按本校上游重写：

1. **零请求的 DOM 取数**（§1），不是 hnsf 的「POST 排课接口拿 JSON」。表格、行结构、学期下拉框都照上游。
2. **时间行解析**（`parse.js:311`）：星期（周一～周日 / 天）、节次集合（`第3,4,5节`，展开成首末两节）、周次区间（`第1-17周`）、
   单双周（`|单周` / `|双周`）四种写法都接住；周次只读花括号里的部分，节次里的数字不会被当成周次；没有花括号时取最后一个「节」之后的文字。
   不相邻的节次（`第1,3节`）按上游的首末节范围导入，但会提醒。
3. **去重与合并**（`parse.js:412` 去重、`parse.js:437` 起分组合并）：完全相同的行先去重；同名、同教师、同地点、同星期、同周次的相邻节次合并成一段
   （首尾相接或重叠，`next.start <= current.end + 1`）。分组键含周次，**单周行与双周行不会被并成「每周都上」**（上游明确不合并不同周次）。
4. **开学日**：上游把「第一学期 9 月 1 日 / 第二学期次年 3 月 2 日」直接当学期开始日；这里按手册 §4.3 回退到那一周的周一
   （`parse.js:533`），并在提醒里说明是推算的。读不到学期下拉框时按今天的日期判断学期再套同一条规则（`parse.js:508`）。
5. **总周数**：上游写死 20；这里 `max(最晚周次, 20)`，最多 30，抬高时提醒。
6. **节次时间**：只有一张 12 节表（逐节照抄上游 `TimeSlots`，`parse.js:40`），没有 hnsf 的三张表 / 提问桥；
   表外节次按 H3 补（`parse.js:576`–`596`）。
7. **学期名**：用两个下拉框的文字拼（如「2026-2027学年第一学期」），拿不到就由学年与学期号推，推不出才用学校名（`parse.js:517`）。
8. 没有 hnsf 的 `jxcdmc2`（分周教室）、`qssj` / `jssj`（实际上课时间核对）、`weekOne`（第 1 周日期接口）：本平台与上游都没有这些数据。

## 6. 上游里删掉 / 改掉的东西及理由

| 上游 | 处理 | 理由 |
|---|---|---|
| `showAlert` 确认框、`showToast` 进度条、`saveImportedCourses` / `savePresetTimeSlots` / `saveCourseConfig` / `notifyTaskCompletion` | 去掉 | 拾光的桥能力；空课由宿主保存，适配器只交数据 |
| 七个字段（课名、时间、教师、地点……）缺一个就 `continue` 整行丢弃 | 只要求课名 / 星期 / 节次 / 周次；教师与地点缺了照常导入（null）并汇总提醒 | 公共说明第 4 条：缺教师 / 缺教室照常导入，不许静默丢课 |
| `innerHTML` 去标签取全文（隐藏元素、格子里的一切文字都会出去） | 逐节点取看得见的文字，隐藏元素整棵跳过，只交前四行 | 公共说明第 3 条：个人信息包括藏在格子 / 浮窗文字里的，一律不带出 |
| `semesterStartDate` 直接写 `2025-09-01` / `2026-03-02`，配 `firstDayOfWeek: 1` | 回退到那一周的周一当第 1 周第一天，并提醒是推算的 | 手册 §4.3：别把学期开始日直接当 firstDay 用 |
| `const` / `let` / 箭头函数 / `Array.from` / `new Set` / `Map` / 模板串 / `?.`，`for...of` | 全部改成 ES5 | 旧 WebView 与 Rhino |
| `detectSemesterStartDate` 静默失败（`try/catch` 后 `console.warn`） | 失败走推算并在 warnings 里说清楚 | 「拿不准一律进 warnings」 |
| 表格里的 `a` 元素不过滤、不相邻节次静默按首末节处理 | 前者照上游（由 parse 判时间行）；后者保留上游行为但写进提醒 | 不许静默猜节次 |
| 全角标点 / `|单周` / `第1-第8周` 等写法 | 保留并放宽（照批次十 swu / hnsf 的周次解析） | 上游接受的写法一个不能少 |

新增（上游没有）的：登录页 / 非本校主机的判断、缺教师 / 缺教室汇总、跳过行的分类计数、提醒限长、H3 表外节次补齐、`frame` 帧支持。

1. **页面结构全部来自上游脚本，没有在苏州大学真机验证**：表格选择器 `table#Table1.schedule`、`<a>` 四行结构、时间行写法、
   `select#xnd` / `select#xqd` 都照上游；若学校改版，会落到「没有找到课表」或跳过行，提醒里会给出计数但不会静默导入错误周次。
2. **开学日是推算的**：上游只给「9 月 1 日 / 次年 3 月 2 日」两个锚点，这里再回退到周一。真实开学日若不同，整学期会整体偏移，
   所以每次导入都有一条提醒让用户去「学期管理」核对。
3. **总周数是假设**：教务不给，按 `max(最晚周次, 20)`；真实学期若是 18 周，课表照常可用，只是「共 N 周」偏大。
4. **节次时间表无法核对**：12 节逐节照抄上游，没有学校公布的版本可对照；南北校区 / 不同学期若作息不同，上游也没有分支，这里同样没有。
5. **入口是 http 明文**：`http://xk.suda.edu.cn/`，应用会显示「不安全连接」标记；上游说明页面仅校园网 / 校内 VPN 可访问，
   校外访问需要在系统层面连 VPN，适配器不做任何代理或跳板。
6. **`scheduleUrlHint` 填的是 `http://xk.suda.edu.cn/`**：上游代码与 yaml 里都只有这个入口，没有课表页的深层地址
   （`SUDA/adapters.yaml` 的 `import_url` 就是根路径），所以「一键刷新」打开的是选课系统入口，由用户登录后进入「学生个人课表」。
   若日后拿到课表页真实地址，应改成那个完整地址。
7. **登录页判断是路径启发式**：根路径一律当登录页。如果登录后的首页恰好也是根路径，用户会看到「当前打开的是登录页」，
   需要先进入课表页再点提取。
8. **隐藏元素只认 `hidden` / 内联 / 计算样式**：被外部样式表以其它方式（如透明度 0、移出屏幕）藏起来的文字，浏览器仍算可见，
   会被当成行内容带出。上游同样会带出，这里只是把最常见、最容易藏学号的几种隐藏方式挡住了。
9. **iframe 只找两层**（与上游相同）；更深的嵌套会报「没有找到课表」。
10. **教师字段原样取**：上游不去括号备注（如「张三（外聘）」），这里同样原样，不拆成第二位教师。
