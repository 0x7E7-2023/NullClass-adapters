## 2. 模板选择与不同构之处

选 **`hnptc`**（批次十六已审计）：同平台，请求落点相同（`xskb_list.do` + `jxzl_query`）；网格列号 `col` / `span` 的交法、星期表头对齐、周历表头与开学日口径、H3 节次补齐、周次逐段判单双、
提醒限长出口都是最新写法。不选 `qdu` / `hnu` / `ouc`（它们是 GET 课表或要问作息方案，请求形状不同）；`gdcp` 的校区判断是按教学楼，与本校「时间模式」探测不同构。

与 `hnptc` 不同构、改过的几层：

1. **只读一份明细**：本校只读 `div.kbcontent`（上游 `querySelector('div.kbcontent')`），没有 `kbcontent1` 简表。`partsOf` 只认 `kbcontent` 类名；
   模板里「简表 / 详表择优打分」那套留着（`mergeCandidates`，同格重复段仍要归并），但不再有两份明细。
2. **课表请求体**：`jx0404id=&cj0701id=&zc=&demo=&xnxq01id=<学期>&kbjcmsid=<「全部」选项的值>`，**没有 `sfFD=1`**（模板有）；时间模式的值按选项文字「全部」找（`modeValue`），找不到带空值（上游同样）。
3. **每次都 POST，不看屏幕上的课表**：上游每次导入都先取学期列表再 POST 整学期课表。屏幕上可能只显示某一周或某个校区的课，所以去掉了模板的「屏幕优先」与「选定了某一周」判断；学期与时间模式直接读页面下拉框（`readTerm` / `modesOf`），页面上没有才 GET 一次课表页。
4. **校区判断（上游新增的功能，本批重点）**：见 §3、§8。
5. **星期标注**：上游优先取课程 div 的 `name`（没有取 `id`）里「哈希-星期-序号」的中间一段当星期，没有才用列序号。extract.js 的 `dayHintOf` 只把这个整数（1..7，不合法交 0）放进 `hints`，哈希不交；
   parse.js 以标注为准，与网格列对不上时计数提醒（`hintConflicts`）。
6. **教室兜底**：上游在没有「教室」标题的行里，把「隐藏 font + 可见文字」的那一行当教室。extract.js 的 `safeHtmlOf` / `closeLine` 把这种行（非首行、有看不见的 font、没有带标题的 font、有可见文字）补成 `<font title="地点">…</font>`，
   带「教室」标题的 font 优先（parse.js 的 `ROOM_KEYS` 先找「教室」再找「地点」）。
7. **不并相邻节次**：上游只把「课名 + 教师 + 地点 + 星期 + 节次」相同的课合并周次，不把第 1-2 节与第 3-4 节并成一条。模板 hnptc 的 `mergeAdjacent` / `NO_MERGE_AFTER` 已删除，只保留 `unionWeeks`（`merge` 用例钉住：第 1-2 与第 3-4 节不并）。
8. **分隔线**：上游 `/-----+/`（5 个及以上减号），模板是 6 个；`DASHES` 改成 5（`merge` 用例钉住，P1 变异）。
9. **节次时间**：龙泉 14 节 / 安宁 13 节两张表（模板是一张 10 节表），H3 顺推按每节 40 分钟、课间 10 分钟（学校课表的常规）。

## 3. 请求清单（与代码一致）

extract.js 只有一处 `fetch(` 字面量（`requestText`），运行时最多发出下面几种请求。地址 = 当前页面 `origin` + 「当前路径里 `/jsxsd/` 之前的前缀」+ 固定路径，全部落在当前页面同源，`credentials: 'same-origin'`。

| # | 方法 | 路径 | 请求体 | 何时发 | 作用 | 取不到时 |
|---|---|---|---|---|---|---|
| R1 | GET | `/jsxsd/xskb/xskb_list.do` | 无 | 当前页面没有学期下拉框或没有时间模式下拉框时（`fetchPageInfo`） | 读 `xnxq01id` 选中的学期、`kbjcmsid` 的全部选项 | 没找到学期：报错「教务页面里没找到「学年学期」选项」；回的是登录页：报「登录状态已失效」 |
| R2 | POST | `/jsxsd/xskb/xskb_list.do` | `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=<学期>&kbjcmsid=<「全部」的值>` | 每次提取（`fetchSchedule`） | 整学期课表（上游 `fetchScheduleForSemester`，请求体一致） | POST 失败（连不上、非 2xx）或返回里没有课 → R2'；返回页的学期与所选不符：报错 |
| R2' | GET | `/jsxsd/xskb/xskb_list.do?xnxq01id=<学期>` | 无 | R2 失败或没有课时 | 退路（上游没有这一步，是模板带来的，POST 失败也能继续） | 也拿不到：把 R2 的报错（有的话）抛出，否则报「教务返回的课表是空的」 |
| R3 | POST | `/jsxsd/xskb/xskb_list.do` | 同 R2，`kbjcmsid` = 「安宁校区」选项的值 | 时间模式里有名字含「安宁校区」的选项时（`chooseCampus` → `probeMode`） | 上游的校区判断：这个模式下有课就用安宁校区的节次时间 | 请求失败不致命，按龙泉并提醒（`probeFailed`） |
| R4 | POST | `/jsxsd/xskb/xskb_list.do` | 同 R2，`kbjcmsid` = 「龙泉校区」选项的值 | **只在安宁有课、且有龙泉选项时** | 上游没有这一步：区分「只在安宁上课」与「两个校区都有课」 | 失败按「只有安宁」处理（上游口径） |
| R5 | POST | `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期>` | 每次提取（`fetchCalendar`） | 教学周历：第 1 周的日期与周号（上游 `requestSemesterDetailPage`） | 不致命：失败、返回页上的学期下拉框选的是别的学期、表格认不出，都交 `found: false`；parse.js 按提取日期推算开学日、按课表最晚周次计总周数，各出一条提醒 |

- 校区判断的结论（`chooseCampus`）：没有「安宁校区」选项 → 龙泉（`noOption`）；安宁请求失败 → 龙泉（`probeFailed`）；安宁没有课 → 龙泉（`noAnning`，上游口径）；
  安宁有课且没有龙泉选项或龙泉没有课 → 安宁（`anning`，上游口径）；两边都有课 → `__ncSelect` 问一次（`asked`，默认选安宁，与上游的默认一致）；宿主不能提问或用户取消 → 安宁并提醒请核对（`bothDefault`）。
  只有「两边都有课」这一种情形会提问（它直接决定每节课的上下课时间，不只是一条提醒），整次提取最多一次提问。
- 请求体里只有学期代码、时间模式的值（都来自页面下拉框）和上游原样保留的空参数；不带学号、姓名、令牌，不读本地存储，不读 cookie。
- 上游的静态扫描：绝对 URL 只有 `import_url`（在 yaml 里）；`fetch(` 有三处（`requestSemesterDetailPage` 的周历 POST、`getSemesterList` 的 GET、`fetchScheduleForSemester` 的 POST），都是相对地址 `/jsxsd/...`；
  没有 `XMLHttpRequest`、`sendBeacon`、`new WebSocket`、`.src =`。上游另调拾光桥（`window.shiguangBridge` / `shiguangBridgePromise`）做提示、选学期、保存，空课里全部删掉（§8）。

## 4. 读了什么、交出去什么

读取，只读，不写页面：

- **活页（`document`）**：只读学年学期下拉框（`readTerm`）、时间模式下拉框（`modesOf`，仅 extract.js 内部用，不交出去）、有没有密码输入框（`hasPasswordInput`，只看类型，不读值）。**不读活页上的课表。**
- **R2 / R2' 返回页**（`harvestPage`）：
  - 课表表格：`#kbtable`，找不到取含 `.kbcontent` 的最近一张表，再找不到取 `#timetable`（`findScheduleTable`）。逐格读 `colspan` / `rowspan`、类名恰为 `kbcontent` 的 div（`partsOf`）。
    **不转交 `innerHTML`**，`safeHtmlOf` 按严格白名单重新拼一份最小的明细：最外层文字节点（课程名）、换行、标题含「周次 / 节次 / 教师 / 老师 / 教室 / 地点 / 课程」的 `font` 里**看得见的**文字（标题原样写回）；
    其它元素——悬浮详情 `.item-box`、`span`、`a`、`img`、输入框、脚本、标题不在白名单里的 `font`——连里面的文字一律不读；看不见的元素（`hidden`、`aria-hidden`、行内样式 `display:none` / `visibility:hidden`）一律不读；每段文字最多 100 字；
    格子里文字不超过 6 个字的不算课（上游同样，`MIN_TEXT`，空格子 / 占位符）。例外一：块里没有带汉字的最外层文字时，补一个看得见的、不带标题的 `font` 当课名；例外二：教室兜底（§2 第 6 点）。
  - 格子的星期标注：`dayHintOf`，只交 1..7 的整数。
  - 没有课程明细的格子的文字：只交 `labelOf` 认得的标签（星期、节次、周号、日期），备注、标题、藏在格子里的姓名学号一律不交；表头单元格打 `th: true`。
  - 学年学期与时间模式选项：学期核对用；时间模式选项只用来挑「全部 / 安宁校区 / 龙泉校区」三个值。
- **R3 / R4 返回页**：只数「有没有课格子」（`courseCells`），内容不交出去。
- **R5 返回页**：`#kbtable`，找不到取第一张 `td[title]` 带日期的表，再找不到取文档里第一张表（上游的做法）；只交有文字或有日期 title 的格子，并保留网格列号；格子文字同样只交 `labelOf` 认得的标签，`title` 只留日期那一段。
- 页面地址只用来拼请求前缀，**不交出去**。

交出去的对象（`payloadOf`，字段白名单）：`now`、`term{code,name}`、`campus{id,how}`、`cols`、`calendar{found,rows[[{col,text,title}]]}`、`rows[[{col,span,text,th,parts[],hints[]}]]`。
`parts` 是按白名单重新拼的课程明细，只有课程名、教师、周次节次、教室，不含学号、姓名、身份证号、手机号；冒烟往页面里放了假学号 / 假姓名 / 假身份证 / 假手机号
（悬浮详情里、`onclick` 属性里、隐藏输入框里、`display:none` 的 `span` / `hidden` 的 `div` / 看不见的带标题 `font`、不认识的可见 `span`、标题为「学号」的 `font`、课表外的备注行里、页面脚本变量里、简表 `kbcontent1` 里），
确认请求与输出里一个都没有（§9）。

parse.js 的输出：`specVersion 1`、`kind schedule`、`ocrAssisted false`、`warnings`（≤20 条、每条 ≤200 字，超 20 条第 20 条为汇总）、`terms`（一个学期：`name`、`firstDay`、`totalWeeks`、`periodTimes`、`courses`）。

## 5. allowHosts

`[]`。请求全部是当前页面同源的绝对地址（`origin` + 前缀 + `/jsxsd/...`），脚本里没有写死任何主机名；`loginUrl` 的主机 `xjwis.ynufe.edu.cn` 自动在白名单里，没有第二个主机，没有通配。
上游也只请求相对地址 `/jsxsd/...`（同源），没有别的主机。

## 6. 手册 §5 安全八条

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 不碰凭据 | 通过 | 不读 password / 令牌的值，不读 cookie、`localStorage`、`sessionStorage`。check.js 对 extract.js 里「password」字样出提示，来源是 `hasPasswordInput`：只读 `input.type` 判断「这是登录页」，不读 `value`，不外发。 |
| 2 | 不外发 | 通过 | `fetch(` 一处字面量（`requestText`），五种请求都是当前页面同源；没有 XHR、sendBeacon、WebSocket，没有图片 src 赋值。 |
| 3 | 请求域可控 | 通过 | `allowHosts` 为空，请求只落在 `loginUrl` 同源；无通配。 |
| 4 | 只读课表 | 通过 | 只请求学生端课表页与教学周历；校区探测只是换一个时间模式再取课表；不请求成绩、学籍、缴费、个人信息页面。 |
| 5 | 不埋点 | 通过 | 没有统计、上报或遥测代码。 |
| 6 | 不 eval 远程代码 | 通过 | 两个文件都没有 `eval` 与 `new Function`；check.js 的词法扫描为 PASS。 |
| 7 | 不写页面 | 通过 | extract.js 只读：`safeHtmlOf` 遍历原节点读文字，不克隆、不改、不写；解析用 `DOMParser` 离线文档；没有 `innerHTML` 赋值、`appendChild`、表单提交、点击。校区探测的 POST 是只读查询（上游同样会发），不改教务端的任何设置。 |
| 8 | 不依赖秘密 | 通过 | 没有硬编码的密钥、令牌、学号；学期代码与时间模式值来自页面下拉框。 |

- **超出学校的节数（H3）**：上游照用课表里的节次、不补节次时间。本件从最后一节下课后顺推，课间 10 分钟、每节 40 分钟，越过 23:59 就停，补了哪些、哪些补不了都写进提醒
  （`period-overflow-longquan`：第 15 节补成 22:30-23:10，第 16 节补不了；`period-overflow-anning`：第 14、15 节补成 21:30-22:10 与 22:20-23:00）。节次上限 `MAX_PERIOD` = 20，超过的安排跳过并点名。
- 上游并不把相邻节次并成一条，这里也不并（§2 第 7 点）。

## 8. 与上游的差异、上游里被删掉或改掉的东西

| # | 上游 | 本件 | 理由 |
|---|---|---|---|
| 1 | 弹窗选学期（`showSingleSelection`，默认项 = 页面选中项） | 取页面下拉框的选中项，不弹窗 | 公共说明第 2 条 |
| 2 | `showToast` / `notifyTaskCompletion` / `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / 全部 `console.*` | 全部删除 | 拾光的桥能力，空课由宿主保存，脚本只交数据；不删就无法在空课运行 |
| 3 | 缺教师写「未知教师」、缺教室写「未知地点」 | 留空（`null`），按类型汇总提醒，点名课名截 20 字，指向「编辑课程」 | 公共说明第 4 条 |
| 4 | 没课名 / 没周次 / 没节次的块静默丢弃（`console.warn` 后 `return`） | 全部计数并点名（≤3 个）；节次写不出来时先取本行表头里的「N-M节」，再没有才丢 | 不许静默丢课 |
| 5 | 周次 `getWeeks`：单双标记只认「周」字后紧挨着的一个字，「(单)1-8周」这类前缀写法认不出；`第`、`到` 被粗暴替换 | 先分段、每段各自判，前缀 / 后缀 / 自成一段的标记都认；「共 N 周」只剥备注本身；教学班序号 `(1)` / 括号备注 `(实验)` 不当周次并计数提醒 | 审计真抓到过的错（批次七 lcudcc / 批次十 swu） |
| 6 | 星期 = 优先 div 的 name 里的星期，没有才用列序号（`td` 序号） | 同口径：标注优先；没有标注按表头里的星期名称对齐网格列，表头认不全再按最右 7 列推断并提醒；跨列的格子放进它跨到的每一天并提醒 | `rowspan` / `colspan` 会让序号错位；推断的一律说明 |
| 7 | 开学日取教学周历第一行第一个带 `title` 的格子，不检查是不是星期一；总周数取所有行第一格的最大整数，取不到给 20 | 按周历表头认出「一」那一列；认不出表头取第 1 周那一行第一个带日期的格子，是星期日就取后一天；不是星期一则对齐到所在周的周一并提醒；都没有按提取日期推算并提醒；总周数取不到时用课表最晚周次并提醒 | 公共说明硬约束 6：推算值必须说明；载荷 totalWeeks 1..30 |

## 11. 已知风险与未验证项

我们没有本校账号，真机没验过；以下都是读上游代码得出的结论。

1. **没有真实页面。** fixtures 全部是合成数据（`_note` 字段标明）。`#kbtable`、`div.kbcontent`、`font[title=…]`、`xnxq01id`、`kbjcmsid`、周历的 `td[title]`、`div` 的 `name`（哈希-星期-序号）这些名字都来自上游代码，没在真实页面上核对。
2. **「周次(节次)」的写法只知道上游的正则**：`^(.+?)\(周\)` 与 `\[(.+?)节?\]`，即 `1-18(周)[06-07节]`。单双周在这家学校的真实写法没见过（上游 `getWeeks` 认「1-6,7-13周(单)」这种）；本件的周次解析范围比上游宽（前缀 / 后缀 / 括号里写周都认），认不出的整段进提醒，不会静默丢。
3. **龙泉校区第 10 节只有 20 分钟（18:10-18:30）**：上游原样如此，疑似笔误，没有学校公布的时间可对；每次导入都出「请核对节次时间」的提醒兜底，但学生如果不核对，这一节的下课时间就是错的。需要主调度或维护者有渠道时核对。
4. **校区判断依赖时间模式的选项文字**：选项文字里含「安宁校区」「龙泉校区」，沿用上游 `includes('安宁校区')`；若教务改了文字，找不到安宁选项 → 按龙泉并提醒（`noOption`）。「全部」选项要求文字完全一致（上游 `=== '全部'`）。
5. **「安宁模式下有课」≠ 学生在安宁校区上课**：这是上游的判据。学生同时有龙泉与安宁的课时，上游会直接选安宁；本件改为问一次（只在两个校区的探测都有课时），取消或不能提问时与上游一致取安宁并提醒。
6. **总周数。** 周历取不到时取课表里最晚的周次，比学期实际周数小是常见的，已出提醒；超过 30 周的周次丢弃并计数。上游取不到给 20。
7. **WebVPN。** 前缀（`/jsxsd/` 之前的路径）原样保留，只测了 `/http/<令牌>/jsxsd/...` 一种形状；学校的 WebVPN 主机名上游没给，不在白名单里，经 WebVPN 打开时宿主可能拦截请求，未验证。
8. **登录页判断。** 只看页面上有没有密码框；会话过期时教务返回 200 加登录页，会被 R1 / R2 / R2' 的「登录状态已失效」或「没找到学年学期」接住，是同一类大白话提示。
9. **白名单读不到的东西。** 悬浮详情 `.item-box`、不认识的标签（包括包着课名的 `span` / `b`）、标题不在白名单里的 `font` 一律不读；若本校的真实课程信息写在这些地方，会读不到，表现为「没认出课名 / 周次」之类的丢弃提醒，不会静默。
10. **教室兜底的识别面。** 只在非首行、有看不见的 `font`、没有任何带标题的 `font`、有可见文字时才把可见文字当教室（上游的条件是「还没拿到教室 + 行内含 `style="display:none;"`」）；若真实页面把隐藏标记写成 CSS 类而不是行内样式，两边都识别不到（上游同样）。
11. **多位教师** 原样放进 `teacher`（如「张三,李四」），与上游一致。
12. **按校区探测多发了 1-2 次课表请求**（R3、R4），都是只读查询；R4 是本件新增的，上游没有。
