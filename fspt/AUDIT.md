## 3. 请求清单（与代码一致）

所有请求都是当前页面同源的相对地址（`origin` + `/jsxsd/` 之前的前缀，没有前缀就是空 + 路径），`allowHosts` 为空。
「取不到时怎么办」写的是代码里的实际分支。

| # | 方法 + 路径 | 请求体 | 用途 | 取不到时 |
|---|---|---|---|---|
| R1 | GET `/jsxsd/xskb/xskb_list.do` | 无 | 只在「屏幕上没有课表 / 选定了某一周，且页面没有学期选中项」时读学期下拉框（`fetchPageTerm`）。若页面有密码框且没有学期选项，报「登录状态已失效」 | 网络错误 → 报「连不上教务系统」；没有学期选项 → 报「教务页面里没找到『学年学期』选项」 |
| R2 | POST `/jsxsd/xskb/xskb_list.do` | `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=<学期>` | 整学期课表（`fetchSchedule` 主路径，与上游同一请求体） | 失败或没有课程格子 → 进 R3；返回的学期与所选不符 → 报「不是所选学期」（不退回） |
| R3 | GET `/jsxsd/xskb/xskb_list.do?xnxq01id=<学期>` | 无 | R2 失败或没有课程格子时的退路（上游没有这一步，保留模板的做法） | 仍拿不到 → 若 R2 抛过错就把 R2 的错原样报出，否则报「教务返回的课表是空的」 |
| R4 | POST `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期>` | 教学周历：开学日期与总周数（`fetchCalendar`） | 任何失败、或返回的学期与所选不符、或认不出格子 → 空网格，由 `parse.js` 推算并提醒（不致命） |

- 与上游比：上游还会 GET `/jsxsd/jxzl/jxzl_query`（列学期，无请求体），本件不发，学期直接取课表页的选中项。
- 不请求：成绩、学籍、缴费、个人信息、选课、评教页面。
- 请求的每一个响应只按白名单读取，不转交原文（见 §4）。

浏览器冒烟的真实请求记录（假站，`route` 拦截）：

- 正常页（`fetch`）：`GET xskb_list.do` → `POST xskb_list.do`，体 `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=2026-2027-1` → `POST jxzl_query`，体 `xnxq01id=2026-2027-1`。
- 屏幕已有课表（`onscreen`）：只发 `POST jxzl_query`（学期取屏幕选中项，不重复请求课表）。
- 选定某一周（`week-filtered`）：`POST xskb_list.do`（同上请求体）→ `POST jxzl_query`。
- POST 500（`post-500`）：`GET xskb_list.do` → `POST xskb_list.do`（500）→ `GET xskb_list.do?xnxq01id=2026-2027-1` → `POST jxzl_query`。
- 登录页（`login`、`root-login`）：零请求，直接报大白话错误。根路径上已登录的页面（`root-main`）照常导入，与 `fetch` 请求序列相同。
- 空课表（`empty`）：`GET` → `POST`（空）→ `GET ?xnxq01id=`，报「教务返回的课表是空的」。

## 4. 读了什么、交出去什么

**读：** 学期下拉框（`id` 或 `name` 含 `xnxq`）的选中项；`select#zc` 的选中值（只用来判断是否选定了某一周）；课表 `#kbtable` 的行与格；`div.kbcontent` 里的课程明细；周历 `#kbtable`（或含日期 `title` 的表）；课表页底部「备注」行的文字；登录页**只看**有没有 `input[type=password]`，不读它的值。
不读：cookie、`localStorage`、`sessionStorage`、任何令牌、学号、姓名、身份证、手机号。

**交出去的 JSON（`extract.js` 的输出，逐字段）：**

| 字段 | 内容 | 不带出的 |
|---|---|---|
| `now` | 提取时的本地日期 `yyyy-mm-dd`（不用 `toISOString`，北京时间早上会退一天） | — |
| `term.code` / `term.name` | 学期下拉框选中项的值（形如 `2026-2027-1`）与文字（截 40 字） | 其它学期选项 |
| `screenTermMissing` | 布尔：屏幕上找不到学期下拉框 | — |
| `cols` | 课表表宽（网格列数） | — |
| `remarks` | 课表备注行「备注」后面的文字，只取看得见的前 60 字；带课程明细的格子不参与 | 备注里的其它 HTML、隐藏文字 |
| `calendar.found` / `calendar.rows` | 周历网格：每格只留 `col`，以及 `text`（仅周号、星期标签、日期）、`title`（仅 `yyyy-mm-dd` / `yyyy年mm月dd日` 形式的日期） | 周历格子里的备注文字 |
| `rows[].cells[]` | 每格：`col`、`span`，`th`（表头格时），`text`（只有没有课程明细时才有，且仅限星期标签、节次标签 `1-2节`、周号 / 日号） | 其它自由文字 |
| `rows[].cells[].parts` | 课程明细 HTML：只保留最外层的文字（课程名）、`<br/>`，以及标题含 `周次` `节次` `教师` `老师` `教室` `地点` `课程` 的 `font` 的**可见**文字（标题原样写回，截 20 字） | 悬浮详情（`.item-box`）、`span` / `a` / `b` 等其它标签的文字、`hidden` / `aria-hidden` / `display:none` / `visibility:hidden` 的元素、`script` / `style`、标题不在白名单里的 `font`、输入框 |

`parse.js` 再把这些交给 CI 能跑的纯函数，只输出载荷（学期名、开学日、总周数、节次时间、课程、提醒）。

**浏览器冒烟里的断言：** 假站里的学号、姓名、身份证号、手机号、隐藏域的值、悬浮详情、标题为「学号」的 `font` 都放了进去，13 个场景里**一个都没有**出现在请求、`extract.js` 输出或载荷里。

### 周次 / 节次 / 课程名的解释（parse.js）

- 课程名：块里第一段带汉字的顶层文字；没有就取第一个 `font` 之前的文字行，再不行取无标题的 `font` 文字；都没有就计数并点名（「没认出课名」）。
- 教师：标题含「教师」或「老师」的 `font`，去掉「任课教师:」前缀；占位词（「未知」「待定」「暂无」「暂无教师」「暂无教室」「未知教师」「未知地点」，整串去掉空白后比对）或为空时 `teacher` = `null`。
- 教室：标题含「教室」或「地点」的 `font`，去掉末尾的 `[01-02]节`；占位词或为空时 `location` = `null`。
- 周次与节次：`font[title含"周次"]` 的文字，方括号之外是周次、方括号里是节次（`[01-02节]`、`[01-02节,05-06节]` 按逗号拆成多段，各自一条）。
  - 单双按**逗号分段各自判**：`(单)1-8周,(双)9-16周`、`(单)1-8周(双)9-16周`、`1-8周(单)9-16周(双)`、`(单)1-8周(双) 9-16周`、`(单)1-8周，(双)9-16周`、`(单)第1-8周` 都认；`1-8周(共8周),9-16周` 只剥「共 8 周」备注。
  - 区间终点前的「第」（`第1-第8周`）先删再认；`(1)`、`(1-2)` 是教学班序号，`(实验)` 是备注，都不当周次，各自计数并提醒。
  - 周次超出 1–30 的丢弃并计数。
- 节次超出 50 的整条跳过并计数；超出内置 12 节的按 H3 顺推（见 §7）。

## 5. allowHosts

`[]`。请求全部是当前页面同源的相对地址；`loginUrl` 的主机 `jwgl.fspt.edu.cn` 就是页面自己的主机，不需要进白名单。没有第二个主机，没有通配。
浏览器冒烟里假教务站跑在 `jwgl.fspt.edu.cn:443` 上，逐条断言每个请求的主机都是它、路径都在 `/jsxsd/` 之下。

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|

| 5 | 不埋点 | 通过 | 没有统计、上报或遥测代码。 |
| 6 | 不 eval 远程代码 | 通过 | 没有 `eval` 与 `new Function`；check.js 的词法扫描为 PASS。 |
| 7 | 不写页面 | 通过 | `safeHtmlOf` 遍历原节点读文字，不改、不克隆页面节点；解析用 `DOMParser` 离线文档；没有 `innerHTML` 赋值、表单提交、点击。 |
| 8 | 不依赖秘密 | 通过 | 没有硬编码的密钥、令牌、学号；学期代码来自课表页下拉框。 |

## 12. 已知风险与未验证项

我们没有本校账号，真机没验过；以下都是读上游代码与模板得出的结论。

1. **没有真实页面。** fixtures 与冒烟都是合成的。`#kbtable`、`div.kbcontent`、`font[title=…]`、`xnxq01id`、周历的 `td[title]` 这些名字来自上游代码，没在真实页面上核对。上游注释写的「强智 2020 前、数据位于 `id='kbtable'`」是它自己的说法。
2. **请求体照上游空值。** `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=…` 是上游代码原样的请求体，上游据说能用。若真实教务要求带页面上的非空隐藏域，POST 会被拒，本件会退到 GET（R3），GET 也可能不带课表。真实行为未验证。
3. **节次时间未经真机验证。** 12 节写死（§7）。学校调整作息后学生只能靠每次导入的提醒自己核对。
4. **根路径的登录页识别只看内容。** 根路径登录页地址里没有 `/login`，靠密码框、登录表单（含同源 iframe，跨域读不到则跳过）判断；框架内嵌登录页没有冒烟覆盖，只有代码路径。
5. **模板里的 `kbcontent1`。** 模板会读简表 `kbcontent1`，上游只读 `kbcontent`，本件只读 `kbcontent`（与上游一致）。若真实页面只有简表，课表会空（表现为「教务返回的课表是空的」）。
6. **白名单读不到的东西。** 悬浮详情 `.item-box`、不认识的标签（包括包着课名的 `span` / `b`）、标题不在白名单里的 `font` 一律不读；若本校的课程信息写在这些地方，会表现为「没认出课名 / 周次」之类的丢弃提醒，不会静默。
7. **课表备注里的课程不导入。** 「未排定时间的课程」只给一条提醒，学生要回教务核对、在空课里手动添加。
8. **会话过期。** 请求返回的登录页（有密码框）会报「登录状态已失效」（冒烟 `kicked`）；返回 200 而没有密码框、也没有课表的页面，会落到「没找到学年学期」或「课表是空的」。
9. **选定某一周。** 只认 `select#zc` 的选中值；若真实页面用别的控件选周，单周课表可能被当整学期用（没有提醒）。
10. **协议。** `loginUrl` 是 `https://`（上游 `import_url` 原样）。通过宿主 WebView 打开，不另做处理。
