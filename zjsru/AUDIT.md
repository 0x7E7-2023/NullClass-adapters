## 0. 平台与上游

上游 `resources/ZJSRU/adapters.yaml` 只有一份：`adapter_id: ZJSRU_01`，`maintainer: CagierAsh123`，
`import_url: http://xk.jwc.zjsru.edu.cn/`，说明写「登录方式为统一身份认证 CAS，教务首页会自动跳转；作息时间取自学校官方校历，
拱宸桥 / 杨汛桥两个校区节次时刻不同，导入时需选择所在校区；仅支持学生个人课表」。**没有第二个上游脚本可取舍。**

本校是正方教务 ASP.NET WebForms 版：课表页 `xskbcx.aspx` 返回服务端渲染的 `<table id="Table1" class="schedule">`，
一个格子里可能并排多门课、以 `<br>` 分行，行首标签形如 `周X第N节{周次}`，标签上一行是课名、下面依次是教师、教室。
学年学期是服务端控件 `select#xnd` / `select#xqd`；上游切换学期要带 `__VIEWSTATE` 用 `__EVENTTARGET` 回发。

选模板：任务卡指定 `jw-adapters/suda`（同为 `table#Table1.schedule` 结构的正方式页面，已审计）。只借解析骨架
（周次解析、极大段切分、提醒限长出口、H3 节次补全、缺教师 / 缺教室汇总），取数与课程切分按本校上游重写。

## 1. 请求清单（与代码逐条对应）

| # | 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|---|
| ① | GET | `<当前路径目录>/xskbcx.aspx?xh=<学号>&type=1`（没有学号时 `?type=1`） | 无 | 当前页不是课表页时，同源拉一次「学生个人课表」页，用 `DOMParser` 离线解析 | 响应非 2xx / 网络失败 → 报「没取到课表页，可能是登录状态已失效…」并结束（`extract.js:50`、`351`） |

发请求的完整条件：当前文档（含同源 iframe / frame）里没有 `table#Table1.schedule`，且不是登录页、不是非本校主机。
当前页就是课表页时**零请求**。地址基址是 `location.origin + location.pathname 去掉最后一段`（`extract.js:267`），
所以校内直连（`/xskbcx.aspx`）与 WebVPN 代理路径（`/https/webvpn<hash>/xskbcx.aspx`）都指向同一目录下的课表页。
学号只进这个请求的查询串（`extract.js:250` 起），不进输出、不进报错。

**没有**其它请求：不从教务切学期（上游的 `__VIEWSTATE` 回发表单整段删掉），不请求成绩 / 学籍 / 个人信息 / 缴费。

不发请求的情形（都在取数之前判断）：
- 页面里有密码框（统一身份认证登录页）或路径含 `login` / `/cas/` → 抛「当前打开的是登录页…」（`extract.js:75`、`81`、`339`）；
- 主机既不是 `xk.jwc.zjsru.edu.cn` 也不是 `webvpn*.zjsru.edu.cn` → 抛「当前页面不是浙江树人学院的教务系统…」（`extract.js:69`、`340`）；
- 当前页就是课表页、但页面标题写「教师…课表」→ 抛「当前打开的是教师课表…」（`extract.js:91`、`345`）。

提问桥：最多一次 `__ncSelect`（`extract.js:298`）。只有课表文字里**同时**没有 / 同时出现两个校区名、判断不了校区时才会问；
桥不在、用户取消、桥报错都按拱宸桥校区继续，由 `parse.js` 在提醒里说明（`extract.js:316`）。

## 2. 读了什么、交出去什么（逐字段）

`extract.js` 交给 `parse.js` 的对象（`JSON.stringify` 后的字符串，`extract.js:327`）：

| 字段 | 内容 | 来源 |
|---|---|---|
| `today` | 提取当天日期（本地日期，不用 `toISOString`） | 本机时钟（`extract.js:62`） |
| `term.year` | 学年下拉框值里的 4 位年份 | `select#xnd` 选中项 `value`（`extract.js:233`） |
| `term.semester` | `1` / `2` / `3`（第 3 学期是短学期） | `select#xqd` 选中项 `value`，只认这三个值 |
| `term.yearLabel` / `term.semesterLabel` | 两个下拉框选中项的文字（如「2026-2027」「第一学期」） | `option.textContent` |
| `campus.key` / `campus.label` | `gongchenqiao` / `yangxunqiao` 与「拱宸桥校区」/「杨汛桥校区」 | 课表文字判断、用户选择，或默认拱宸桥（`extract.js:288`–`322`） |
| `campus.source` | `page` / `user` / `default` | 上面三条路径各一个值，`parse.js` 据此写提醒 |
| `cells[][]` | 每个 `<td>` 的可见文字行（按 `<br>` 分行，空行不占位，每行 ≤120 字、每格 ≤60 行） | 课表表格（`extract.js:190`、`203`） |

取数规则：从每个 `<td>` 起逐个子节点取**看得见**的文字 —— `<br>` 换成换行；`hidden` 属性、`display:none`、
`visibility:hidden`（内联或计算后）的元素整棵子树跳过，`script` / `style` / `noscript` 不读；
当前活动文档里还会看 `getClientRects()` 是否为空（祖先被隐藏）——`DOMParser` 拉回来的离线文档不排版，量出来永远为空，
所以那里**不量**（`extract.js:176`）。表格以外的页面文字（姓名、学号、菜单、格子里藏的个人信息）都进不了输出：
冒烟 `hidden-cell` 往格子里塞了学号 / 姓名 / 身份证号 / 手机号（隐藏 `<span>`、隐藏 `<a>`、隐藏 `<div>`、隐藏 `<td>` 四种），
输出与载荷里都找不到。

`parse.js` 是纯函数：不碰网络、不碰页面，输出载荷里的教师名只是课表本来就显示的任课教师。

## 4. 给学生看的文字

`extract.js` 的报错与 `parse.js` 的 warnings 都按 `docs/ux-writing.md` 写：不出现「接口」「载荷」「上游」「脚本」「字段」「JSON」「HTML」
「null」「学期设置」「作息表」；时间表统一叫「节次时间」；改学期名、开学日、总周数、节次时间指向「学期管理」，改教师 / 教室指向「编辑课程」。
带课名的提醒（缺教师 / 缺教室）课名截到 20 字、最多点名 3 门；认不出的行原文同样截 20 字；每条都经过 `warn()`（`parse.js:184`）
再截到 200 字以内。fixture `long-warnings` 钉住这一点（长课名 + 3 门缺项 + 3 行跳过，实际最长提醒 105 字）。

提醒清单（顺序固定）：① 学期来源（取自页面下拉框 / 按今天的日期推算）；② 开学日是推算的（上游明确不给）；
③ 校区与节次时间（按哪套表、是不是没确认）；④ 总周数（教务不给，按 max(最晚周次, 20) 导入）；
⑤ 表外节次的补齐（空课默认 / 顺推 / 补不了）；⑥ 被跳过的行（缺课名 / 节次 / 周次，分类计数 + 认不出的行原文）；
⑦ 缺教师 / 缺教室汇总；⑧ 不相邻节次按首末节之间的范围导入；⑨ 周次里的序号括号 / 备注括号 / 越界周次 / 孤立单双标记 / 单双同写。

## 5. 与模板（suda）的差异

借的是解析骨架：周次解析 `weeksOf`（前缀 / 后缀单双标记归属、「第1-第8周」、「共 N 周」只剥备注、序号 / 备注括号、全角标点）、
`runsOf`、提醒限长出口 `warn`、H3 节次补全、缺教师 / 缺教室汇总。取数层与课程切分按本校上游重写：

1. **取数可以是零请求，也可以是一次同源 GET**（§1）：当前页是课表页就直接读；否则按当前路径推导基址拉 `xskbcx.aspx`。
   suda 永远零请求。
2. **按格子交原始文字行**，不是 suda 的「每个 `<a>` 前四行」：本校一格可并排多门课，切分放到 `parse.js`
   （锚点行 `parse.js:102`、`parseAnchor` `parse.js:336`、逐格循环 `parse.js:397`）。
3. **学期**：本校有 `1` / `2` / `3`（第 3 学期是短学期）三个值，学期名取 `select#xnd` / `select#xqd` 的文字；
   suda 只有 1 / 2。上游切学期要回发，这里只导当前选中的学期。
4. **校区与两套节次表**：拱宸桥 / 杨汛桥各 12 节（`parse.js:44`），杨汛桥不设第 5 节、上游虚拟 11:35–12:15 占位，
   保证教务返回的「下午第一节 = 第六节」仍落在 6 号上；suda 只有一张表。校区判断顺序：课表文字 → `__ncSelect` → 拱宸桥。
5. **开学日**：上游明确不给（`semesterStartDate: null`）。这里按第一学期 9 月 1 日 / 第二学期次年 3 月 2 日 /
   第 3 学期（短）次年 7 月 1 日所在周的周一推算（`parse.js:568`），并每次都写提醒。suda 只有前两个锚点。
6. **总周数**：上游 `max(18, 课表最晚周)`；这里按公共口径 `max(课表最晚周, 20)`，最多 30（`parse.js:589`）。18 周下限被 20 覆盖。
7. **去重**：先按原始字段去重再计数，完全相同的行只留一条（`parse.js:444`）；上游的第二步「同课同节不同周并成一条」没有照搬，
   这里按「同名 + 教师 + 地点 + 星期 + 周次」分组后相邻合并，不同周次落成两个 block，语义等价。
8. `getClientRects` 只在当前活动文档里量（`extract.js:176`）——suda 零请求，量不量都在活动文档里；本校会解析离线文档，必须区分。

## 6. 上游里删掉 / 改掉的东西及理由

| 上游 | 处理 | 理由 |
|---|---|---|
| `showAlert` 确认框、`showToast` 进度条、`showSingleSelection` 选学期 / 校区、`saveImportedCourses` / `savePresetTimeSlots` / `saveCourseConfig` / `notifyTaskCompletion` | 去掉 | 拾光的桥能力；空课由宿主保存，适配器只交数据 |
| 选学期后带 `__VIEWSTATE` 用 `__EVENTTARGET` 回发切学期 | 去掉 | 公共说明第 2 条：不弹窗问学期，读教务给的当前学期；也避免替用户改页面状态 |
| 必问校区、取消就中止导入 | 先看课表文字能否判断，判断不了才问一次；取消 / 桥不在按拱宸桥继续并提醒 | 少打扰一次；找不到答案时也不让导入失败，但必须说实话 |
| `semesterStartDate: null`，要求用户自己设 | 按学期锚点所在周的周一推算，并提醒 | 手册 §4.2 / §4.3：`firstDay` 必填，推算值必须说出来 |
| `semesterTotalWeeks = max(18, maxWeek)` | `max(课表最晚周, 20)`，最多 30，抬高时提醒 | 公共说明第 7 条：没有校历就按 20 周 |
| 教师 / 教室为空串时原样保存 | 空串和「未知」「暂无」「待定」一律交 null，并按类型汇总提醒 | 手册 §4.7：写「未知」会被当成人名显示；缺项不许静默 |
| `zjsruCellLines` 用 `innerHTML` 转文本（隐藏元素、格子里的一切文字都会出去） | 逐节点取看得见的文字，隐藏元素整棵跳过，每行截 120 字 | 公共说明第 3 条：个人信息包括藏在格子里的，一律不带出 |
| 正则 `^周X第N节(?:{…})?$` 要求整行完全匹配，没有花括号就丢掉这门课 | 允许锚点行后面带周次文字，`节` 后面的部分交给 `weeksOf` | 公共说明「周次用模板强解析兜底」；不许静默丢课 |
| 节次 `Math.min / Math.max` 静默取首末节 | 保留首末节，但不相邻时提醒 | 不许静默猜节次 |
| 表外节次（>12 节）没有处理 | 按批次五统一修订 H3 逐节补齐并提醒 | 载荷要求节次时间连续 |
| `const` / `let` / 箭头函数 / `new Set` / `Array.from` / `...` 展开 / 模板串 / `for...of` | 全部改成 ES5 | 旧 WebView 与 Rhino（Rhino 也不支持 async/await） |
| `console.log` / `console.error` | 不移植 | 不埋点、也不往控制台留数据 |

新增（上游没有）的：登录页 / 非本校主机 / 教师课表的判断、校区自动判断、缺教师 / 缺教室汇总、跳过行的分类计数、
提醒限长、H3 表外节次补齐、iframes 一层嵌套 / frame 帧支持、花括号外的周次兜底。

## 9. 已知风险与未验证项（我们没有本校账号，真机没验过）

1. **页面结构全部来自上游脚本，没有在浙江树人学院真机验证**：表格选择器 `table#Table1.schedule`、`<br>` 分行、

2. **开学日是推算的**：第一学期 9 月 1 日、第二学期 3 月 2 日、第 3 学期（短）7 月 1 日，各回退到那一周的周一。

3. **总周数**：教务不给，按 `max(课表最晚周, 20)`；上游的 18 周下限被 20 覆盖。短学期也按 20 周导入，可能偏大。
4. **校区判断是启发式**：只看课表文字里出现「拱宸桥」/「杨汛桥」的唯一一方；教室名里不带校区就判断不了，会问一次。
   用户取消或没有提问桥时按拱宸桥导入，提醒里会说明。
5. **节次时间表无法核对**：两套 12 节逐节照抄上游（来源是学校官方校历），没有校历原文可对照。杨汛桥第 5 节是上游虚拟的占位，

6. **`allowHosts` 只声明了 `xk.jwc.zjsru.edu.cn`**（主调度已定）。经学校 WebVPN 打开时，请求打在 `webvpn*.zjsru.edu.cn` 上，

7. **教师课表的判断靠页面标题**（标题含「教师…课表」且不含「学生」）。上游没有这条判断；标题改版会落到按普通课表解析。
8. **登录页判断是启发式**：密码框、路径含 `login` / `/cas/`。不在这些形态里的登录页会走到「没有找到课表」。
