审计对象：`jw-adapters/cjlu/` 下的 `extract.js` / `parse.js` / `manifest.json`，以及它们移植自的上游脚本
`shiguang_warehouse` 的 `CJLU/cjlu.js`（快照 commit `e15c6274ac347c9642da890504651a9b4e374391`，2026-10-26 拉取，MIT；
adapters.yaml 维护者 `salt-fishes, ying-ck`，注释写明「原适配脚本作者 ying-ck；本适配由 salt-fishes 按正方教务 v9 规范重构」；

## 0. 出处、平台与模板

- 上游 `CJLU/cjlu.js`：正方新版 UI（zftal-ui-v5），部署在根路径 `/xtgl/`（没有 `/jwglxt/` 上下文）；数据全部走接口，不读页面 DOM；
  三个数据接口都是 POST + 表单体（课表 `xskbcx_cxXsgrkb`、校历 `xskbcxZccx_cxZcByXnxq`、节次时间 `skxxMobile_cxRsdjc`），
  只取课表里出现的**第一个**校区的节次时间；弹窗选学年学期；课表里有节次不在节次表里的课整门跳过；保存课程 / 节次 / 学期配置三步。
- 模板选 `zust`（批次十七，正方新版，同样的三个接口、同样的校历 + 按校区取节次时间 + H3 补节次 + 去重合并 + 提醒限长），
  而不是 `hueb` / `jsei`：`zust` 是更新的吸收了批次七至十六全部审计修正的版本，且接口路径与上游完全一致，改动面最小。
  周次解析、`(单)/(双)` 归属、「共 N 周」只剥备注、「第1-第8周」都沿用 `zust`（其前身 `jsei` / `hueb` 已修的坑没有改坏，fixtures `weeks-forms` 钉住）。
- 同批的 `hebeu`（河北工程大学）上游与本校结构几乎相同，由另一位同事移植，互不读对方目录。

## 1. 请求清单（与 `extract.js` 逐条对应）

模块根 `jwBase()` = 当前地址里最早出现的 `/xtgl/`、`/kbcx/`、`/jzgl/` 之前的部分（照上游 `getBaseUrl`；冒烟里 `/jwglxt/...` 子路径也能拼对），
没有就是站点根。主机一律由 `window.location.origin` 拼，不写死绝对地址。全部 `credentials: 'include'`，头只带 `X-Requested-With` 与 `Accept`（POST 再带 `Content-Type`）。

| 方法 | 地址 | 干什么 | 取不到时 |
|---|---|---|---|
| GET | `<根>/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151&layout=default` | 读 `#xnm` / `#xqm`（**页面上已有这两个字段时跳过**） | 报错，提示重新登录并打开「个人课表查询」 |
| POST | `<根>/kbcx/xskbcx_cxXsgrkb.html?gnmkdm=N2151`，表单 `xnm xqm kzlx=ck xsdm= kclbdm= kclxdm=` | 取整学期课表（排课行 `kbList`、实践课 `sjkList`） | 报错 |
| POST | `<根>/kbcx/xskbcxZccx_cxZcByXnxq.html?gnmkdm=N2154`，表单 `xnm xqm` | 学期校历（开学日、总周数） | 交 `null`，`parse.js` 推算开学日、总周数按 20 并说明 |
| POST | `<根>/jzgl/skxxMobile_cxRsdjc.html?gnmkdm=N2154`，表单 `xnm xqm [xqh_id]` | 每个出现过的校区各取一次节次时间（最多 6 个）；课表里一个校区号都没有时不带 `xqh_id` 取一次 | 该校区交 `null`；基础校区取不到则整张用上游写死的 12 节兜底表并说明 |

与上游一致：路径、方法（课表首页 GET，其余 POST）、表单参数与顺序、菜单号（课表 `N2151`、校历与节次时间 `N2154`）逐字照抄上游 `requestHaue` / `runImportFlow`；
登录过期判断照上游：响应不是 JSON 且正文含 `login_slogin` / `用户登录` / `统一身份认证` → 报「登录已过期，请重新登录教务系统」，
另外响应地址含 `authserver/`、`login_slogin` 或页面标题以「统一身份认证」开头也算（`looksLikeLogin`）。
不同：上游每次先取课表首页给弹窗用，这里页面上读得到就不取；校历与节次时间失败时上游把原因写进弹窗提醒并回落兜底节次，这里降级成交 `null`，说明由 `parse.js` 给；
上游只取第一个校区的节次时间，这里每个校区各取一次（见第 4 节）。

入口判断：`loginUrl` = 上游 `import_url`（`https://jwxt.cjlu.edu.cn/xtgl/login_slogin.html`，经统一认证 `authserver.cjlu.edu.cn` 登录后回到教务）；`allowHosts` = `[]`（所有请求都与 `loginUrl` 同源）。
`extract.js` 在以下情形直接报大白话提示、**不发任何请求**（冒烟 `loginpage` / `sso` / `auth` / `site` 覆盖）：
当前主机不是 `jwxt.cjlu.edu.cn`（统一认证页、学校官网等）；当前路径含 `login_slogin.html`（教务登录页）或 `/sso/`（单点登录跳转页）。

**上游 `cjlu.edu.cn$` 主机名判断的处理**：上游只检查主机名以 `cjlu.edu.cn` 结尾，统一认证页也会放行（然后在统一认证页上发请求、必然失败）。
这里按白名单口径收紧为主机正好是教务 `jwxt.cjlu.edu.cn`（与 `loginUrl` 同源）；其它主机给「当前页面还不是教务系统」的提示。
因为请求全部同源且不发往任何其它主机，`allowHosts` 不需要声明额外域名。

## 3. 移植手册 §5 八条逐条结论

1. **不碰凭据**：不读不存不发账号密码；统一认证登录全程由用户在 WebView 里手工完成，只用已登录的会话（`credentials: 'include'`），不读 Cookie。通过。
2. **不外发**：全部请求同源（`window.location.origin`），`extract.js` 里没有任何写死的绝对地址，`allowHosts` 为空。通过。
3. **只读课表**：只请求课表首页、课表、校历、节次时间四类，不碰成绩 / 学籍 / 个人信息。POST 只是正方接口的取数约定（表单里全是学年学期与固定筛选值），不提交任何修改。通过。
4. **字段白名单**：见第 2 节。通过。
5. **不埋点**：无 `sendBeacon` / `WebSocket` / `Image` 上报。通过。
6. **不动态执行**：无 `eval` / `new Function`。通过。
7. **不写页面、不提交表单**：只读 `#xnm` / `#xqm`，首页用离线 `DOMParser` 解析，不插入当前页面，不触发页面表单。通过。
8. **不硬编码秘密**：无任何账号、学号、令牌；写死的只有上游的节次兜底表与菜单号。通过。

## 4. 与模板 `zust` 的差异

- 入口：主机固定 `jwxt.cjlu.edu.cn`，根路径部署（`jwBase` 用上游的三个模块目录标记，不是 `/jwglxt`）；没有 WebVPN 入口；登录页 / 单点登录跳转页 / 其它主机都不发请求。
- 请求：三个数据接口 POST + 表单体（模板全 GET + 查询串），菜单号在查询串；课表表单字段与顺序照上游。
- 登录过期判断多一条：JSON 接口回的不是 JSON 且正文有登录页字样（上游同样）。
- 不做学期回显核对（模板的 `xsxx` 比对）：上游没有读 `xsxx`，不加一条会误报的检查。
- 校区：上游只取第一个校区的节次时间；这里沿用模板的「每校区各取一次、课数最多的作基础、其它校区不同要提醒」，课表里一个校区号都没有时照上游不带 `xqh_id` 取一次（`campusId` 交空串，`parse.js` 里键就是 `c`）。
  这是比上游宽的做法，多出的请求只可能多取节次时间；若真实教务只有一个校区，行为与上游一致。
- 上课地点：上游 `position` 只取教室名 `cdmc`，这里同样不加校区名（模板按校区名拼「校区名 教室」）；缺教室 = `cdmc` 为空。合并键仍含校区号（上游不含，更保守，只会少合并不会错合并）。
- 节次兜底：模板用空课内置 12 节，这里换成上游写死的 `CJLU_FALLBACK_TIME_SLOTS` 12 节（逐节对照上游抄：
  08:00-08:45、08:50-09:35、09:55-10:40、10:45-11:30、11:35-12:20、13:30-14:15、14:20-15:05、15:15-16:00、16:05-16:50、18:00-18:45、18:50-19:35、19:40-20:25）；
  提醒措辞写「学校常用的节次时间」。上游对超出节次表的课整门跳过，这里按 H3 补并说明（fixtures `multi-campus` / `fallback`）。
- 校历：总周数照上游只认「周次连续（1..N 不缺不重）且最大周次在 10-60」的校历（模板不查连续与下限，`calendar-gap` 钉住）；周次读 `zs`，没有再读 `zsmc`，且接受「第3周」写法；
  日期字段取 `rq` / `zcrq` / `ksrq` 第一个认得出的（上游同样三个，模板多认一个 `zrq`，这里去掉）；超过 30 周钳到 30（载荷限制）。
- 节次字段读 `jcs`，没有再读 `jc`（上游 `row.jcs || row.jc`）。
- 学期名：学期下拉框文字多是 1 / 2 / 3，代码 3 / 12 / 16；认不出时用「中国计量大学 第 X 学期」。

## 5. 上游里被删掉 / 改掉的东西及理由

- **选学期弹窗**（`selectAcademicYearAndSemester`，含 `window.xnm` / URL 参数 / 选中项三级默认）：改为读页面当前学期（移植手册 §3）；URL 参数那一级不移植（课表页是 ajax 加载，地址里没有这两个参数）。
- **严格校验后整行跳过 / 整次报错**：周次认不出、节次异常、缺课名等，上游只在确认弹窗里写「跳过课程 X」；这里计数进「数据不全」提醒，不静默丢课。
- **节次不在节次表里整门课跳过**：改为 H3 补并提醒（见第 4 节）。
- **课表周次超过校历总周数**：上游放弃保存总周数；这里抬高总周数并说明（`calendar-raise`）。
- **实践课（`sjkList`）**：上游列在确认弹窗里（含 `qsjsz`）；这里只取课名，按模板写进提醒让学生自己添加。
- **保存桥调用、确认弹窗、`notifyTaskCompletion`、`showToast`**：「拾光」的桥能力，空课由宿主保存，适配器只交数据。
- **学期配置 `firstDayOfWeek: 1`**：空课每周起始日按载荷默认处理，不写。
- 上游 `mergeAndDistinctCourses`（含 `localeCompare` 排序）：由模板的去重 + 两阶段合并代替，语义对齐、不改任何一周的安排。
