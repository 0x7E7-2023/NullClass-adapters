## 2. 上游分析与请求清单

上游是一个自执行脚本：按页面地址判断是个人课表还是班级课表，不在支持页面时弹窗问「班级课表 / 个人课表」并按菜单号
`N214505` / `N253508` 点击跳转；读到课程后用拾光桥保存，并把写死的 11 节节次时间一并保存。

移植后**一个网络请求都不发**：

| 方法 | 地址 | 用途 | 取不到时 |
|---|---|---|---|
| —— | —— | 无任何 fetch / XHR / sendBeacon / WebSocket / 图片打点 | 不适用 |

- 读的是**当前页面已有的 DOM**：个人课表 `#innerContainer #table1 div.timetable_con`，
  班级课表 `#table1.tab-pane>.timetable1 div.timetable_con`，以及页面顶部的 `#xnm` / `#xqm`。
- 页面判断按**路径**（不写死协议与主机，网关前缀也能命中）：
  `/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html` → 个人课表；`/jwglxt/kbdy/bjkbdy_cxBjkbdyIndex.html` → 班级课表。
- 登录页判断：主机 `sso.ujn.edu.cn`、路径含 `login`、路径含 `/sso/`。这三种以及任何其它页面都在发请求前报错，
  零请求、不弹提问桥（宿主没有点击菜单的能力）。
- `allowHosts` 按任务卡写 `["jwgl.ujn.edu.cn"]`：本件脚本自身不发请求，这一项声明的是课表主机本身（登录跳转、宿主下载课表图
  与桥注入都按它约束），不是脚本的请求出口。`loginUrl` 用主调度给定的 SSO 地址，同源规则覆盖 `sso.ujn.edu.cn`。
- `scheduleUrlHint` 是个人课表页完整地址（一键刷新优先打开）；班级课表同样支持，只是不在一键刷新里。

## 3. 读取与交出字段

| 数据 | 交出的白名单 | 用途 |
|---|---|---|
| 页面地址 | `page`（`personal` / `class`） | 决定取哪几段表格文字、班级课表缺周次时是否按 1-20 周 |
| 学年 / 学期下拉框 | `xnm` / `xqm` / `xnmText` / `xqmText` | 学期名、开学日锚点 |
| 每个课表格子 | `name` / `weeks` / `location` / `teacher` | 课名、周次原文、教室原文、教师原文 |
| 每个课表格子 | `row` / `col` / `rowSpan` / `colSpan` | 换算星期与节次 |
| 本地日期 | `today`（仅 `yyyy-MM-dd`） | 没有学年时推算周一 |

- 个人课表：`.title` 取课名，三个 `p` 的**最后一个元素**依次是周次、教室、教师（照上游）。
  班级课表：`.title` 取课名，`p[2] / p[3] / p[4]` 中「标签元素后面紧跟的那段文字」依次是周次、教室、教师（照上游）；
  只有一个 `p`（没有明细）的格子把周次交成空串。
- **不交出**：学号、姓名、身份证号、手机号，以及表格外的提示文字、页面脚本里的 `xsxx`、浮层内容。`extract.js` 只遍历上面两个
  选择器命中的格子，并从 `#xnm/#xqm` 取两个值，其余 DOM 一概不读。冒烟用的假页面里埋了「学生某 / 2026000001 /
  110101200001011234 / 13800000000」四样，实测均未出现在交出的内容里。
- `parse.js` 是纯函数：不碰 DOM、不发请求、不读写存储、不调用桥。

## 4. 节次时间与解析边界

上游写死的 11 节逐节照抄（第 11 节上游本身就是 55 分钟，未擅自改成 45 分钟）：

| 节 | 时间 | 节 | 时间 | 节 | 时间 |
|---|---|---|---|---|---|
| 1 | 08:00-08:50 | 5 | 14:00-14:50 | 9 | 19:00-19:50 |
| 2 | 08:55-09:45 | 6 | 14:55-15:45 | 10 | 19:55-20:45 |
| 3 | 10:15-11:05 | 7 | 16:15-17:05 | 11 | 20:50-21:45 |
| 4 | 11:10-12:00 | 8 | 17:10-18:00 | | |

- 表外节次按 H3：上一节下课后课间 5 分钟、每节 45 分钟顺推（第 12 节 21:50-22:35、第 13 节 22:40-23:25）；
  顺推到越过 23:59 的节次（第 14 节起）不补时间，课程照常导入并说明。
- 星期与节次由格子几何换算（上游算法逐行照搬）：`startPeriod = row - 1`、`endPeriod = row + rowSpan - 2`、
  `dayOfWeek = col - 1 + offset`，其中 `offset` 按 `(row - 2) % 4`：余 0 的行前面多一个「上午 / 下午 / 晚上」侧栏标签，取 0；
  余 2 的行取 1。**上游对余 1、余 3 的行没有返回值**，会算出空星期（教务把课排在偶数节开始时就会踩到），
  这里按「没有侧栏标签」回退成 1，并汇总一条提醒说明有几门课的星期是按位置推算的。
  这类提醒（含下面的「没写周次」）都按**门课**（课名 + 教师去重）计数，不按格子：同一门课占两三个格子时，
  提醒里的门数必须与真正导入的课数一致。
- 周次：先整段剥掉「(1-2节)」「（3-4节）」这类节次括号（不当成周次备注），再按多段、前后置单双、**无逗号前置单双**
  「(单)1-8周(双)9-16周」、「第1-第8周」、「共 N 周」只剥备注本身、全角数字与全角括号解析。
  归一化后每段只允许数字、区间符、空白与单双标记；含其它文字的段不从里面猜数字，整行跳过并汇总提醒。
- 教师后面括号里的「外聘」「研究生」「主讲」是备注，剥掉不进教师名；「未知」「待定」「暂无」「暂无教师」「暂无教室」「无」写为
  `null`，课程照常导入并按类型汇总提醒（写的是在「编辑课程」里补）。
- 班级课表里没写周次的格子按第 1-20 周导入（上游行为），并汇总提醒（按门课计数），不静默。
- 学期名取教务页面的学年 + 学期（「2026-2027学年第一学期」）；读不到时用「济南大学 课表」并提醒。
  **开学日**：教务课表页没有这个来源，任务卡原写「null」，但载荷校验要求 `firstDay` 必须是 `yyyy-MM-dd`，因此与模板同口径按
  锚点推算（第一学期 = 9 月 1 日所在周的周一，第二学期 = 次年 2 月 20 日所在周的周一，夏季学期 = 7 月 1 日所在周的周一；
  没有学年时退回「今天的周一」），并在提醒里写明推算依据、请用户在学期管理里核对。总周数用 20，课表更晚才抬高并提醒。
- 完全重复的格子按八个白名单字段先去重，再解析、再计数；相邻或重叠节次吸收（`<= end + 1`），同节次取周次并集。
- 所有提醒走同一个出口：教务原文（课名、周次原文、学期名）先截到 20 字，整条 ≤200 字，最多 20 条，超出时最后一条说明还有几条未显示。

## 5. 与 gxcme 模板的主要差异

1. **取数方式**：模板请求 Mobile 课表与校历接口；本件零请求，读已渲染的课表表格，星期 / 节次由格子行列换算。
2. **学年学期**：模板优先读页面 `#xnm/#xqm`、读不到再 GET 首页；本件只读当前页，读不到就把学期名与开学日退到保守值并提醒，
   不发任何请求（多一条请求就多一条审计面，而这里并不需要）。
3. **入口与不支持页面**：模板只判断登录页与门户页；本件另按路径只认两种课表页，其余页面直接给大白话提示（上游那套
   「弹窗问 + 点菜单跳转」整段删除）。
4. **周次来源**：模板解析 `zcd` 字段；本件解析格子里 `p` 的文字，并多一道「先剥节次括号」。
5. **节次表与缺口**：模板 14 节（08:10 起），本件 11 节（08:00 起，第 11 节 55 分钟）；H3 顺推参数与提醒口径沿用模板。
6. **没有**模板里的校历接口、记录数对账、集中实践课名单、校区号、GateWay 前缀拼装 —— 上游 UJN 没有这些，也不该凭空加请求。

## 6. 上游删除或修正的内容

- 删除拾光桥的全部调用：`showSingleSelection` 选「班级课表 / 个人课表」、`clickMenu`（`N214505` / `N253508`）跳转、
  `showToast`、`saveImportedCourses`、`savePresetTimeSlots`、`notifyTaskCompletion`。宿主负责保存与提示。
- 删除 `CourseModel` / `CustomTimeModel` 的结构体写法（上游是 class + 箭头函数 + 展开运算符，ES5 与 Rhino 都不吃），
  字段语义改由 `parse.js` 的载荷结构表达；上游 `isCustomTime` / `customStartTime` 本校用不到，不搬。
- 上游缺教师或教室时字段留空串、周次解析为空会静默变成没有上课安排的课程；这里改为 `null` + 汇总提醒，不丢课。
- 上游 `parseWeekText` 把「(单)」这类前置标记整段忽略（`1-8周(单)` 读对，`(单)1-8周` 读错，退化成每周都上）；
  这里用模板的强解析，两种写法都有用例钉住。
- 上游 `offsetColByRow` 对两类行号返回空值（NaN 星期）；这里回退成「没有侧栏标签」并提醒。
- 上游把表格文字交给拾光桥时是整份 `CourseModel`；这里按白名单挑字段，学生信息一律不出页面。

## 10. 已知风险与未验证项

- **没有本校账号**，未访问真实 SSO、门户与教务页面，未做真机验证；`loginUrl`、`scheduleUrlHint`、`allowHosts` 均来自任务卡的
  主调度给定值，没有实测跳转链。
- **表格几何是推断出来的**：上游只给了 `row - 1` / `row + rowSpan - 2` / `col - 1 + offsetColByRow(row)` 这三个算式与
  `(row - 2) % 4` 的分支，没有页面样本。本件按「两行表头 + 上午 / 下午 / 晚上侧栏 `rowspan` 四个节次」的结构自洽验证
  （假站与 fixtures 按这个结构造），**真页若表头行数或侧栏跨行不同，星期 / 节次会整体偏移**，第一次真机导入必须核对。
- 上游对余 1、余 3 的行没有值（会算出空星期）。本件回退成「没有侧栏标签」并提醒，但这是推断，不是实证；教务若把课排在偶数节
  开始，这几门课的星期需要用户核对（提醒里已说）。
- 班级课表的 `p` 顺序按上游索引（`p[2]/p[3]/p[4]`）；只有一个 `p` 的格子按 1-20 周是上游行为，教务改版后需按真实页面调整。
- 11 节时间来自上游写死值，未与学校当前公布时间核对（导入预览始终提示核对）。
- 没有学年学期下拉框时，学期名退成「济南大学 课表」、开学日退成学期锚点推算，都靠提醒兜底。
- fixtures 是按上游形状编造的，只能证明转换逻辑与防回归能力，不能证明真实页面结构完全相符。
- 未运行 Gradle（任务禁止）；验证只用指定的 `check.js`（Rhino 1.8.0）与本地假站。
