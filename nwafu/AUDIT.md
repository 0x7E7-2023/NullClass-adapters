## 0. 通读结论与模板选择

模板用同平台已审的 `sany`（金智 jwapp / wdkb 接口式），并参考同平台 `dlutci` 的会话与 403 结论、`jlu` / `njnu` 的 wdkb 取数写法。选 `sany` 的依据是：两者都是「同源 POST → `datas.<action>.rows` → 结构化字段直接映射」的 jwapp 形状，转换层（周次切段、占位词、提醒限长、节次顺推、字段缺失计数）可以整段复用；而取数层、周次来源、学期选择、节次表、连堂语义都不同，按本校上游重写。

与模板不同构的地方：

1. **应用代码与路径**：本校是 `wdkbby`（我的本研课表），上游把模块名与 action 名写死；`sany` 是 `wdkb`。路径统一 `rootPath() + '/sys/wdkbby' + module`，`rootPath()` 优先读页面上的 `_JW_INIT_CONFIG`（path / ROOT_PATH / contextPath），取不到用 `/jwapp`；请求一律相对地址，始终同源。
2. **学期**：上游先取学期列表、再取当前学期，然后弹窗让用户单选。移植不弹窗：先问 `dqxnxq.do` 当前学年学期；取不到才问 `xnxqcx.do`（`*order=-DM`）并取排好序的第一条，由 `parse.js` 明确提醒。
3. **周次**：上游先读 `SKZC` 位串、失败再读 `ZCMC` 文字。移植按任务卡改为 **`ZCMC` 文字优先、位串兜底**：`extract.js` 只把 `SKZC` 按位展开成周号数组，全部文字解析（多段并集、单双标记前置/后置）放在 `parse.js`。
4. **校历**：本校校历是 `xskcb/cxxljc.do`（`XN`/`XQ` → `XQKSRQ`/`ZZC`），不是 `sany` 的 `cxjcs.do`。
5. **节次**：上游写死冬令/夏令两套 11 节表并按日期生成两段「作息」；空课载荷只有一个 `periodTimes`，移植按今天日期选一套（05-01 至 09-30 夏令，否则冬令）并提醒。
6. **连堂**：上游 `mergeAndDistinctCourses` 会把同课、同教师、同地点、同星期、同周次且下一节正好接着的记录合成一段；`sany` 保持两段。本校按上游合并，差别见 §4。

## 1. 请求清单（与代码一致）

所有请求都在 `extract.js` 的 `post()` 里：`POST` + `credentials: 'same-origin'`，头固定为 `Accept`、`Content-Type: application/x-www-form-urlencoded; charset=UTF-8`、`X-Requested-With: XMLHttpRequest`；**不发 `Authorization`**（上游也不用令牌，只靠浏览器同源 Cookie）。请求之间用 `pause(300ms)` 留间隔。

| 谁 | 方法 | 地址（均相对当前页面同源） | 干什么 | 取不到时 |
|---|---|---|---|---|
| `loadTerm()` | POST | `<root>/sys/wdkbby/modules/jshkcb/dqxnxq.do`，空正文 | 当前学年学期：`DM`、`MC` | 403 / 非 2xx / 非 JSON / 连不上 / 响应含 `loginURL` 时直接报错，不再重试；其他失败（缺行、缺 `DM`）转下一条 |
| `loadTerm()` 回落 | POST | `<root>/sys/wdkbby/modules/jshkcb/xnxqcx.do`，正文 `*order=-DM` | 学期列表，按 `DM` 降序取第一条 | 列表失败则抛回第一次的错误；`selection` 记为 `list`，由 `parse.js` 提醒核对学年学期 |
| `loadCourses()` | POST | `<root>/sys/wdkbby/modules/xskcb/cxxszhxqkb.do`，正文 `XNXQDM=<DM>` | 个人课表行（`datas.cxxszhxqkb.rows`） | 缺 `rows`、非 2xx、非 JSON、含 `loginURL` 均整次报错（见下）；空数组交给 `parse.js` 报「没有解析到任何课程」 |
| `loadCalendar()` | POST | `<root>/sys/wdkbby/modules/xskcb/cxxljc.do`，正文 `XN=<学年>&XQ=<学期>` | 校历：开学日 `XQKSRQ`、总周数 `ZZC`（`datas.cxxljc.rows[0]`） | 任何失败都吞掉返回 `null`，课程照常导入，`parse.js` 提醒并推算 |

`<root>` 见 §0 第 1 条。`<学年>-<学期>` 由 `DM`（如 `2026-2027-1`）拆出；`DM` 拆不开时不发校历请求。

**不请求**上游的 `jshkcb/cxjcs.do`：它只返回上午/下午/晚上的节数（`SFJJ`/`XFJJ`/`WSJJ`），没有上下课时间，上游自己也只用来打日志。任务卡写的「优先用 cxjcs 给的节次时间」在本校数据上不成立，见 §11。

错误提示（学生可见，原样在 WebView 里抛给宿主）：

- 403：`教务系统拒绝访问：请先在新门户里打开「我的本研课表」，看到个人课表后再回来导入`
- 其他非 2xx：`教务系统返回错误（代码 N）：登录状态可能已失效，请重新登录后再试`
- 非 JSON：`教务系统没有返回可读取的数据：登录状态可能已失效，请重新登录后再试`
- 网络失败：`连不上教务系统：请确认已登录并打开「我的本研课表」，再点「提取课表」`
- 响应含 `loginURL`：`登录状态已失效：请重新登录后打开「我的本研课表」，再点「提取课表」`
- 页面不对（`pageProblem()`，零请求）：登录页 / 门户首页 / 非「我的本研课表」页各一句大白话。

## 2. 读了什么、交出去什么

| 数据 | 来源 | extract 输出 |
|---|---|---|
| `DM`、`MC` | 当前学期行，或学期列表第一条 | `term.dm`、`term.mc` |
| 选择方式 | 是否走过列表回落 | `term.selection`（`current` / `list`） |
| `XQKSRQ` | 校历行 | `term.startDate`，仅取前 10 字 |
| `ZZC` | 校历行 | `term.totalWeeks`（原样字符串，parse 判断合法性） |
| 本机日期 | 浏览器时钟 | `today`，用于选冬令/夏令与开学日缺失时推算 |
| `KCM`、`TYXMDM_DISPLAY`、`SKJS`、`JASMC`、`JAS`、`JXLDM_DISPLAY`、`JXLMC`、`XXXQMC`、`SKXQ`、`KSJC`、`JSJC`、`SKZC`、`ZCMC` | 课表行 | `rows[]` 的十三字段白名单，另加由 `SKZC` 展开的 `weeks` 数组 |
| 学号、姓名、人员标识、证件号、手机号等 | 三个响应里都可能夹带 | **不带出**：`pick()` 按字段白名单挑，白名单外的键一律丢弃 |
| Cookie、密码框内容、页面正文 | — | 不读取、不带出 |

`parse.js` 只吃上述普通 JSON，无 DOM、网络、存储、挂钟（只用 `data.today`）；输出课名、教师、地点、星期、节次、周次段、学期名、开学日、总周数与节次时间。教师/地点为空及「未知」「待定」「暂无」等占位词时交 `null`，课程照常导入并汇总提醒。

## 3. parse.js 的转换规则

- **周次**：`ZCMC` 文字 → 逐段解析取并集；单双标记既认段首（`(单)1-8周,(双)9-16周`、`(单)1-8周(双)9-16周`）也认段尾（`1-8周(单)9-16周(双)`、`1-16周(单)`）；兼容 `第1周至第8周`、`第1-第8周`、`1,3,5周`、`1~8周`；只剥「共 N 周」备注。文字解析不出时用 `weeks`（位串展开）兜底；第 31 周起丢弃并计数。
- **行去重与合并**：先按十三字段 + 周次原文去重（重复行不放大计数）；同课、同教师、同地点、同星期、同节次的周次取并集；同课、同教师、同地点、同星期、下一节正好接着（`end + 1`）且周次完全相同才合成一段（与上游一致的连堂语义）。
- **课名**：`KCM` 非空才收；有 `TYXMDM_DISPLAY` 时按上游拼成 `课名(别名)`。教师按上游 `cleanTeacher` 去重后交名字；地点按 `JASMC`/`JAS` → `JXLDM_DISPLAY`/`JXLMC` → `XXXQMC` 回落，占位词交 `null`。
- **开学日**：校历 `XQKSRQ` 回退到同一周周一（有变化就提醒）；无效时按 `today` 所在周周一推算并提醒。
- **总周数**：校历 `ZZC` 合法就用，超过 30 截断并提醒；没有就用 20 并提醒；只有课表排到更晚的周才抬高并提醒。
- **节次**：按今天日期选冬令或夏令表（§8）；第 12 节起按「上一节下课后课间 10 分钟、每节 45 分钟」顺推，越过 23:59 的不补时间但保留课程并提醒；节次超过 20 或不合法（结束早于开始）的行跳过并计数。
- **提醒**：按类型汇总、课名截 20 字、统一出口 ≤20 条 × 每条 ≤200 字；不写「适配器」「接口」「作息」等词。

## 4. 与模板（sany）的主要差异

1. 取数：`wdkb` 两请求 → `wdkbby` 四请求（另加学期列表回落），模块与 action 名照上游写死。
2. 周次：位串为唯一来源 → `ZCMC` 文字优先、位串兜底，并新增单双标记前置/后置、`第N周至第M周` 的兼容。
3. 学期：按开学日期在学期列表里挑 → 当前学期优先，回落列表第一条并提醒；不弹窗。
4. 校历与总周数：`ZZC`/`ZJXZC` → `cxxljc.do` 的 `XQKSRQ`/`ZZC`。
5. 节次：单一 10 节表 → 冬令/夏令两套 11 节表按日期选一套；顺推课间 5 分钟 → 10 分钟；连堂合并吸收，而不是保持两段。

## 6. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。账号密码不读；密码框只做存在性判断（`input[type="password"]`）；不发 `Authorization`，不用令牌；Cookie 由浏览器同源自动携带。
2. **不外发**：通过。只有上述四个同源 POST，无统计、图片信标、WebSocket、第三方地址。
3. **请求域可控**：通过。相对路径，永远落在当前教务页主机；`allowHosts: ["newehall.nwafu.edu.cn"]`，无通配。代码里的绝对地址只出现在文件头注释的上游仓库出处，运行时不使用。
4. **只读课表**：通过。只问当前学期、学期列表、个人课表与校历；不请求成绩、学籍、个人信息、缴费。响应里夹带的学生信息被字段白名单挡掉（冒烟已用合成学号/姓名/证件号/手机号验证不泄露）。
5. **不埋点**：通过。无统计、上报或遥测。
6. **不动态执行远程代码**：通过。无 `eval`、`new Function`。
7. **不写页面**：通过。只读 URL、查询密码框是否存在；不改 DOM、不提交表单、不点击。
8. **不依赖硬编码秘密**：通过。无固定令牌、密钥或他人信息；fixtures 全为合成课程与「教师甲」「老师甲」等虚构值。

`check.js` 对 `password` 字样的提示已人工复核：只出现在登录页门禁的选择器里，不读取其值。
