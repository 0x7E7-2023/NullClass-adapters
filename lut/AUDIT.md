# 安全审计 —— 兰州理工大学（lut，金智 jwapp / 我的课表 wdkb）

审计对象：`jw-adapters/lut/` 下的 `manifest.json`、`extract.js`、`parse.js` 与 `fixtures/`。
上游：`shiguang_warehouse` 的 `LUT/LUT.js`（128 行，MIT，作者及 `adapters.yaml` 维护者 Colton）。
上游快照 `baf83fa7972d4be6627c534992f7d2da399a0945`；`git log -1 -- resources/LUT/LUT.js` 核对为 `f1de9c2`
（2026-08-25，PR #499），与任务卡一致。未修改快照。

## 0. 通读结论与模板选择

任务卡指定模板 `sany`（同族金智 wdkb）。通读后确认两者只有「金智 jwapp 的响应外壳 + 白名单挑字段」这一层同构：

- 取数不同构：`sany` 是「POST 学期列表 + POST 课表」，按开学日期自己挑学期；本校是「GET 当前学年学期 + POST 课表」，
  学期代码由教务直接给出，没有选择余地。
- 学期信息不同构：`sany` 的学期行带 `XN` / `XQ` / `XQKSRQ` / `ZZC`；本校 `dqxnxq` 只给 `DM`，**没有开学日期，也没有总周数**。
- 周次不同构：`sany` 是 `SKZC` 位串；本校 `ZCMC` 是文本（`1-16周`、`(单)…`、`全周` 等）。
- 认证不同构：`sany` 要扫本地存储里的 JWT 加 `Authorization`；本校上游只用浏览器 Cookie，移植不读任何令牌。

因此复制 `sany` 的骨架（请求封装、白名单 pick、提醒限长与计数、H3 补节次、提醒出口），
其余按本校上游代码重写；周次文本解析按已审计的 `bbgu` / `bupt` 的写法移植，并补齐公共说明要求的
「无逗号前置单双」和「按段判单双」用例。

上游代码事实：

1. 常量 `API_ROOT = "/jwapp/sys"`，两个路径都是**根相对地址**，脚本内不写死主机。
2. `requestJson` 无参数时 GET；有参数时 POST，正文是 `URLSearchParams`，`Content-Type` 为
   `application/x-www-form-urlencoded; charset=UTF-8`，两者都带 `credentials: "include"`。
3. 非 2xx 抛错；`data.code` 存在且不是 `"0"` 时抛「教务系统拒绝请求」。
4. 学期取 `datas.dqxnxq.rows[0].DM`；课表 POST `XNXQDM=<DM>`，读 `datas.cxxszhxqkb.rows`。
5. 行字段：`SKXQ` 星期、`KSJC` / `JSJC` 起止节次、`ZCMC` 周次文本、`KCM` 课名、`SKJS` 教师、`JASMC` 教室。
6. `parseWeeks(ZCMC, 30)`：删「第」「周」、全角逗号转半角；出现「全周 / 全部」或一个数字都没有时按 1..30；
   否则数字逐个加入、`至`/`到`/`-` 区间展开；单 / 双是**整串**判定的（上游缺陷，见 §5）。
7. 上游只过滤 `KCM / 星期 / 起止节次 / 周次` 齐全的行，缺哪项就静默丢掉。
8. 节次时间写死 `LUT_TIME_SLOTS` 10 节；`getTimeSlots` 与 `parseTime` 定义了但没被调用。
9. 学期总周数只在保存配置时用 `Math.max(所有周次, 20)`；开学日 `null`；每周起始日 1。
10. 上游用 ES6、`Set`、`URLSearchParams`、弹窗选学期（没有）、拾光保存桥与提示条。

## 1. 请求域与请求清单

| 谁 | 方法 | 地址 | 干什么 | 取不到时 |
|---|---|---|---|---|
| `extract.js` 第一个 `request()` | GET | `/jwapp/sys/wdkb/modules/jshkcb/dqxnxq.do` | 读当前学年学期，取 `datas.dqxnxq.rows[0].DM` | 非 2xx、非 JSON、`code` 非 `"0"`、缺 `datas.dqxnxq.rows`、空列表、缺 `DM`：整次报错，不继续取课表 |
| `extract.js` 第二个 `request()` | POST | `/jwapp/sys/wdkb/modules/xskcb/cxxszhxqkb.do`，正文 `XNXQDM=<DM>` | 读个人课表 | 非 2xx、非 JSON、`code` 非 `"0"`、缺 `datas.cxxszhxqkb.rows`：整次报错；空行交给 `parse.js` 报「没有解析到任何课程」 |

两个地址都是**根相对路径**，永远打到当前教务页面同源的主机（不写死 API 主机，也没有 `/jwapp` 前缀推导，因为上游本身就是根相对地址）。
表单 `Content-Type` 与上游一致；两个请求都带浏览器现有 Cookie。**不读本地存储令牌，不加 `Authorization`**。
不添加额外业务参数，不重试、不翻页。上游没有分页代码，移植也不臆造分页。

登录页（有密码框或地址含 `login`）与不在 `/jwapp/sys/wdkb` 下的页面（含 `loginUrl` 门户根地址）都在
`pageProblem()` 直接报错，两个请求均不发生。只判断密码框是否存在，不读取其值。

`loginUrl` = `https://jwxt.lut.edu.cn/`；`allowHosts` = `["jwxt.lut.edu.cn"]`（精确主机，无通配）；
`scheduleUrlHint` = `https://jwxt.lut.edu.cn/jwapp/sys/wdkb/*default/index.do`。

## 2. 读了什么、交出去什么

| 数据 | 来源 | extract 输出 |
|---|---|---|
| `DM` | `dqxnxq` 第一行 | `term.dm`，用于课表请求和学期名 |
| 本机日期 | 浏览器时钟 | `today`，只用于开学日推算 |
| `KCM`、`SKJS`、`JASMC`、`SKXQ`、`KSJC`、`JSJC`、`ZCMC` | 每个 `cxxszhxqkb` 行 | `rows[]` 的七字段白名单（`pick()`） |
| 学期及课表其他字段 | 两个响应 | 一律不带出；包括学号、姓名、人员标识、证件号、手机号 |
| Cookie / 页面正文 | 浏览器 | 不读取、不带出（Cookie 由浏览器随请求自动携带，脚本不碰） |
| 密码框 | 页面 | 只查是否存在，不读值 |

`parse.js` 只接收上述普通 JSON，无 DOM、网络、存储、挂钟或桥调用。输出课名、教师、教室、星期、节次、周次段、
学期名、开学日、总周数与 10 节节次时间。教师或地点为空及「未知」「待定」「暂无」等占位词时为 `null`，
课程仍导入并按类型汇总提醒。

## 3. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。上游这两个接口不需要令牌，移植不读 `localStorage` / `sessionStorage` / cookie；
   代码里唯一的 `password` 是登录页门禁的框存在性判断。账号密码不读、不存、不传。
2. **不外发**：通过。只有上面两个同源请求；无统计、图片信标、WebSocket 或第三方请求。
3. **请求域可控**：通过。请求是根相对路径，主机恒为当前教务页同源（`jwxt.lut.edu.cn`），已写进 `allowHosts`，无通配。
4. **只读课表**：通过。只读当前学期与个人课表；不请求成绩、学籍、个人信息、缴费。字段白名单阻挡响应夹带的个人信息。
5. **不埋点**：通过。无统计、上报或遥测。
6. **不动态执行远程代码**：通过。无 `eval`、`new Function`。
7. **不写页面**：通过。只查询密码框、读 URL；不改 DOM、不提交表单、不点击。
8. **不依赖硬编码秘密**：通过。无固定令牌、密钥、真实学号或他人信息；fixtures 全为合成课程与「教师甲」等虚构值。

`check.js` 对 `password` 字样的提示已人工复核：只用于登录页判断，不读值、不外发。

## 4. 与模板的主要差异

- **取数**：`sany` 的「POST 学期列表 + 按日期挑学期」改为「GET 当前学期 + POST 课表」，路径与表单字段照本校上游。
- **学期信息来源**：只有 `DM`。学期名按 `yyyy-yyyy-n` 拼「2026-2027学年第一学期」，格式不认识时退回「学校名 + 原文」。
- **周次**：删除位串解析，改为文本解析；单 / 双按段判定（模板没有文本周次这一层）。
- **开学日与总周数**：本校教务都没有；开学日按本机日期所在周的周一推算，总周数默认 20、课表更晚才抬高，均写提醒。
- **认证**：删除模板的本地存储 JWT 扫描，本校接口只用 Cookie。
- **节次表**：本校 10 节 08:00–21:20（模板是三一自己的时间）。

## 5. 上游删掉或改掉的内容

- 删除 `showToast`、`notifyTaskCompletion`、`saveImportedCourses`、`savePresetTimeSlots`、`saveCourseConfig`
  与控制台输出；空课宿主统一保存载荷。
- 删除 ES6 语法、`Set`、`URLSearchParams`、展开与异步函数，改为 ES5 对象字典、数组与 Promise 链。
- 删除没有被调用的 `getTimeSlots` / `parseTime`（上游留有课表接口给节次时间的死代码，本校实际只用写死表）。
- 教师 / 教室的空值从 `""` 改为 `null`；占位词（未知、待定、暂无…）同样交 `null`。
- 无效行不再静默丢弃：缺课名 / 星期 / 节次 / 周次按原因计数进提醒，并附最多 3 条周次原文。
  缺教师 / 缺教室只在**确定要导入**的行上记账（含全周行）；因缺周次被跳过的行不再被说成「已照常导入」。
- 完全重复的原始行先按七字段内容去重，再计数，避免提醒被重复放大。
- **周次单双改为按段判定**：上游是整串判单双（`(单)1-8周,(双)9-16周` 会退化成 1-16 每周都上），
  移植后每段只跟自己的标记；同时认「第1-第8周」「至/到」区间、「共 N 周」备注。这是对上游的有意修正。
- 括号包住的整段周次（`(1-16周)`、`（第1-16周）`）去掉括号、保留里面的周次；纯数字或数字逗号列表
  （`(1)`、`(1,2)`）仍按教学班序号整组摘掉。
- `第1周至第8周` / `1周至8周`：区间符号两侧数字后面的「周」先归一，再走区间展开，读成完整的 1-8。
- 「全周 / 全部」不再沿用上游固定铺 1-30 周的做法：先读完所有行，再按
  `max(默认 20 周, 其余行出现的最大周)` 展开；全周行本身不参与「课表更晚抬高」的判断。
  30 周只作为显式周号的上限（超出丢弃并提醒）。锚点来自其他课程时提醒「已按课表覆盖到的第 1-X 周导入」，
  否则提醒「已按默认的 20 周导入」。这是对上游的有意修正。
- 总周数不再可能落为 0 或 40：默认 20，课表更晚才抬高，载荷上限 30 周。
- 开学日必填（应用靠它算「现在第几周」），推算值一律写进提醒。
- 第 11 节起按统一修订 H3 补：默认节次表同一节的开始不早于上一节下课就用它，否则按课间 5 分钟、每节 45 分钟顺推，
  越过 23:59 不编造时间（课程保留并提醒）。本校第 10 节 21:20 下课，空课默认表第 11 节 20:20 更早，
  所以本校实际只会走顺推分支。
- 学期名用 `DM` 生成，不用适配器名。

## 9. 已知风险与未验证项

- **没有本校账号，真实教务与真机未验证。** 页面路径、`DM` 格式、响应字段与节次以快照代码为依据；
  合成 fixture 与假站不能证明线上返回完全一致。
- `scheduleUrlHint` 按金智 wdkb 标准模块地址写为 `/jwapp/sys/wdkb/*default/index.do`；上游只给门户入口与接口路径，
  没有直接给出模块首页，需真机确认入口路径是否相同（任务卡已提示这一点）。
- 学期名依赖 `DM` 形如 `2026-2027-1`；若真实格式不同，会退回「兰州理工大学 + 原文」，不影响导入但不好看。
- 「全周」的范围取决于其他课程排到第几周：只有全周行时按默认 20 周，其他课排得更晚才跟着延长（已提醒）；
  全周行里的单 / 双标记不参与判定（按整段每周都上处理），真实数据若这样写需要再确认。
- 开学日一律是推算值（本机所在周的周一），学期开始后导入可能与真实第 1 周有偏差，提醒里已说明。
- 上游没有分页或 `totalSize` 特判，本移植也不增加；若真实课表分页，只能读响应里的 `rows`，可能少课。
- `SKJS` 写成多个教师（逗号分隔）时按原样输出为一个教师名，没有拆分（上游也不拆）。
- 位周次超过 30 的一律丢弃，不猜；提示里给的是个数。
