## 0. 通读结论与模板选择

**库里没有同平台的件。** 上游是「CAS 登录后，在 `tis.sustech.edu.cn` 上同源 POST，拿回 JSON / 纯数字文本」的纯接口式取数，
与已审的 `nwafu`（金智 jwapp 同源 POST → 结构化字段 → 纯函数转换）在**骨架**上最像：登录页零请求、字段白名单 `pick()`、
响应外壳只认一次、槽位并周次再连堂合并、提醒统一限长。因此模板取 `nwafu`，**取数层、周次来源、节次表、学期处理全部按上游重写**，
转换层（周次文字解析、单双归属、连堂、占位词、提醒出口）沿用 `nwafu` 已审的实现。`ustc` 只作 CAS 门禁写法的旁证。

与模板不同构的地方：

1. **五个接口、四种外壳**：学期与课表是 JSON 对象（数组可能直接给，也可能包在 `content` / `data` 里）；节次时间是 JSON 数组；
   当前教学周是**纯数字文本**（不是 JSON，学期的第 1 周前返回空）。`nwafu` 全部是 `datas.<action>.rows`。
2. **周次来源是 `ZC` 0/1 位图**，不是周次文字列；位图「下标即周次（下标 0 未使用）」，上游还准备了「下标 + 1」的第二种解释，
   用 `SKSJ` 里声明的周次择优校准。`nwafu` 是 `ZCMC` 文字优先、位串兜底。
3. **没有校历**：开学日只能由 `querydangqianzc` 的当前教学周往回推；总周数没有教务来源（见 §3）。
4. **课名 / 教师 / 地点来自授课文本 `SKSJ`（为空时读英文授课的 `SKSJ_EN`）多行文本**（`课程名` / `[教师]` / `[班级]` / `[周次][地点][节次]`），
   不是独立字段；班级行必须丢掉。`nwafu` 是 `KCM` / `SKJS` / `JASMC` 等列。
5. **节次口径**：`KEY` 里的 `jc` 是**课表网格行号，不是节次**，真实节次是 `KSJC` / `JSJC`（见 §7 的坑）。
6. **不弹窗选学期**：上游先拉历史学期列表再弹窗选择；移植只问当前学年学期，取不到仍照常查课表并提醒（§3）。

## 1. 请求清单（与代码一致）

全部在 `extract.js` 的 `request()` 里：`POST` + `credentials: 'same-origin'`，头固定为 `Accept`、
`Content-Type: application/x-www-form-urlencoded; charset=UTF-8`、`X-Requested-With: XMLHttpRequest`；
**不发 `Authorization`、不读 Cookie**（同源 Cookie 由浏览器自动带）。请求之间 `pause(300ms)`。

| 谁 | 方法 | 地址（相对当前页面，永远同源） | 正文 | 干什么 | 取不到时 |
|---|---|---|---|---|---|
| `loadTerm()` | POST | `/component/querydangqianxnxq` | 空 | 当前学年学期：`XN`、`XQ`、`XNXQ` | 403 / 登录失效 / 连不上直接报错并停止；其余失败（缺 `XN`/`XQ`、非 JSON、空）交空学期，流程继续 |
| `loadRows()` | POST | `/xszykb/queryxszykbzong` | `xn=<学年>&xq=<学期>`；学期未知时空正文 | 整学期课表行 | 非 2xx / 登录页 / 非 JSON 整次报错；空数组交给 `parse.js` 报「没有读到任何课程」 |
| `loadSlots()` | POST | `/component/queryKbjg` | `xn=&xq=&zc=1`（该校上游固定 `zc=1`） | 节次时间：`xj`、`kssj`、`jssj` | 任何失败都吞掉交 `null`，课程照常导入，`parse.js` 回落到写死的常规节次表并提醒 |
| `loadCurrentWeek()` | POST | `/component/querydangqianzc` | 空 | 当前教学周（纯数字文本） | 空文本 / 非数字 / 失败交 `null`，`parse.js` 改按本机日期推算开学日并提醒 |

**不请求**上游的 `/cjgl/grcjcx/grcjcx`（成绩 / 历年课程查询）：它只用于拼学期列表，既不需要，也违反「只读课表」（§5 第 4 条）。

`manifest.scheduleUrlHint` 填 `https://tis.sustech.edu.cn/`（教务系统入口）：课表页在 CAS 登录后是单页应用，没有稳定深链，
填根地址是当前能确认的最深地址；登录后由用户自己进课表。不编造 `/xszykb/...` 之类的页面地址。

页面门禁（`pageProblem()`，命中即抛错、**零请求**）：

- 页面上有密码框，或主机是 `cas.sustech.edu.cn`、地址含 `/cas/login` → 「当前打开的是登录页：请先完成统一身份认证登录，进入教学管理与服务平台后再点「提取课表」」；
- 主机不是 `*.tis.sustech.edu.cn` → 「请先打开南方科技大学教学管理与服务平台（tis.sustech.edu.cn）并登录，再点「提取课表」」。

错误提示（学生可见）分两类，**不合并**：HTTP 非 2xx → 「教务系统返回错误（代码 N）：登录状态可能已失效，请重新登录后再试」；
返回了页面但不是可读数据（以 `<` 开头，或含「重新登录 / 请登录 / 用户认证 / 登录已过期」）→ 「教务系统返回的是登录页面，登录状态可能已失效，请重新登录后再试」
或「登录状态已失效：请重新登录后再点「提取课表」」；`JSON.parse` 失败 → 「教务系统没有返回可读取的数据…」；403 → 「教务系统拒绝访问…」；网络失败 → 「连不上教务系统…」。

## 2. 读了什么、交出去什么

| 数据 | 来源 | extract 输出 |
|---|---|---|
| `XN`、`XQ`、`XNXQ` | `querydangqianxnxq` | `term.xn`、`term.xq`、`term.label`（`XN`/`XQ` 格式不对就都交空串） |
| 本机日期 | 浏览器时钟 | `today`（`yyyy-MM-dd`），用于推算学期名与开学日 |
| 当前教学周 | `querydangqianzc`（纯数字） | `currentWeek`（数字）或 `null` |
| `xj`、`kssj`、`jssj` | `queryKbjg` | `slots[]` 三字段白名单，或 `null`（请求失败） |
| `KEY`、`KCMC`、`SKJS`、`SKDD`、`KSJC`、`JSJC`、`ZC`、`SKSJ`、`SKSJ_EN` | `queryxszykbzong` | `rows[]` 九字段白名单，原样交（含 `ZC` 位串与授课文本全文；`SKSJ_EN` 只是英文授课文本，不含学生信息） |
| 学号、姓名、班级、人员 ID、证件号、手机号 | 响应里夹带 | **不带出**：`pick()` 只按白名单挑键，白名单外的键一律丢弃（冒烟用合成学号/姓名/证件号/手机号/人员 ID 验证） |

`parse.js` 只吃这份普通 JSON：无 DOM、无网络、无存储、无挂钟（只用 `data.today`）。输出课名、教师、地点、星期、起止节、
周次段、学期名、开学日、总周数与节次时间。教师 / 地点为空或为「未知」「待定」「暂无」等占位词时交 `null`，课程照常导入并汇总提醒。
班级行（含「班」的 `[思想道德与法治-09班-中文]`）读完即丢，不进任何输出。

## 3. parse.js 的转换规则（自己做的分析）

- **行去重**：先按九字段原文去重（同一节课在课表网格里占多行时，`jc` 不同但其余相同也会被判成不同行，靠下一步合并吸收），
  避免提醒里的「有 N 条」被放大。
- **周次**：`ZC` 位图 → 两种解释（周次 = 下标；周次 = 下标 + 1），`SKSJ` 里声明了周次就用重叠多的一种，声明为空按「周次 = 下标」；
  位图不是纯 0/1 时退回声明周次。`SKSJ` 的周次文字逐段解析取并集，单双标记前置（`(单)1-8周,(双)9-16周`）与后置（`1-15周(单)`）都认，
  兼容 `第1周至第8周`、`第1-第8周`、`1,3,5周`、`1~8周`，只剥「共 N 周」备注；第 31 周起丢弃并计数。
  只把「含数字又含『周』」的中括号组当周次读，没有中括号的整行才整行读，免得把「二教202」当成第 202 周。
- **合并**：同课、同教师、同地点、同星期的行，节次相同则周次取并集；下一段起点不晚于上一段结束的下一节、且周次完全相同则合成连堂
  （用 `<= end + 1` 而不是 `= end + 1`，同一节的重复行不会另起一段）。课表里用到 `KSJC`/`JSJC`，`jc` 不参与节次。
- **课名 / 教师 / 地点**：授课文本按上游取 `SKSJ`，`SKSJ` 为空时读英文授课的 `SKSJ_EN`（课名、教师、地点、周次声明都跟着换）。
  课名取授课文本第一行，缺了用 `KCMC`；教师取第一条非班级文字，缺了用 `SKJS`；地点取含周次那行里
  第一个既不是周次、也不是节次、也不含「班」的中括号组，缺了用 `SKDD`。「未知」「待定」「暂无」等一律 `null`（取下一个候选）。
  教师按中英文逗号 / 顿号 / 分号去重，括注（「张三（外聘）」）不拆成第二位教师。
- **开学日**：`currentWeek` 在 1..30 时，第 1 周周一 = 本机日期所在周的周一往前推 `(currentWeek - 1)` 周，并提醒这是推算值；
  `currentWeek` 缺失时按本机日期所在周的周一，并提醒。
- **总周数**：本校没有校历接口，按公共说明用 20 周（上游写死 18）；只有课表排到更晚的周才抬到那一周并提醒；超过 30 截断。
- **节次时间**：`queryKbjg` 的 `xj`/`kssj`/`jssj` 逐条校验（节次号 1..20、`HH:mm`、结束晚于开始、同一节次取第一条），全部不可用就用
  写死的常规 12 节表并提醒；课表用到表尾以后的节次，按「上一节下课后课间 10 分钟、每节 50 分钟」顺推，越过 23:59 的不补时间但保留课程并提醒。
- **提醒**：按类型汇总、点名的课名截 20 字、统一出口 ≤20 条 × 每条 ≤200 字；拼进提醒的教务原文只有节次时间区间（固定格式、不会被撑爆），
  认不出的周次原文不拼进提醒。不写「接口」「载荷」「上游」「脚本」「作息」「学期设置」等词。

## 4. 与模板（nwafu）的主要差异

1. 取数：`datas.<action>.rows` 四请求 → 四种外壳的四请求，含一个纯文本接口与一个可为 `null` 的节次接口。
2. 周次：`ZCMC` 文字优先 + 位串兜底 → `ZC` 位图为主（两种解释择优校准）+ `SKSJ` 声明周次兜底。
3. 课名 / 教师 / 地点：独立字段 → `SKSJ` 多行文本（为空时读 `SKSJ_EN`）+ 字段兜底，班级行丢弃。
4. 开学日：校历 `XQKSRQ` → 当前教学周往回推；总周数：校历 `ZZC` → 无校历按 20 周。
5. 节次：冬令/夏令两套按日期选 → 教务现给的一套 + 写死的常规表回落，顺推每节 50 分钟（模板 45 分钟）。

## 7. `KEY` 的坑（必须写清）

`KEY` 形如 `xq1_jc5`：`xq` 后面是**星期**（1-7），`jc` 是**课表网格行号，不是节次**。上游注释与代码一致：
节次一律取 `KSJC` / `JSJC`，`jc` 只在 `KSJC` 缺失时兜底（`parse.js` 主循环里 `startPeriod` 的回落）。
把 `jc` 当节次会让整张课表错位——本移植没有这么做。

## 8. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。账号密码不读；密码框只做存在性判断（`input[type="password"]`）；不发 `Authorization`，不读 Cookie。
2. **不外发**：通过。只有上述四个同源 POST，无统计、图片信标、WebSocket、第三方地址。
3. **请求域可控**：通过。全部相对路径，永远落在当前教务页主机；`allowHosts` 为 `["tis.sustech.edu.cn", "cas.sustech.edu.cn"]`，无通配。
4. **只读课表**：通过。只问当前学年学期、课表、节次时间、当前教学周；不请求成绩、学籍、个人信息、缴费（上游的成绩接口已删除）。
   响应里夹带的学生信息被字段白名单挡掉。
5. **不埋点**：通过。无统计、上报或遥测。
6. **不动态执行远程代码**：通过。无 `eval`、`new Function`。
7. **不写页面**：通过。只读 `location` 与密码框是否存在；不改 DOM、不提交表单、不点击。
8. **不依赖硬编码秘密**：通过。无固定令牌、密钥或他人信息；fixtures 全是合成课程与「教师甲」「晚课甲」等虚构值。

`check.js` 对 `password` 字样的提示已人工复核：只出现在登录页门禁的选择器里，不读取其值。

## 12. 已知风险与未验证项

- **没有本校账号，真实教务与真机未验证。** 路径、字段名、响应外壳（数组 / `content` / `data`）、`SKSJ` 的行格式均以快照代码与注释为依据；
  合成 fixture 与假站不能证明线上完全一致。
- **`allowHosts` 与任务卡不一致**：任务卡写 `["*.sustech.edu.cn"]`，但本系列红线与 `check.js` 都禁止通配（`*.` 会让提问桥 / OCR 拿不到主机，
  也放得太宽），故改为显式的 `tis.sustech.edu.cn` 与 `cas.sustech.edu.cn` 两个。若真实流程还会经过别的主机（例如别的 CAS 域名），需要补一个。
- **`scheduleUrlHint` 只能填教务系统入口** `https://tis.sustech.edu.cn/`：课表页在 CAS 登录后是单页应用，没有稳定深链，
  一键刷新只能把用户送到入口，再由用户自己进课表。若将来确认了课表的稳定地址，应改成那个地址。
- **学期接口失败时按空参数查课表**：依赖 TIS 在缺省 `xn`/`xq` 时返回当前学期。这是上游没有的路径（上游直接报错），
  线上若返回空或报错，用户看到的是「没有读到任何课程」或对应报错，不会导入错学期——但仍属未验证。
- **开学日靠当前教学周推算**：学期开始前该接口返回空，此时按本机日期所在周的周一，可能与真实第 1 周差一周，已在提醒里说明。
- **总周数固定 20**：本校没有校历接口，18 周的学期在应用里会多出两周空白；这是公共说明第 7 条的取舍。
- **节次表有空档时**：`queryKbjg` 若只给部分节次（例如缺第 6 节），空档那一节没有时间显示，代码不会补——只补表尾以后的。
- **`SKSJ` 的格式只覆盖快照注释与批次教训里出现过的写法**；若真实数据把教师和地点写在同一行且不加中括号，可能把地点当成教师。
  教师 / 地点缺失都会进汇总提醒，不会静默丢课。
- **教师 / 地点在第一行**（`SKSJ` 首行不是课名）时会被当成课名；上游同样如此，未做额外识别。
- **同一门课同一时段跨地点**（教室调整）会各成一段，应用里会显示为两条重叠课程；上游去重键同样包含地点。
- **`querydangqianzc` 返回两位数以上**（例如 100）按非法处理，退回本机日期推算。
