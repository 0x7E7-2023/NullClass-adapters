上游快照 `baf83fa`（2026-11-11 复核）；`git log -1 -- resources/HEBAU/hebau.js` 核对为 `c60b8f7`（2026-10-08），与任务卡一致。未修改快照。

## 0. 通读结论与模板选择

模板按任务卡用批次三十已审的 `sany`（同为金智 wdkb：`datas.<键>.rows` 外壳、`SKZC` 位串、同键合并、H3 节次扩展、
提醒统一出口）。上游与 `sany` 同构的部分：`credential: include` 的同源 POST、`datas` 信封、位串下标即周次、
按「课名 + 教师 + 星期 + 起止节 + 教室」合并周次、教师/教室占位词处理。不同构的部分按本校上游重写：

1. 请求是五个：当前学期、学期列表、校历、节次时间、课表；`sany` 只有学期与课表两个。
2. 学期不是从列表按开学日挑，而是读教务给出的当前学期（`dqxnxq.do`），再用学期列表（`xnxqcx.do`）核对。
3. 总周数与开学日来自单独的校历接口 `cxxljc.do`（`ZZC` / `ZJXZC` / `XQKSRQ`）。
4. 节次时间来自 `jc.do`；上游没有写死表，取不到就交空表用应用默认节次时间，不编造。
5. 上游读本地存储令牌的写法没有出现；本校接口只用会话 Cookie（与上游一致），模板里的令牌扫描已删除。

另交叉参考同平台已审件 `ctgu`（`dqxnxq.do` + `cxxszhxqkb.do` 的写法）与 `jlu`（`jc.do` 启停节次与 H3 顺推）。
最终请求、请求体、字段名一律以上游 `HEBAU/hebau.js` 的代码为准。

## 1. 任务卡分析与本校边界

- **与模板不同构之处**：见第 0 节五条；合并、位串切段、占位词、提醒限长仍沿用模板口径。
- **请求清单**：第 2 节表格；五个都是 POST，全部同源，按顺序串行，不并发。
- **内置节次时间**：**没有**。上游从 `jc.do` 读 `DM` / `KSSJ` / `JSSJ`；取不到时上游只是不保存。
  本移植交空 `periodTimes`，由应用用默认节次时间，并在提醒里说明来源（不自己编一套表）。
- **本校专属边界用例**：当前学期取不到 / 不在学期列表里、校历缺失（总周数与开学日回退）、节次时间取不到、
  节次表只覆盖前 8 节而课表用到第 12 节、`SKZC` 第 31 周、长课名提醒限长。均钉在本目录 fixtures 里。
- **需要桩跑 / 冒烟的场景**：五个请求的地址与请求体、登录页 / 教务首页 / 其他页零请求、当前学期取不到、
  学期列表为空、节次时间 500、课表返回登录页、空课表。

## 2. 请求域与请求清单

`<base>` 是当前页面 URL 中第一个 `/jwapp` 之前的完整前缀（带端口与路径前缀都原样保留），没有匹配时退回当前源。
所有请求始终与当前教务页面同主机；`loginUrl` 为 `http://urp.hebau.edu.cn:1009/jwapp/sys/homeapp/home/index.html#/`，
`allowHosts` 为 `[]`，没有通配、第三方地址或其他请求。未写 `scheduleUrlHint`：金智模块页对新会话会 403（`dlutci` 的结论）。

| # | 方法 | 地址 | 正文 | 干什么 | 取不到时 |
|---|---|---|---|---|---|
| 1 | POST | `<base>/jwapp/sys/wdkb/modules/jshkcb/dqxnxq.do` | 空 | 当前学年学期 `DM` / `MC` | 判定失败即按本机日期推算学期编号，`term.source` 记 `guess`，parse 写提醒；不阻断 |
| 2 | POST | `<base>/jwapp/sys/wdkb/modules/jshkcb/xnxqcx.do` | `*order=-DM` | 学期列表，核对当前学期在不在列表里 | 请求失败、缺表或空列表都记 `listed=null`，不写提醒、不阻断 |
| 3 | POST | `<base>/jwapp/sys/wdkb/modules/xskcb/cxxljc.do` | `XN=<学年>&XQ=<学期>` | 校历：`XQKSRQ`、`ZZC`、`ZJXZC` | 交空数组；parse 用本机日期与 20 周回退并提醒 |
| 4 | POST | `<base>/jwapp/sys/wdkb/modules/jshkcb/jc.do` | 空 | 节次时间 `DM` / `KSSJ` / `JSSJ` | 交空数组；parse 交空 `periodTimes` 并提醒用应用默认节次时间 |
| 5 | POST | `<base>/jwapp/sys/wdkb/modules/xskcb/cxxszhxqkb.do` | `XNXQDM=<学期编号>` | 个人课表行 | 非 2xx、非 JSON、缺 `datas.cxxszhxqkb`：整次报错；空行交给 parse 报「没有解析到任何课程」 |

五个请求都带浏览器现有 Cookie；`Content-Type: application/x-www-form-urlencoded; charset=UTF-8` 与
`X-Requested-With: XMLHttpRequest` 与上游一致。不添加额外业务参数，不重试、不翻页（上游没有分页代码）。

登录页（密码框或地址含 `login`）、教务首页（地址含 `/jwapp/sys/homeapp`）、不在 `/jwapp/sys/wdkb` 下的页面
都在 `pageProblem()` 直接报错，五个 POST 均不发生。只判断密码框是否存在，不读取其值。

## 3. 读了什么、交出去什么

| 数据 | 来源 | extract 输出 |
|---|---|---|
| `DM`、`MC` | `dqxnxq` 第一行 | `term.code`、`term.name`；用于课表请求、学期名与提醒 |
| 时间推算结果 | 本机日期 | `term.code`（起始学年-结束学年-学期）、`term.source`=`guess` |
| 学期核对结果 | `xnxqcx` 行 | `term.listed`：在列表里 `true`、明确没有 `false`、取不到或空列表 `null` |
| `XN`、`XQ`、`XQKSRQ`、`ZZC`、`ZJXZC` | `cxxljc` 行 | `calendarRows[]` 五字段白名单 |
| `DM`、`KSSJ`、`JSSJ` | `jc` 行 | `sectionRows[]` 三字段白名单 |
| `KCM`、`SKJS`、`JASMC`、`SKXQ`、`KSJC`、`JSJC`、`SKZC` | 每个 `cxxszhxqkb` 行 | `rows[]` 七字段白名单 |
| 本机日期 | 浏览器时钟 | `today`，只用于学期推算与开学日缺失时回落 |
| 学期与课表其他字段 | 五个响应 | 一律不带出；包括学号、姓名、人员标识、证件号、手机号 |
| 密码、Cookie 内容、页面正文、本地存储 | 页面 | 不读取、不带出；`extract.js` 不碰 `localStorage` / `sessionStorage` / Cookie |

`parse.js` 只接收上述普通 JSON，无 DOM、网络、存储、挂钟或桥调用。输出课名、教师、教室、星期、节次、周次段、
学期名、开学日、总周数与节次时间。教师或地点为空及「未知」「待定」「暂无」等占位词时为 `null`，课程仍导入并汇总提醒。

## 4. 字段映射与周次

- `SKZC` 位串：第 `i` 位为字符 `1` 表示第 `i+1` 周有课；按步长 1 / 2 切成极大段，步长 2 且多于一节时按起始周奇偶标
  `ODD` / `EVEN`；第 31 周起丢弃并计数提醒。
- 同键（课名 + 教师 + 教室 + 星期 + 起止节）取周次并集；连堂不合并；不同教室不合并；原始重复行先按七字段去重再计数。
- `SKXQ` 1-7 为星期；`KSJC` / `JSJC` 为起止节，超出 1-20 或倒挂的行跳过并计数。
- 教师、地点占位词（未知 / 待定 / 暂无等）交 `null`，缺了照常导入并按课名去重后汇总提醒。
- 开学日取 `XQKSRQ` 前 10 字，回退到同一周周一，变化时提醒；无合法日期才用本机日期所在周周一。
- 总周数依次取 `ZZC`、`ZJXZC`；都无效用 20，课表排得更晚才抬高，超过 30 按 30 截断；每种情况都写提醒。
- 学期名优先用教务给的 `MC`；没有就按编号拼 `2026-2027学年第一学期`；编号也认不出才用「河北农业大学 + 原文」。

## 5. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。账号密码不读；密码框只用于存在性判断；不读本地存储与 Cookie，会话 Cookie 由浏览器自动带上。
2. **不外发**：通过。仅第 2 节五个同源 POST；无统计、图片信标、WebSocket 或第三方请求。
3. **请求域可控**：通过。主机为当前教务页面主机，入口主机为 `urp.hebau.edu.cn`（端口 1009）；`allowHosts: []`，无通配。
4. **只读课表**：通过。只读当前学期、学期列表、校历、节次时间与个人课表；不请求成绩、学籍、个人信息、缴费。
   响应里的学号、姓名等字段被白名单挡在 extract 之外。
5. **不埋点**：通过。无统计、上报或遥测。
6. **不动态执行远程代码**：通过。无 `eval`、`new Function`。
7. **不写页面**：通过。只查询密码框、读 URL；不改 DOM、不提交表单、不点击。
8. **不依赖硬编码秘密**：通过。无固定令牌、密钥、真实学号或他人信息；fixtures 全为合成课程与「教师甲」等虚构值。

`check.js` 对 `password` 字样的提示已人工复核：仅用于登录页密码框存在性判断。

## 6. 与模板的主要差异

- **取数**：`sany` 两个 POST 改为五个 POST；保留 `/jwapp` 前缀推导，新增 `dqxnxq` / `xnxqcx` / `cxxljc` / `jc`。
- **学期**：`sany` 从学期列表按开学日挑；本校读当前学期，再用列表核对；取不到才按日期推算并如实提醒。
- **周次/合并**：与 `sany` 同口径，未改。
- **校历**：开学日与总周数从独立的 `cxxljc` 请求取，支持 `ZJXZC` 备用总周数。
- **节次时间**：`sany` 写死 10 节表；本校读 `jc.do`，取不到交空表（应用默认），表外节次按 H3 逐节顺推。
- **认证**：删除模板的本地存储令牌扫描，只依赖会话 Cookie（与上游一致）。

## 8. 节次时间

本校没有内置节次表。`parse.js` 读 `sectionRows` 的 `DM` / `KSSJ` / `JSSJ`：
- `KSSJ` / `JSSJ` 接受 `H:mm`、`HH:mm`、`HH:mm:ss`，统一成 `HH:mm`；结束不晚于开始的行丢弃；
- 同一节号只取第一次出现；节号 1-20 以外丢弃；
- 一行合法节次都没有时交空 `periodTimes`，提醒「用应用默认的节次时间」；
- 有的节次没覆盖课表用到的节次时，从上一节下课后课间 5 分钟、每节 45 分钟逐节顺推；越过 23:59 起停止补时间。

上游代码不读 `SFSY`（是否启用），本移植也不读；若 `jc.do` 返回停用或午休行，会按节号原样保留（见第 11 节风险）。

## 11. 已知风险与未验证项

- **没有本校账号，真实教务与真机未验证。** 五个地址、字段名与响应外壳以快照代码为依据；`dqxnxq.do` 在本校是否返回
  `datas.dqxnxq.rows`、`jc.do` 是否返回 `DM`/`KSSJ`/`JSSJ` 均来自金智通行写法，未经真机确认。取不到都有降级与提醒。
- `xnxqcx.do` 的 `*order=-DM` 请求体与 `xnxqcx` 数据键照上游；若本校改了参数或键名，只会失去核对、不会阻断导入。
- 校历请求的 `XN` / `XQ` 由学期编号拆出（上游用的是学期列表行的 `XNDM` / `XQDM`）；若本校编号格式不是
  `学年-学年-学期`，校历只会取不到，parse 按本机日期与 20 周回退并提醒。
- `jc.do` 不读 `SFSY`（上游如此）。若返回停用节次或午休行，会按节号原样写进节次时间；真机上需核对。
- 节次时间没有内置表；`jc.do` 失败时由应用默认节次时间兜底，学生看到的节次时间可能与本学期实际不同，已有提醒。
- H3 顺推从上一节下课推算，不参考应用默认节次表；时间只保证不倒挂、不重叠，不保证与学校一致，已有提醒。
- 上游没有分页；若真实课表分页，当前只读响应里的 `rows`，可能少课，且无法自行识别分页缺失。
- 学期推算沿用上游的月份启发式（9 月～次年 1 月为第一学期）；无当前学期时可能推错，已用提醒说明。
- `scheduleUrlHint` 按任务卡省略；一键刷新会停在 `loginUrl` 的教务首页，需要用户自己点进「我的课表」。
- 模块未从门户点入时金智可能对 wdkb 接口回 403；本移植不做 `dlutci` 那种自动进应用，403 会提示「先点开一次我的课表」。
