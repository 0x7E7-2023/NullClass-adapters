# 安全审计 —— 山东师范大学（正方新版 jwglxt 平台）

审计对象：`jw-adapters/sdnu/` 下的 `extract.js` / `parse.js` / `manifest.json`，以及它们移植自的上游脚本
`shiguang_warehouse` 的 `SDNU/sdnu.js`（快照 commit `ff72d1f08782df965cae110034a9d87cd91e0c07`，
2026-10-08，MIT，上游 `SDNU/adapters.yaml` 的 maintainer 是 `LiquoriceHy`）。

审计方式：逐行读上游脚本与移植件；跑移植手册 §5 的静态扫描（`grep -oE "https?://[A-Za-z0-9.-]+"` 与
`grep -nE "fetch\(|XMLHttpRequest|sendBeacon|new WebSocket|\.src\s*="`，外加 `eval` / `new Function` /
存储 / 页面写入的关键词扫描）。

扫描结果：代码里出现的绝对 URL 只有文件头里写上游出处的 `https://github.com`（注释，不是请求）；
`jwxt.sdnu.edu.cn` 只出现在 `manifest.json` 的 `loginUrl` / `scheduleUrlHint` 数据里，代码里没有写死主机。
网络调用只有 `extract.js` 里的一个 `fetch` 包装函数（`X-Requested-With: XMLHttpRequest` 是请求头，
不是 XHR 对象）。`parse.js` 里没有 `window.` / `document.` / `fetch(` 等页面与网络相关的引用。

## 1. 请求域与请求清单（本节必须与代码一致）

上游 `SDNU/sdnu.js` 里写死的同主机绝对 URL 有三处：登录页判断（第 119 行）
`http://jwxt.sdnu.edu.cn/jwglxt/xtgl/login_slogin.html`、课表接口（第 187 行）
`http://jwxt.sdnu.edu.cn/jwglxt/kbcx/xskbcx_cxXsgrkb.html?gnmkdm=N253508`，以及 `refer` 请求头里的课表首页（第 196 行）。移植件把主机名去掉了：
请求地址全部由 `window.location.origin` + `/jwglxt` 拼出来，所以**主机只有用户当前所在的那一个教务主机**。
正常就是 `loginUrl` 的主机 `jwxt.sdnu.edu.cn`；学生若通过学校的网关或 WebVPN 打开，请求跟着当前源走，
不需要（也没有）额外放行任何域。**`allowHosts` 为空数组，不写通配。**

请求按顺序发出：先（必要时）读学年学期，再取课表；课表回来后，作息与校历两条附加请求并行发出。
所有请求都带 `credentials: 'include'`，请求头只有 `Content-Type` / `X-Requested-With` / `Accept`，
不带任何自定义令牌。

| 谁 | 方法 | 地址 | 干什么 | 取不到时 |
|---|---|---|---|---|
| extract.js | GET | `<origin>/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N253508&layout=default` | 读课表页上的学年学期（`#xnm` / `#xqm`）。**页面上已有这两个字段时跳过这一步**；需要时取一次课表首页，用 `DOMParser` 在内存里解析，**不插入当前页面** | 报错并提示重新登录（没有学年学期就没法查课表） |
| extract.js | POST | `<origin>/jwglxt/kbcx/xskbcx_cxXsgrkb.html?gnmkdm=N253508` | 取课表 JSON（`kbList` 排课行、`sjkList` 集中实践课、可能有的记录总数）。请求体 `xnm=&xqm=&kzlx=ck&xsdm=&kclbdm=&kclxdm=`，与上游逐字一致 | 报错并提示重新登录 |
| extract.js | POST | `<origin>/jwglxt/kbcx/xskbcx_cxRjc.html?gnmkdm=N253508` | 取校区作息（请求体 `xnm` / `xqm` / `xqh_id`） | 交 `null`，parse 回落到内置 12 节作息表并写进 `warnings` |
| extract.js | POST | `<origin>/jwglxt/kbcx/xskbcxZccx_cxZcByXnxq.html?gnmkdm=N2154` | 取学期周次校历（请求体 `xnm` / `xqm`），用于定开学日与总周数 | 交 `null`，parse 回落到推算并写进 `warnings` |

- 后两条附加接口**不在上游 `SDNU/sdnu.js` 里**（已对上游全文检索 `cxRjc` / `Zccx` 核对：没有）。
  它们的路径取自同族正方脚本，见 §8 第 1、2 条。两条都是 best-effort：`optionalJson` 把任何失败
  （非 2xx、网络错误、JSON 解析失败）都吞成 `null`，由 `parse.js` 回落，**回落会出现在导入预览的 `warnings` 里**，不是静默降级。
- `parse.js` 不发任何请求（CI 里用 Rhino 实跑，是纯函数）。

## 2. 读了什么、带出了什么（数据面）

| 数据 | 从哪来 | 怎么处理 |
|---|---|---|
| 学年学期（`xnm` / `xqm` 与下拉框文本） | 课表页的 `#xnm` / `#xqm`，或课表首页 HTML（离线解析） | 随载荷 `term` 交给 parse，用于学期名与学期序号 |
| 排课行 `kbList` | 课表接口 | **字段白名单**：只带 `kcmc` / `xm` / `cdmc` / `xqj` / `jcs` / `zcd`。`xqh_id` 只在 extract 内部用于派生 `campusId` 与作息请求，不进载荷 |
| 集中实践课 `sjkList` | 课表接口 | **字段白名单**：只带 `kcmc` / `zcd`。只有课名与起止周，排不进周课表，但**不能吞掉**：写进 `warnings` 让用户自己加 |
| 记录总数（若响应里有） | 课表接口 | 只取数字，用于和 `kbList` 行数对账 |
| 校区代码 `campusId` | 第一条排课行的 `xqh_id` | 作为 `campusId` 交出。这是校区代码，不是人的标识 |
| 校区作息 | 作息接口 | **白名单**：`jc` / `jcmc` / `qssj` / `jssj`。行数组的找法与 `parse.js` 的 `rowsIn` 一致（各部署的信封不一样）；取不到就是空数组，parse 回落 |
| 学期周次校历 | 校历接口 | **白名单**：`zs` / `zsmc` / `zrq` / `zcrq` / `rq` / `ksrq`。找法同上。只用来算开学日与总周数，**最终课表里不整表带出** |
| **学生个人信息**（课表响应里夹带的 `xsxx` 等） | 课表接口 | **不带出，不进 fixture**：extract 只挑上面列出的字段，其余字段在 extract 里就丢掉 |

静态扫描：请求路径全部在 `/jwglxt/kbcx/` 下（课表页、课表接口、作息、周次校历），**没有成绩、学籍、个人信息、缴费**等其它模块的接口。
扫描无 `password`、`localStorage`、`sessionStorage` 命中；脚本不读表单，不读 Cookie（`credentials: 'include'` 只是让浏览器按同源带上 Cookie，脚本不取它的值）。

## 5. 与模板件的差异（同平台、同批次的正方模板件）

同样是正方新版 `jwglxt`，但不是克隆。本件与模板件的差异：

- **课表主菜单号**：本件 `N253508`（与上游本校一致）；模板件是 `N2151`。
- **课表请求体**：本件带 `kclxdm=`（上游逐字）；模板件的请求体没有这一项。
- **学校作息表**：本件是上游 `TimeSlots` 的 12 节（08:20 起）；模板件的学校作息表是另一套（08:00 起）。本件的内置回落表（应用默认，08:00 起）只用来补超出学校表的节次，不当作本校作息。补的时候：内置表那一节的开始不早于上一节下课才用内置表，否则在上一节下课后顺推（课间 5 分钟、每节 45 分钟），顺推越过 23:59 就不再补（见 §8 第 8 条）。
- **作息接口菜单号**：本件 `cxRjc` 挂 `N253508`（推断，§8 第 1 条）；模板件挂 `N2151`。两条附加接口的路径与校历菜单 `N2154` 相同。
- **字段白名单（本件新增）**：extract 对课表、实践课、作息、校历四类响应都只带 parse 要读的字段，学生信息不出 extract。
- **学期名兜底（本件新增）**：学年读不出来、只剩「第X学期」时，前面补上学校名（`山东师范大学 第一学期`），不拿适配器名当学期名。
- **登录页判断**：本件只看路径是否包含 `login_slogin.html`（上游是 URL 精确相等，见 §6）。
- **`loginUrl` 是 `http`**：上游也是 `http`，本件没有改（见 §8 第 4 条）。
- **校历被判不属于本学期（H1）**：模板只作废开学日、仍用校历的周数定总周数；本件连周数一起作废（同一份校历，周数同样不能用），总周数回到内置 20 周。
- **抬高总周数的提醒（H2）**：模板固定写「教务校历写的一学期是 X 周」，校历没给周数时就成了「是 0 周」；本件按来源分开写（校历给了周数 / 校历没给或已作废）。
- **超出作息表的节次（H3）**：模板无条件用内置表补，补出的时间可能与学校最后一节重叠甚至倒挂；本件先看内置那一节能否接在上一节之后，不能就顺推，顺推越过 23:59 就不补，补的与补不了的都写进 `warnings`。
- **周次括号（X1）**：模板件先删「周」再处理括号，`(1-16周)` 删完成 `(1-16)`，被当成教学班序号整组摘掉，整门课丢失；`1-16周(1,2)` 删掉括号后数字粘成 `161`，整段被读成第 1–30 周。本件先按括号里的内容分类（只有数字和逗号是序号、含别的字是备注、其余保留），然后才删「周」，最后把落单的括号字符换成逗号，不直接删（用例见 §4 第 6 项，备注括号的限制见 §8 第 17 条）。

## 6. 移植时对上游做的删改（都不牵涉安全问题，但审阅者需要知道）

1. **三个弹窗未移植**：`showAlert`（上游第 139 行）、`showPrompt`（第 149 行）、`showSingleSelection`（第 160 行）。
   学年学期改成读页面上的 `#xnm` / `#xqm`。理由：用户已经在教务页面里看见自己选的学期，弹窗让人手填学年反而容易填错。要导入别的学期，在教务页面里切一下再点「提取课表」。
2. **`refer` 请求头未搬**（第 196 行）：`refer` 不是合法的 fetch 选项，浏览器会忽略；`Referer` 由浏览器按当前页面自动带。
3. **登录页判断放宽**（第 117–123 行）：上游 `url === loginUrl` 是精确相等，带参数的登录页地址会漏判。本件改成看路径。
4. **主机名不再写死**（第 119、187、196 行的 `jwxt.sdnu.edu.cn`）：改为 `window.location.origin`，跟随当前源（含网关前缀）。
5. **桥调用全部未移植**：`showToast`、`savePresetTimeSlots` 等（第 279–289 行一带）。落库与提示由 App 侧负责，移植件只交出数据。
6. **固定 `TimeSlots` 的导入未移植**（第 260–273 行与第 348 行 `importPresetTimeSlots`）：改为载荷带 `periodTimes`，教务作息优先；取不到时用同一张表回落，并写进 `warnings`。
7. **周次解析静默丢课**（第 8–48 行 `parseWeeks`，上游只按逗号切段，且只认 `\d+-\d+周` 与 `^\d+周`）：
   - `1-3,5-9周`：`1-3` 段里没有「周」字，匹配不上，**`1-3` 周静默丢掉**，只剩 5–9 周。
   - `1-3周 5-9周`（空格分段）：整串只按第一个 `1-3周` 匹配，**`5-9` 周静默丢掉**。
   - `1-16(单周)`：「周」不紧跟数字，整段匹配不上，**整门课被跳过**（`weeksArray.length === 0` 时直接 `continue`）。
   - 独立写成「单周」「双周」的段：没有周次数字，同样跳过。
   本件的写法见 `parse.js` 文件头 ①–②（周次）与 ④（节次），用例见 §4 第 6 项。
8. **行过滤静默丢课**（第 67–70 行）：`kcmc` / `xm` / `cdmc` / `xqj` / `jcs` / `zcd` 任一为空就 `continue`，不计数、不提示。
   本件只要求课名、星期、节次、周次；缺教师或缺教室的课保留，`teacher` / `location` 为 `null`。跳过的行按原因计数写进 `warnings`。
9. **节次解析错误**（第 80–82 行 `jcs.split('-')`）：`0102` 被 `Number` 读成 102，**当作第 102 节放行**（起止相等，不会被校验挡掉）；`1,2` 这种逗号写法 `Number` 得 `NaN`，**静默跳过**；`3-4节`、`第9-10节` 同理（`Number('4节')`、`Number('第9')` 得 `NaN`），也**静默跳过**；`1-2,5-6` 按 `split('-')` 只取首尾，得 1–6，**3–4 节静默并入**。
