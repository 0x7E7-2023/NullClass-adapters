## 0. 出处、平台与模板

- 上游 `XZIT/xzit_01.js`：正方 jwglxt 学生课表查询页。做法是 `fetch(window.location.href)` 把**当前页**再取一遍，
  判断文本里有「课表查询」；再看 `#shcPDF` 的 `data-type`（`list` 用 `#kblist_table`，否则 `#kbgrid_table_0`）；
  然后用页面上的 jQuery 逐格读课程块，写死 14 节节次时间，`firstDayOfWeek = 1`，总周数取课表里出现的最大周。

  批次七至十九的审计修正（前缀与后缀单双标记各归各段、共 N 周只剥备注、`<= end + 1` 合并重复行、提醒限长）。
  zust 的接口取数、WebVPN 双主机、校区节次时间、校历、实践课部分在本校不存在，已整段删掉（见第 4、5 节）。

## 1. 请求清单（与 `extract.js` 逐条对应）

**本件不发任何请求**：只读当前页面的 `document.documentElement.outerHTML`，再用离线 `DOMParser` 解析。
上游那一次 `fetch(window.location.href)` 取的就是同一个页面，数据完全一样，去掉它不改变结果。

| 方法 | 地址 | 干什么 | 取不到时 |
|---|---|---|---|
| GET（上游） | `window.location.href`（当前课表页） | 上游把当前页再取一遍 | 上游报错；本件改为直接读当前页，不需要这次请求 |

入口判断（`onJwHost` / `onLoginPage`）：主机必须是 `jwglxt.xzit.edu.cn`，路径含 `login_slogin.html` 视为登录页；
两者都不满足或页面文本里没有「课表查询」时直接给大白话报错，**不发请求**（冒烟 `auth` / `loginpage` / `notschedule` 覆盖）。
页面里找不到 `#shcPDF`、或按 `data-type` 找不到对应的课表表格时，也直接报错并提示先点「查询」、等课表显示出来。

## 2. 读了什么、交出去什么（逐字段）

网格视图（`parseGrid` / `gridRow`）：`#kbgrid_table_0 td.td_wrap`，id 拆出星期；每个 `.timetable_con.text-left` 是一门课；
课名取 `.title font` 并去掉 `●★○`；`p[0]` 的第 2 个 `font` 是「(1-2节)1-16周」，按 `节)` 切成节次与周次；
`p[1]` 是上课地点（取空白分隔的最后一段），`p[2]` 是教师。

列表视图（`parseList`）：`#kblist_table` 的 `tbody` 序号 1..7 = 星期；跳过每个 `tbody` 的第一行；
第一个 `td` 是节次（续行没有这个格子，沿用同一 `tbody` 里上一行的节次）；课名取 `.title`，`p font` 依次是

不带出：学号、姓名、身份证号、手机号等任何学生信息；页面里别的内容；页面 HTML 本身。
冒烟里在页面正文塞了四个假个人信息串，交出的 JSON 与载荷里一个都没有。

## 3. 移植手册 §5 八条逐条结论

1. **不碰凭据**：不发请求，不读 Cookie / localStorage / sessionStorage，不碰账号密码。通过。
2. **不外发**：零请求；`allowHosts` 只声明 `jwglxt.xzit.edu.cn`。`extract.js` 代码里没有任何绝对地址。通过。
3. **只读课表**：只读当前课表页的表格与学年学期下拉框，不碰成绩、学籍、个人信息。通过。
4. **字段白名单**：见第 2 节，行对象只有六个字段。通过。
5. **不埋点**：无 `sendBeacon` / `WebSocket` / `Image` 上报。通过。
6. **不动态执行**：无 `eval` / `new Function`。`DOMParser.parseFromString` 只解析当前页 HTML，不执行页面脚本、不加载子资源。通过。
7. **不写页面、不提交表单**：只读 `outerHTML` 与两个下拉框，不写 DOM、不提交。通过。
8. **不硬编码秘密**：无任何账号、学号、令牌。通过。

## 4. 与模板 `zust` 的差异

- **取数**：接口 JSON + 校历 + 校区节次时间 → 只读当前页 DOM，零请求。
- **主机**：WebVPN 子域名 + 直连双入口 → 单一主机 `jwglxt.xzit.edu.cn`。
- **节次时间**：教务接口取 / 空课默认 12 节 → 上游写死的 14 节（逐节照抄）；H3 顺推逻辑沿用，提醒里写「学校公布的节次时间」。
- **开学日**：优先教务校历 → 没有校历，一律按学期序号推算（第一学期 9 月 1 日所在周的周一、第二学期 2 月 20 日所在周的周一、
  夏季学期 7 月 1 日所在周的周一），推算结果写进提醒。
- **总周数**：优先教务校历 → 没有校历用 20 周，课表里有更晚的周次才抬到那一周并提醒。
- **校区**：删掉；地点只写教室名，合并键不再含校区号。
- **集中实践课 / 记录总数 / 学期回显核对**：本校本校页面没有这些数据，删掉。
- **占位词**：新增 `realOrEmpty`——教师 / 教室写成「未知」「待定」「暂无」「无」（可带「教师」「老师」「教室」「地点」）时交 `null`。
- **合并**：阶段 1 的相邻条件用 `next.start <= current.end + 1`（批次十九 xsyu），重复行与重叠行都并成一段。
- **空值提醒**：缺教师 / 缺教室按课名汇总并截到 20 字；缺课名 / 星期 / 节次 / 周次的行只跳过并计数，不静默丢课。

## 5. 上游里被删掉 / 改掉的东西及理由

- **`fetch(window.location.href)` 取整页 HTML**：取的就是当前页，改成直接读 `document.documentElement.outerHTML`，少一次请求。
- **jQuery 依赖与「缺 jQuery 就报错」**：改成 `DOMParser` + 原生选择器，缺 jQuery 不再影响；这条报错整段删掉。
- **`showAlert` / `showToast` / `notifyTaskCompletion` / `saveImportedCourses` / `saveCourseConfig` / `savePresetTimeSlots`**：
  「拾光」的桥能力，空课由宿主保存，适配器只交数据；节次时间随载荷的 `periodTimes` 一起交。
- **「缺教师 / 教室 / 节次 / 周次就整行丢弃」**（`parseTable` / `parseList` 末尾的 `if (name && position && teacher && ...)`）：
  改为缺教师 / 教室照常导入（`null`）并汇总提醒；缺课名 / 星期 / 节次 / 周次的行计数进「数据不全」提醒。
- **`buildCourseConfig` 用课表最大周当学期总周数**：改成 20 周兜底，课表里更晚的周次才抬高并提醒（公共口径）。
- **`config.firstDayOfWeek = 1`**：空课没有这个字段，语义落在 `firstDay` 的星期几上——推算时取周一（手册 §4.3）。
- **启动时的确认弹窗**：空课点「提取课表」即导入，不需要。
- **学年学期**：上游压根没读学期下拉框；这里补读 `#xnm` / `#xqm`，只用于学期名与开学日推算，读不到就用「徐州工程学院 第 X 学期」并推算。

## 9. 已知风险与未验证项

- **没有本校账号，真机没验过**：网格页 `p` 的三行顺序、`#shcPDF` 的 `data-type` 取值、列表视图 `tbody` 序号与续行结构，
  全部来自上游代码，没有拿真实页面核对过。
- **页面结构变了就会少课**：`p[0]` 第 2 个 `font` 若不是「(1-2节)周次」，节次与周次会读不到，行会进「数据不全」提醒——
  不会静默丢课，但用户会看到课少了，需要按反馈修选择器。
- **列表视图续行沿用上一行节次**（与上游相同）：如果同一 `tbody` 里出现「首列为空但其实是另一门课」的行，会沿用错节次。
- **开学日是推算值**：本校教务页不给校历，第一 / 第二 / 夏季学期的锚点是通用经验值，提醒里已如实说明，用户需在学期管理里核对。
  学期下拉框读不到时默认按第一学期推算。
- **节次时间 14 节来自上游写死表**：学校调整作息后需要改 `BUILTIN_PERIOD_TIMES`。
- **`scheduleUrlHint` 的菜单号 N2151** 是正方学生课表查询的标准菜单号，本校实际值未经真机验证；
  该字段是「一键刷新时优先打开的课表页」，所以写完整地址，大白话提示放在报错里。
