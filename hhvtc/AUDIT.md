## 0. 移植前分析与模板选择

任务卡建议模板 `hlju`（相似度 0.427，`upc-grad` 次之）。通读本校上游后确认：可以复用 `hlju` 的周次显式集合切极大段、单双标记归属、共 N 周备注剥离、重复行先去重、提醒统一限长和超出节次表后的补时思路；**取数与课程文本结构不能复用**。

- `hlju` 来自选课 JSON 响应，课名、教师、周次、地点混在 `SKSJ`，星期与节次另在 `KEY`、`KSJC`、`JSJC`。
- 本校青果课表的 `.have-content` 可见格可能为空，真实课程位于标识以 `weekly0` 开头的隐藏详情区，每项是 `ul/li` 的「课程名称 / 任课教师 / 上课时间 / 上课地点 / 合班信息」。上课时间集中写成 `[周次]星期[起止节次]`。
- 本校上游通过主文档、同源 `iframe` 与 `frame` 查详情，最长等待 6 秒；没有任何 `fetch`、表单提交或课表接口地址。
- 因而本校是**结构化 DOM 文本**，不是 canvas 或课表图片，不需要 `kind:"image"`、OCR 或 `kind:"boxes"`；直接保留课程文本让 `parse.js` 转换更准确，也避免把页面其他文字带出。
- 上游有两套 8 节时间，5 月至 9 月默认夏秋，其余月份默认冬春，并弹窗让用户改选。本移植按公共说明取消提问，以提取日期自动选择，并始终提醒核对。

本校专属验证点：隐藏详情区而非可见格、同源内嵌框架、四项字段白名单、两套 8 节时间、单节与连堂、稀疏周次、前置和后置单双标记、重复详情计数、缺教师与地点、长提醒、登录和门户零请求。

## 2. 读了什么、交出去什么（逐字段）

| 数据 | 从哪来 | 是否带出 extract.js |
|---|---|---|
| 课程名称 | 隐藏详情区中含「课程名称」的 `li`，取首个中英文冒号后的文字 | 带出为 `details[].name` |
| 任课教师 | 含「任课教师」的 `li` | 带出为 `details[].teacher`；教师属于课程信息 |
| 上课时间原文 | 含「上课时间」的 `li` | 带出为 `details[].timeText`，由 parse.js 解析周次、星期、节次 |
| 上课地点 | 含「上课地点」的 `li` | 带出为 `details[].location` |
| 本地日期 | 浏览器时钟 | 带出为 `today`，用于推学期、开学日和季节节次表 |
| 合班信息、详情区标识、可见格文字、页面标题、其他 `li` | 当前课表页 | 不带出 |
| 学号、学生姓名、证件号、手机号、人员标识、账号、密码、 Cookie、存储令牌 | 不读取 | 不带出；脚本没有相应读取逻辑 |

输出形状固定为 `{ today, details }`。每项详情在 `readDetails()` 中新建且仅有 `name`、`teacher`、`timeText`、`location` 四个键，不把原始元素、整段详情文字或响应对象交出。即使可见格或合班信息含个人信息，也不会进入输出。

## 3. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。只检查密码框元素是否存在；不读密码值、Cookie、localStorage、sessionStorage 或令牌，也没有提问。
2. **不外发**：通过。两段脚本均无网络请求，无第三方地址，无统计图片、信标或套接字。
3. **请求域可控**：通过。`allowHosts` 为空，根入口主机为 `jwgl.hhvtc.com.cn`，没有额外请求域。
4. **只读课表**：通过。只读课表隐藏详情区的四种课程文本和本地日期，不读成绩、学籍、个人信息、缴费等页面。
5. **不埋点**：通过。无统计、上报、遥测或日志外发。
6. **不执行远程代码**：通过。无动态代码执行；parse.js 只做固定 JSON 解析与字符串转换。
7. **不写页面**：通过。不写 DOM、不插入节点、不点击、不改表单、不提交。
8. **不依赖额外秘密**：通过。无固定令牌、秘密、真实学号或他人信息；fixtures 全为合成课程和虚构教师代称。

## 4. 与模板 hlju 的主要差异

1. **取数**：模板有两条同源 JSON 请求；本校零请求，从主文档或同源内嵌框架的 `weekly0` 隐藏详情区取四项文本。
2. **课程结构**：模板解析 `SKSJ` 多行与 `KEY/KSJC/JSJC`；本校从 `[周次]星期[起止节次]` 一次取周次、星期与节次，课程名、教师、地点已有独立标签。
3. **节次时间**：模板固定 12 节；本校逐节保留上游夏秋和冬春两套 8 节，按提取月份选择，第 9 节起顺推。
4. **学期信息**：模板使用接口给的学年学期；本校上游没有学期文字，按提取日期推学年学期与开学日，默认 20 周，全部提醒。
5. **交互**：本校上游的开场确认和节次选择弹窗均删除；不调用拾光提示、保存和完成通知桥，空课宿主负责保存。

周次切段、前置与后置单双标记、共 N 周剥离、重复详情先去重、缺失字段汇总提醒、课名截短和 H3 补时继承模板已审计思路，但输入形状和计数均按本校重写。

## 5. 上游里删掉或改掉的东西及理由

- 删除 `showAlert`、`showSingleSelection`、`showToast`、`saveImportedCourses`、`savePresetTimeSlots`、`notifyTaskCompletion`、`console.error`：这些是上游交互与保存流程，空课只接受课表载荷。
- 删除 `getErrorMessage()` 的原始异常序列化展示：错误统一改为学生可操作的提示，不暴露实现细节。
- 保留轮询与三类同源文档查找；跨域内嵌框架仍只捕获访问异常并忽略，不尝试绕过同源限制。
- 上游在 extract 阶段直接算星期、节次、周次数组并合并课程；本移植只搬四项原文，全部计算移到可测试的 parse.js。
- 上游缺教师写「未知」、缺地点写「待定」；现统一把空值和「未知 / 待定 / 暂无 / 暂无教师 / 暂无教室」转为 `null`，课程仍导入并汇总提醒。
- 上游只认逗号分隔连续周；现增加单双标记、无逗号前置标记、标记与周次之间的空格或逗号（前置标记交给后一个周次段）、`第1-第8周`、共 N 周备注剥离、稀疏周次极大段与超界保护，无法识别时计数提醒。
- 星期写法放宽：`[周次]星期X[节次]`、`[周次]周X[节次]` 与 `[周次]X[节次]`（裸汉字一～六/日/天）都可识别，周日与周天都算第 7 天。此前只认「星期」前缀，课表详情里写「周一」「三」这两种最常见形状会被当成缺星期跳过。
- 上游一格里只取第一个星期段与第一个节次段，后面再写的节次段静默消失（上游同样）。本移植仍只导入第一段——多段的星期与周次归属要靠猜，规范要求不猜；改为数出「一格内连着写多个节次段」的条数并提醒，不静默丢课。
- 上游合并键为课名、教师、地点、星期、起止节次并取周次并集，本移植保留；输出再按课名与教师组成课程，不同节次不合并。完全重复详情在解析与计数前去重。
- 上游没有学年学期、开学日、总周数来源：按提取日期推学期，第一学期以 9 月 1 日所在周周一、第二学期以 2 月 20 日所在周周一为第 1 周，总周数先取 20；更晚上课周才抬高，均有提醒。
- 上游节次弹窗改为按提取月份自动选表，避免询问；提醒明确提取日期和季节，查询其他学期或学校调整时需核对。
- 第 9 节起按课间 5 分钟、每节 45 分钟逐节顺推；若结束越过 23:59 则停止补时，课程不丢并说明从哪节起缺时间。
- 所有拼入提醒的课名、学期名、周次原文先经 `shortName()` 截到 20 字，所有提醒再统一经 `warn()` 限 200 字、20 条；缺教师与地点指向「编辑课程」。

## 7. fixtures 与独立期望

共 10 对，全部为合成输入。期望值在运行 parse.js 前按上游格式、规范与本文件规则手工推演写入，不是把当前输出保存为期望。

1. `basic-summer`：夏秋 8 节、连续周、单周、单周次、占位教师与地点、四类不完整详情。
2. `winter-second-extend`：第二学期、22 周抬总周数、第 9-10 节补时、第 16 节起无法落在当天。
3. `week-markers`：前置、后置、无逗号前置与后置单双标记，共 N 周只剥备注，`第1-第8周`。
4. `merge-duplicates`：同课同节次周次并集、不同节次保留、三条重复详情的备注计数不放大。
5. `long-warnings`：四门长课名缺教师或地点，三条长周次不可识别，原文截短且每条不超 200 字。
6. `january-single-period`：一月仍属上一学年第一学期，双周文字与单节第 8 节。
7. `sparse-weeks-second`：五月第二学期，多个独立区间与交错周次切极大段，不补入未上课周。
8. `weekday-short-forms`：周一至周日七种简写全部落对天，周日第 3-4 节不按缺星期跳过，`星期一/星期日` 完整写法仍兼容。
9. `multi-segment`：一格内连着写多个节次段时只导入第一段并计数提醒，其余段不静默丢课；同一时间的第三段也只计一次。
10. `marker-before-separator`：单双标记与周次之间用空格或全角逗号隔开时属前置写法，标记交给后一个周次段，双周落第 2-8 周、单周落第 9-15 周。
