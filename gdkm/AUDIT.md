# 广东科贸职业学院（gdkm）移植审计

## 出处

- 上游文件：`resources/GDKM/GDKM.js`，作者 qwwshs。快照提交 `03d161a`（2026-11-01 与 origin/main 对齐）。本校脚本最后一次修改 `08b0e02`（`improve：更新广东科贸的教务系统适配`），与任务卡一致，没有改快照。
- 上游 `resources/GDKM/adapters.yaml`：adapter_id `GDKM`，名称「广东科贸职业学院强智教务」，import_url `https://aic.gdkm.edu.cn/cas_server/login`，maintainer `qwwshs`。登录页不采用这条认证地址。主调度已定 `loginUrl` 为 `https://jw.gdkm.edu.cn/jsxsd/`，`allowHosts` 为 `[]`，`scheduleUrlHint` 为 `https://jw.gdkm.edu.cn/jsxsd/xskb/xskb_list.do`。
- 模板：任务卡指定已审计的 `zsc`（强智 `/jsxsd/`）。周次切段、提醒限长、缺教师缺教室、超出节次的占位沿用 `zsc` 的 `weeksIn` / `runsOf`。课表形态不同构：`zsc` 读 `div.kbcontent` 网格，本校上游读 `table.qz-weeklyTable` 里的 `li.courselists-item`，取数按 `GDKM.js` 重写，不照抄 `zsc` 的 POST 接口。

## 本校与模板不同的地方

1. 只发两个 GET，都是上游写死的绝对地址改成的同源相对路径：教学周历 `GET /jsxsd/jxzl/jxzl_query`，课表 `GET /jsxsd/xskb/xskb_list.do?viweType=0&xnxq01id=<学期>&zc=`。参数名 `viweType` 少一个字母，与上游一致。没有 POST，没有作息模式下拉框。
2. 节次时间是上游 `saveAppTimeSlots()` 写死的 12 节，不是 `zsc` 的 12 节时刻。第 6、8、10、12 节只有 30 分钟，照抄，不改。
3. 节次优先取时间字段方括号里的数字（`periodsFromSpec`）；没有方括号再用行首「(01、02小节)」或「第N，M节」，数字全部取值（`periodsFromLoose`）。
4. 星期按上游的跨行占位：`rowspan` 占用的列在下面几行空出来，不能按格子下标当星期。
5. 周次是文字。`(单)1-8周(双)9-16周` 收成单周 1–7 与双周 10–16，不是 1–16 每周。后置 `1-8周(单)9-16周(双)`、逗号后置 `1-8周(单),10-16周(双)`、「第1-第8周」、「共 N 周」只剥备注，都有用例。
6. 总周数以周历「第 N 周」的最大 N 为准。没有周历才用 20。课表里有更晚的周次才抬高并提醒。不把课表最大周当成学期长度，也不采用 `zsc`「周历不足 8 周就丢掉」的做法。
7. 开学日按上游：第 1 周星期一的日号，配星期六格子里的「M月D日」；星期一数字更大则月份减一（`firstMondayFromCalendar`）。算出来不是星期一就对齐到周一并提醒。
8. 上游弹窗选学期。改为读周历页 `#xnxq01id` 的当前选中项，不弹窗。校区选择在上游已被注释，不恢复。
9. 同一门课、同一天、同一套周次，节次重叠或下一节正好接着（起点不大于上一段终点加 1）合成一段，同一节的重复行不会叠成两门。
10. 登录页、统一认证页、学校主页不发请求（`loginHint`）。

## 请求清单

只在 `loginHint` 通过之后发请求。地址都是相对路径，主机只能是打开页面的 `jw.gdkm.edu.cn`。

| 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|
| GET | `/jsxsd/jxzl/jxzl_query` | 无 | 读 `#xnxq01id` 的选中项（`termOf`），并带走周历行（`calendarOf`） | 页面标题像登录且没有学期：报「登录已失效」。没有选中项：报「找不到学年学期」，不再请求课表。网络失败或状态码不对：报「连不上教务系统」或「教务系统返回错误（代码 N）」 |
| GET | `/jsxsd/xskb/xskb_list.do?viweType=0&xnxq01id=<学期代码>&zc=` | 无 | 整学期课表。卡片只留课名和「老师 / 时间 / 地点」原文（`timetableOf`） | 没有课程卡片：报「没有找到课程」。被转到别的主机：报「登录已失效」 |

登录页判断在任何 `fetch` 之前：主机不是 `jw.gdkm.edu.cn`，或路径是 `/`、`/jsxsd`、`/jsxsd/`、`/jsxsd/index`、`/jsxsd/login`、`/jsxsd/xk/LoginToXk`，直接提示，不发请求。认证中心 `aic.gdkm.edu.cn` 不加入白名单。

## 读了什么、交出去什么

读取面只有这些：

- 地址的协议、主机、路径（不要查询串）。
- 周历页 `#xnxq01id` 的选中值与显示文字。
- 带 `qz-weeklyTable-label` 的行：周次标签，以及该类名下 `qz-weeklyTable-normalDay` 格子的文字。
- 含 `td[name=kbDataTd]` 的表：行首 `td[name=timeTd]` 的文字、每个课表格子的 `rowspan`、`li.courselists-item` 的课名和缩略文字。

不读学号、姓名、身份证号、手机号、隐藏令牌。这些即使出现在页面上，也不放进交出去的对象。

`extract.js` 交出去的字段：`source`、`pageUrl`、`now`、`term.code`、`term.name`、`calendar.weeks[].label`、`calendar.weeks[].days`、`rows[].sectionText`、`rows[].cells[].rowspan`、`rows[].cells[].items[].name`、`rows[].cells[].items[].abbr`。

`parse.js` 交出去的载荷：学期名、开学日、总周数、节次时间、课程的课名 / 教师 / 地点 / 星期 / 节次 / 周次段。教师、地点是「未知」「待定」「暂无」，或「暂无教师」「暂无教室」这类占位，就写成空，不把这些词交出去。

## 上游里删掉或改掉的

| 上游 | 本件 | 理由 |
|---|---|---|
| `showSingleSelection` 选学期 | 读下拉框选中项 | 移植约定不弹窗问学年学期 |
| 已注释的校区选择 | 不恢复 | 上游自己关掉了，课表不依赖校区 |
| `showPrompt` 手填开学日、周数、学年 | 推算失败才提醒，不打断去问 | 空课用提醒，不用上游的输入框 |

| 教师、教室缺了写成「未知教师」「未知地点」 | 空值，并按课汇总，提示到「编辑课程」补 | 占位词会被当成真名；学期管理只改学期信息 |

## 已知风险

- 没有本校账号，真页面没验过。周历若不用 `qz-weeklyTable-label` / `qz-weeklyTable-normalDay` 这两个类名，开学日和周数会走兜底并提醒。
- 周历只有「M月D日」、没有年份时：8–12 月用学期代码的起始年，1–7 月用结束年。2025-2026 学年第二学期的 2 月 3 日是 2026-02-03，不是 2025-02-03。星期一退到上一个月时，按退完的那个月取年。
- 占位节次从第 13 节的 20:00 起，和晚上已有节次的真实时间可能重叠，只靠提醒说明。
- 周历请求本身失败会整次报错，不会悄悄改用 20 周。只有周历打开了但数不出「第 N 周」时才按 20 周。
