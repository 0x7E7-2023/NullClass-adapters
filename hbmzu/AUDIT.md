## 0. 平台与上游

本校是自研 MVC 教务（`.mvc` 服务端渲染），课表分两块：

1. **理论课表**：`/edu/report/mySchedule.mvc`。页面里 `#container` 内每行 `tr` 的首个 `td` 是节次（「上午1-2节」「晚上11-12节」…），
   后面 7 个 `td` 对应周一~周日；每格 `.course-block` 里有若干 `span`，上游按「哪个 span 长得像周次」定名称 / 教室 / 周次 / 教师，
   无教室时只有 3 个 span。页面可能在 frameset / iframe 里（上游 `collectDocs()`）。
2. **实验课表**：先 GET `/edu/report/myLabSchedule.mvc`，页面里用脚本声明学号 / 学年 / 学期；再按周 GET
   `/edu/report/stuLabCourseTable/{学号}/{学年}/{学期}/{周}.mvc`，返回 `sheduleTable`（大节 × 星期，单元格内 `lessons`）。

选模板：本批任务卡指定借 `suda` 的 DOM 取数与解析骨架（服务端渲染表格、可见文字提取、隐藏元素过滤、`weeksOf` 周次解析、
`runsOf` 极大段、提醒限长出口、H3 节次补全、缺教师 / 缺教室汇总），取数与课程拼装按本校上游重写。库里没有同平台的已移植件。

## 1. 请求清单（与代码逐条对应）

| # | 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|---|
| 1 | GET | `{ctx}/report/myLabSchedule.mvc` | 无（只带浏览器 Cookie） | 读实验入口页里声明的学号 / 学年 / 学期；学号只用来拼第 2 条地址 | 返回非 200、页面里缺 id / openYear / openTerm 之一 → `labStatus: "no-entry"`，理论课表照常导入并提醒 |
| 2 | GET | `{ctx}/report/stuLabCourseTable/{学号}/{学年}/{学期}/{周}.mvc`（第 1 周后每次 5 周并发） | 无 | 取该周实验课表（`sheduleTable`） | 该周 `ok: false`；第 1 周失败 → `labStatus: "first-week-failed"`；都不影响理论课表导入 |

`ctx` 由当前页 `pathname` 推到 `/report/` 或 `/mainpage/` 之前的部分（`getContextPath`，推不出回落 `/edu`），不写死主机。
第 2 条地址里出现的学号只来自用户自己已登录的实验入口页，**只在 extract.js 的闭包里拼接地址，不写进输出、不写进提醒**。

不发请求的情形（都在取数之前判断）：
- 当前主机不是 `jwgl.hbmzu.edu.cn` → 抛「当前页面不是湖北民族大学的教务系统…」（`extract.js:367`、`onJwHost`）；
- 找不到 `#container`：路径是根 / `/edu` / `/edu/` 或含 `login` / `cas` / `auth` → 抛「当前打开的是登录页或门户页…」；
  其它路径 → 抛「没有找到课表…」（`extract.js:369`–`370`、`onLoginPage`）。登录页 / 门户页上零请求。

提问桥：**一次都不用**。没有校区 / 季节 / 学期分支需要问用户。

## 2. 读了什么、交出去什么（逐字段）

`extract.js` 交给 `parse.js` 的对象（`JSON.stringify` 后的字符串，`extract.js:401`）：

| 字段 | 内容 | 来源 |
|---|---|---|
| `today` | 提取当天日期（本地日期，不用 `toISOString`） | 本机时钟 |
| `term.year` | 实验入口页 `openYear` 的 4 位年份 | 实验入口页正则 |
| `term.semester` | 实验入口页 `openTerm`（原样字符串，parse 只认 1 / 2） | 同上 |
| `rows[].day` | 1..7 | 理论课表 `td` 的列序（首 td 之后的第 n 个） |
| `rows[].section` | 节次原文（如「上午1-2节」），截 120 字 | 该行首个 `td` 的可见文字 |
| `rows[].spans` | 该 `.course-block` 内每个可见 `span` 的文字，各截 120 字 | `visibleText` + `hiddenWithAncestors` |
| `labStatus` | `ok` / `no-entry` / `first-week-failed` | 第 1、2 条请求的结果 |
| `labWeeks[].week` / `.ok` | 周号 / 这一周有没有取到 | 请求顺序与结果 |
| `labWeeks[].lessons[]` | 每门课只交 `name` / `teacher` / `location` / `day` / `start` / `period` / `week` 七个字段 | `sheduleTable` 的 `lessons` |
| `labTruncated` | 实验周数超过 30 时只取前 30 周，交 `true` 让 parse 提醒 | 第 1 周的 `totalWeeks` |

学生个人信息（学号、姓名、身份证号、手机号）不进输出：理论格子只读看得见的 `span`，`hidden` / `display:none` /
`visibility:hidden`（内联或计算后）以及祖先被隐藏的整棵子树都跳过；实验数据按上面的字段白名单挑，
`sheduleTable` 里若夹带学生信息不会带出。冒烟场景 `normal` 往格子里塞了学号 / 姓名 / 手机号（隐藏 `span`），
并在实验入口页放了姓名 / 身份证号，输出里都找不到（§8）。

`parse.js` 是纯函数：输出里的教师名只是课表本来就显示的任课教师，不含学生信息。

## 4. 给学生看的文字

`extract.js` 的报错与 `parse.js` 的 warnings 都按 `docs/ux-writing.md` 写：不出现「接口」「载荷」「上游」「脚本」「字段」
「课程块」「组件」「模板」「HTTP」「JSON」「DOM」「HTML」「null」「undefined」「学期设置」「作息表」；时间表统一叫「节次时间」；
改学期名、开学日、总周数、节次时间指向「学期管理」，改教师 / 教室指向「编辑课程」。
带课名的提醒课名截到 20 字、最多点名 3 门；认不出的原文同样截 20 字；每条都经过 `warn()`（`parse.js:162`）再截到 200 字以内。
fixture `long-warnings` 钉住长课名 + 多条缺项时全部提醒 ≤200 字。

提醒清单（顺序固定）：① 学期来源（实验入口页的学年学期 / 按今天的日期推算并冠学校名）；② 开学日是推算的；
③ 总周数（默认 20，课表更晚才抬高）；④ 节次时间取自上游写死的 12 节表；⑤ 表外节次的补齐（空课默认 / 顺推 / 补不了）；
⑥ 理论课表被跳过的行（缺课名 / 星期 / 节次 / 周次分类计数 + 认不出的原文）；⑦ 实验课表被跳过的记录（同类计数）；
⑧ 实验入口打不开 / 第 1 周失败 / 某几周没取到 / 只取到第 30 周；⑨ 缺教师 / 缺教室汇总；⑩ 周次里的序号括号 / 备注括号 /
越界周次 / 孤立单双标记 / 单双同写。

## 5. 与模板（suda）的差异

借的是解析骨架：可见文字提取 `visibleText` / `hiddenWithAncestors`、`weeksOf`（前缀 / 后缀单双标记归属、`第1-第8周`、
「共 N 周」只剥备注、序号 / 备注括号、全角标点）、`runsOf`、`warn` 限长出口、H3 节次补全、缺教师 / 缺教室汇总。
取数与课程拼装按本校上游重写：

1. **两路取数、合并成一张课表**：理论课表零请求只读当前页 DOM；实验课表走两条同源 GET（§1）。suda 是纯 DOM。
2. **span 归属**（`parse.js:330` 起）：从第 2 个 span 起找周次，前一个是教室、后一个是教师；3 个 span 的两种结构都接住。
   suda 解析的是「周一第3,4节{第1-17周}」时间行。
3. **合并分两步**（`parse.js:469` 起）：先按上游 `mergeCourses` 的口径把「课名 + 教师 + 教室 + 星期 + 首末节」相同的并周次，
   再把同周次的相邻节次并段；理论与同一门实验课因为时间地点相同会合并，周次取并集。
4. **学期与开学日**：学期取实验入口页的学年 / 学期（拿不到按今天推算并冠「湖北民族大学」）；开学日按今天的日期回退到本周周一
   （`parse.js:599`）。suda 按 9 月 1 日 / 3 月 2 日两个锚点推。
5. **总周数**：实验课表第 1 周的 `totalWeeks` 只用来决定翻几页，**不当作学期长度**；载荷按公共口径取 20，课表更晚才抬高（`parse.js:602`）。
6. **节次时间**逐节照抄本校上游 `HBMZU_TIME_SLOTS`（12 节，08:00–21:50），与 suda 的 12 节表数值不同。
7. **实验失败不影响理论**：`labStatus` / `labWeeks[].ok` 把失败拆成提醒，suda 没有这一层。

## 6. 上游里删掉 / 改掉的东西及理由

| 上游 | 处理 | 理由 |
|---|---|---|
| `showAlert` 确认框、`showToast` 进度条、`saveImportedCourses` / `savePresetTimeSlots` / `notifyTaskCompletion` | 去掉 | 拾光的桥能力；空课由宿主保存，适配器只交数据 |
| 上游 `runImportFlow` 的弹窗里说「将同时导入理论课表与实验课表」 | 去掉 | 宿主统一显示导入预览，适配器不弹窗 |
| `mergeCourses` 用 `Map` / 展开 / `Array.from(new Set(...))` | 改成对象字典 + 数组并集 | ES5 |
| 格子里 `span.textContent`（隐藏元素也读） | 逐节点取可见文字，祖先被隐藏整格不读 | 公共说明第 3 条：个人信息不许带出 |
| 上游要求 `id` + `openTerm` 就能拼实验地址，缺 `openYear` 时用本机日期兜底 | 三个值缺一个就整段实验课表不导入并提醒 | 不向教务发残缺地址，也不猜学年 |
| 实验入口 / 第 1 周失败时只弹一句提示 | 交 `labStatus` / 每周 `ok`，由 parse 汇总进 warnings | 失败原因要能被看到，且理论课表不许被拖垮 |
| 上游 `parseWeeksText` 只认 `^\d+-\d+(单|双)?周$` | 放宽到多段、前置 / 后置单双、`第1-第8周`、全角标点、`共 N 周` | 公共说明与批次十八 / 十九的既有修正 |
| 教师 / 教室缺一个就整块 `continue`（上游按 span 位置取值，缺了就是空串，但空串会被当成真值写进载荷） | 占位词（未知 / 待定 / 暂无 / 无）与空串一律 null，按类型汇总提醒 | 手册 §4.7 与公共说明第 4 条 |
| 上游注释「无开学日期接口，不写课表配置」 | 推算本周周一并提醒 | 载荷 `firstDay` 必填，手册 §4.2 要求如实说明 |
| `console.error` / `showToast` 里的原始错误文本 | 一律换成大白话提示，原始错误只用于开发诊断 | `docs/ux-writing.md` |

新增（上游没有）的：登录页 / 门户页 / 非本校主机的判断与零请求提示、`#container` 缺失与空课表的区分、隐藏元素与祖先隐藏过滤、
实验记录字段白名单、跳到失败周 / 第 30 周上限的提醒、缺教师 / 缺教室汇总、H3 表外节次补齐、提醒限长。

## 7. fixtures（8 对，全部合成）

| 用例 | 覆盖什么 |
|---|---|
| `basic` | 学期读自实验入口页；开学日按今天（2026-10-27）所在周的周一 = 2026-10-26；一格两门课；缺教室只有 3 个 span；缺教师 / 缺教室汇总；12 节节次时间 |
| `weeks` | `(单)1-8周,(双)9-16周` 两段各自归属；无逗号的 `1-8周(双)9-16周`；`（1）` 教学班序号；`（共8周）` 只剥备注；`1-3,5-9周` 两段；单双同写按每周都上 |
| `merge` | 理论行与同一门课同一时间的实验记录合并、周次取并集；实验教师写「未知」与理论缺教师都按没给处理，不会变成两门 |
| `lab-missing` | 第 2、4 周失败只写进提醒；第 3 周返回空课表不算缺失；理论课表与其余实验周照常导入 |
| `no-term` | 实验入口页打不开 → 学期按今天推算并冠学校名、开学日按本周周一推算，两条推算都在提醒里；只导入理论课表 |
| `long-warnings` | 长课名截 20 字；缺教师 5 门 / 缺教室 4 门；缺课名 / 节次 / 周次的理论行与实验记录被跳过；全部提醒 ≤200 字 |
| `beyond-20` | 第 1-22 周的生产实习 → 总周数从 20 抬到 22 并说明 |

期望值的推演方式：节次时间表逐节照上游手抄；开学日按「今天所在周的周一」手算（2026-10-27 → 2026-10-26，2026-03-05 → 2026-03-02）；
周次集合先手写（如 `(单)1-8周` → 1,3,5,7，`1-8周(双)9-16周` → 2,4,6,8,9…16），再按手册 §4.1 手切极大段；
课程顺序按码位比较手排（如 实验甲 < 暑期… < 缺教室…）。生成脚本 `.test/port-batch34/hbmzu/gen_fixtures.py` 只负责序列化字面量，
**没有读 parse.js 的输出**。首跑 3 对 DIFF（同一处真 bug：缺教师时输出空串而不是 null，已改 `courseOf(..., || null)`），其余 4 对首跑 MATCH。

## 9. 已知风险与未验证项（我们没有本校账号，真机没验过）

1. **页面结构全部来自上游脚本，没有在本校真机验证**：`#container`、首 td 节次写法、`.course-block` 的 span 顺序、
   实验入口页的三个变量声明、`sheduleTable` 的字段名都照上游；若学校改版，会落到「没有找到课表」或跳过行，
   提醒里会给出计数，但不会静默导入错误周次。
2. **实验入口页变量名**：`id` / `openYear` / `openTerm` 的拼写与声明方式（`var` / `const` / `let` 都认）来自上游的写法。
   如果实际页面把学年学期放在别的元素里，实验课表会整段不导入并提醒，理论课表不受影响。
3. **开学日是推算的**：没有开学日期来源，按今天所在周的周一推。真实开学日不同时整学期会整体偏移，所以每次导入都有一条提醒。
4. **总周数是假设**：教务不给学期总周数，按 20 周，课表更晚才抬高（最多 30）。实验第 1 周的 `totalWeeks` 只用来决定翻几页。
5. **节次时间表无法核对**：12 节逐节照抄上游写死表，没有学校公布版本可对照。
6. **实验课表请求量**：第 1 周后每 5 周一批，整学期通常 20 条请求；教务若限流，失败的周会进提醒。
7. **学号出现在请求地址里**：这是上游的设计，学号只用于本校同源 URL；若日后学校改成 POST 或别的 ID，需要跟上游一起改。
8. **登录页判断是路径启发式**：`/edu/` 一律当登录 / 门户页，但会先找 `#container`，门户页里已经嵌着课表的仍能导入；
   登录后的首页若恰好是 `/edu/` 且课表不在同源 frame 里，用户会看到「登录页或门户页」提示。
9. **frameset 只找两层**（与 suda 相同，上游只找一层）；更深的嵌套会报「没有找到课表」。
10. **实验周数超过 30**：载荷上限 30 周，只取前 30 周并提醒；后面的实验课不会导入。
11. **`scheduleUrlHint` 是任务卡给的 `https://jwgl.hbmzu.edu.cn/edu/report/mySchedule.mvc`**：上游 yaml 只给入口
    `/edu/`，这个课表页地址来自任务卡与脚本注释，首次真机要核对是否直接可打开。
