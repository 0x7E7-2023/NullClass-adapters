## 本校与模板不同的地方（分析）

1. 课表表格 id 是 `timetable`，不是 `kbtable`。认不出 id 时才退到最近一张含课表明细的表（`findScheduleTable`）。
2. 上游只 GET 课表页。用户改选学期时才 POST，请求体只有 `xnxq01id`。本件不弹窗改学期，所以不发这次 POST。当前页已有课表格子就不再 GET。
3. 上游没有教学周历。开学日期按提取日所在周的周一推算，总周数没有更晚的课就按 20 周，两条都提醒。
4. 节次时间是写死的 10 节，分非夏季和夏季。页面上看不出用哪一套，又会改掉全部上课时间，所以问一次（`askSeason`）。取消或问不了就按非夏季并提醒。
5. 上游 `parseWeeks` 只按逗号和横线拆数字，单双标记会被丢掉。本件保留模板的分段判断，覆盖无逗号前置「(单)1-8周(双)9-16周」和后置「1-8周(单)9-16周(双)」。
6. 没有方括号节次时，先读行首「第N，M节」；行首也没有，按行序顺延（第 1 行是第 1-2 节）并提醒。星期按表头网格列对齐，不把第几个单元格当成星期几。
7. 登录走企业微信。首页、登录页、统一认证页、别的主机都不发请求，报错里写明要用企业微信登录（`loginHint`）。

## 请求清单

| 方法 | 路径 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|
| GET | `/jsxsd/xskb/xskb_list.do` | 无 | 课表页：下拉框选中项 + `#timetable`（`requestGet`） | 没有课表格子：没学期就报找不到学年学期，有学期但没课就报课表是空的 |

当前页已经有课表格子时不发这次 GET。不 POST。地址是相对路径，主机是打开页面的 `kdjw.hnust.edu.cn`。

`loginHint` 在任何 `fetch` 之前：路径是 `/`、含 login / cas / weixin / wechat / wwopen、`/jsxsd/`、`/jsxsd/index`、`/jsxsd/xk/LoginToXk`，或主机不是 `kdjw.hnust.edu.cn`，直接提示，不发请求。

## 读了什么、交出去什么

读：课表表格的格子文字和 `div.kbcontent` 的 HTML；学年学期下拉框选中项的值和文字；用户选的季节下标（0 非夏季，1 夏季）；当前页的协议、主机、路径；本地日期。

不读、不交：学号、姓名、身份证号、手机号、查询串、密码、登录框。课表格子里如果教务自己写了这些，明细 HTML 会原样进 `parts`，解析只取课名、教师、教室、周次节次。

`parse.js` 交出去的载荷：学期名、开学日、总周数、10 节（或补上的）节次时间、课程的课名 / 教师 / 地点 / 星期 / 节次 / 周次段。教师、地点没有，或写着「未知」「待定」，就是空。

## 上游里删掉或改掉的

| 上游 | 本件 | 理由 |
|---|---|---|
| `showSingleSelection` 选学期，再 POST `xnxq01id` | 读下拉框选中项，不 POST | 移植约定不弹窗问学年学期 |
| `showSingleSelection` 选作息 | `__ncSelect` 问一次；取消或问不了按非夏季并提醒 | 两套时间会改掉上课时间，又不能从页面判断 |
| `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / toast / `notifyTaskCompletion` | 删除 | 空课自己组载荷，脚本只读 |
| `parseWeeks` 不认单双 | `weeksIn` 按段判断 | 否则「(单)1-8周(双)9-16周」会塌成每周都上 |
| 教师写「未知」、教室写「待定」 | 空值，并按课汇总提醒 | 这两个词会被当成真名 |
| 第几个 td 当星期几，并跳过最后一行 | 按表头列号对齐，不跳最后一行 | 节次列若是单元格会错位；最后一行若是真课不能静默丢掉。没有明细的说明行本来就不会导入 |
| 没有方括号就用行号乘 2 | 先行首标签，没有才按行序，并提醒 | 行上写了「第1，2节」时以标签为准 |

## 已知风险

- 没有本校账号，真机没验过。课表页结构以脚本里的选择器为准。
- 夏季时间是上游写死的，注释写明「假设下午推迟半小时，请按实际情况微调」。选错会让下午和晚上整体差 30 分钟，提问说明里写了这一点。
- 开学日期和总周数都是推算，提醒里要求到「学期管理」核对。
- 上游会丢掉表格最后一行。本件不丢。若最后一行是带课表明细的说明，可能多出几门课。
- 提问桥不在时一律按非夏季，并提醒。
