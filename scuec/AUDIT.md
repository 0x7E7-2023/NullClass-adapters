## 0. 平台与上游（自己读上游得到的分析）

上游 `resources/SCUEC/adapters.yaml` 只有一份：`adapter_id: SCUEC`，`maintainer: Zellon0w0`，
`import_url: https://webvpn.scuec.edu.cn/`。**没有第二个上游脚本可取舍。**

本校是正方教务 ASP.NET WebForms 版课表页，页面结构全部来自上游代码（不是注释）：

- 课表是 `<table class="CourseFormTable">`：**表头第 1、2 格是「时间 / 节次」**，之后每天一列（`headerCells.length - 2` 就是天数）；
- 每个数据行的第 2 格写节次，形如「第N节」+「08:00~08:45」（上游 `generateTimeSlots` 用 `第(\d+)节` 与
  `(\d{1,2}:\d{2})\s*~\s*(\d{1,2}:\d{2})` 两处正则读它）；
- 课程格子里多门课用 `<hr>` 分隔、每门课用 `<br>` 分行；每块第一行是课名 + 周次（+ 可能带节次），后面几行是
  教师与地点（上游 `parseSingleCourse` 的判断：带「楼馆场室厅」的那行是地点，另一行是教师）；
- 表格末尾可能有一张 `<table class="NoFitCourse">`（未安排时间的课程，每行前三格是课名 / 周次 / 教师），
  上游遇到它就**跳出整个循环**，把前面的课表当作已完成；
- 上游**不发任何请求**（除了页面本身的加载），也没有学期 / 校区概念，没有开学日，没有总周数。

选模板：任务卡指定批次三十四已审的 `jw-adapters/zjsru`（同为正方 **ASP.NET WebForms 服务端渲染课表页**，
都已审计）。借的是解析骨架：周次解析 `weeksOf`（前缀 / 后缀单双标记归属、「第1-第8周」、「共 N 周」只剥备注、
序号 / 备注括号、全角标点）、`runsOf`、提醒限长出口 `warn`、去重与连堂合并、H3 节次补全、缺教师 / 缺教室汇总。
取数层与课程字段解析按本校上游重写（本校没有学期下拉框、没有 iframe、没有二次请求，但格子结构与树人不同）。

与模板**不同构**的地方（决定了哪些层要按上游重写）：

| 层 | 模板 zjsru | 本校 scuec |
|---|---|---|
| 页面 | `<table id="Table1" class="schedule">`，格子文字自带「周X第N节{周次}」锚点 | `<table class="CourseFormTable">`，**星期由列位置决定**、节次由行决定 |
| 取数 | 当前页没有课表时同源再拉一次课表页 | **永远只读当前页，零请求** |

`extract.js` 从入口到出口只有：判断登录页 → `document.querySelector('table.CourseFormTable')` → 读当前页表格

**零请求之前的三道判断**（都在取数之前，命中即抛大白话提示）：

- 页面里有密码框（统一身份认证登录页）或路径含 `login` / `/cas/` / `/auth/` → 报「当前打开的是登录页…」

  （`extract.js:194`、`197`）。

`parse.js` 里「一门课都没解析出来」又是第三句话（`parse.js:638`），三者互不混用。

提问桥：**不用**。本校没有需要现场选择、又影响课表本身的东西（没有校区、学期从页面也读不到）。

## 2. 读了什么、交出去什么（逐字段）

`extract.js` 交给 `parse.js` 的对象（`JSON.stringify` 后的字符串，`extract.js:245`）：

| 字段 | 内容 | 来源 |
|---|---|---|
| `today` | 提取当天日期（本地日期，不用 `toISOString`） | 本机时钟（`extract.js:55`） |
| `truncated` | 是否因为条数上限截断过内容（读多了一部分） | 各上限命中时置位（`extract.js:137`、`159`、`206`） |
| `rows[].section` | 该行第 2 格（节次格）的可见文字行，如 `["第1节","08:00~08:45"]` | 课表表格（`extract.js:192`） |
| `rows[].days[]` | 该行 7 个（按表头列数）课程格子的**课程块**：`[[块内文字行…], …]`，空格子交 `null` | 同上；块内 `<hr>` 切块、`<br>` 切行（`extract.js:142`） |
| `unscheduled[]` | 未安排课程表每行前三格的可见文字行 | `table.NoFitCourse`（`extract.js:172`） |

取数规则：从每个格子起逐个子节点取**看得见**的文字 —— `<br>` 换成换行、`<hr>` 切成课程块；
`hidden` 属性、`display:none`、`visibility:hidden`（内联或计算后）、以及 `getClientRects()` 为空的元素
整棵子树跳过；`script` / `style` / `noscript` 不读（`extract.js:77`、`94`、`107`）。
**表头、行首「上午 / 下午」标签、表格以外的页面文字（姓名、学号、菜单）一概不读** —— 只挑
「第 2 格（节次）」与「第 3 格起（课程格子）」以及未安排课程表的前三格。

条数上限（都留得比真实课表宽，命中会置 `truncated` 并在提醒里说出来，不静默丢课）：单行 120 字
（`extract.js:121`）、一个课程块 40 行、一个格子 20 块（`extract.js:126`–`160`）、课表 80 行（`extract.js:206`）、
未安排课程 80 行（`extract.js:176`）。

`parse.js` 是纯函数：不碰网络、不碰页面，输出载荷里的教师名只是课表本来就显示的任课教师。
冒烟 `hidden` 往格子里塞了学号 / 姓名 / 身份证号 / 手机号（隐藏 `<span>`、整格隐藏的 `<div>`、隐藏祖先），
输出与载荷里都找不到。

## 4. 给学生看的文字

`extract.js` 的报错与 `parse.js` 的 warnings 都按 `docs/ux-writing.md` 写：不出现「接口」「载荷」「上游」「脚本」
「字段」「JSON」「HTML」「null」「学期设置」「作息表」；时间表统一叫「节次时间」；改学期名、开学日、总周数、
节次时间指向「学期管理」，改教师 / 教室 / 手动加课指向「编辑课程」。范围用「~」。

**每条提醒都走同一个限长出口** `warn()`（`parse.js:172`）：先按类型汇总计数，点名课名 / 原文 / 备注 / 校区类的
教务原文一律过 `shortName`（20 字，`parse.js` 的 `shortName`），整条再截到 200 字。逐个 `warn(` 调用核对过：
唯一拼教务原文进提醒的是「认不出的行」「括号备注」「未安排课程名」「缺教师 / 缺教室的例子」，四处都截短。

提醒清单（顺序固定）：① 学期是推算的（教务不给学期）；② 开学日是推算的；③ 总周数（教务不给，按 max(最晚周, 20)）；

与表外节次顺推（顺推补不了的单独说）；⑥ 被跳过的行
（缺课名 / 缺节次 / 缺周次，分类计数 + 认不出的行原文）；⑦ 缺教师 / 缺教室汇总；⑧ 不相邻节次按首末范围导入；
⑨ 自定义时间与节次对不上 / 只有时间按最近一节放入 / 对不上被跳过；⑩ 未安排时间的课程点名；
⑪ 周次里的序号括号 / 备注括号 / 越界周次 / 孤立单双标记 / 单双同写；⑫ 页面内容过多只读了一部分。

## 5. 与模板（zjsru）的差异

借的是解析骨架（见 §0 末）。按本校上游重写的层：

1. **零请求**：模板「当前页不是课表页就同源再拉一次」整段没有移植，本校永远只读当前页（上游就是这样）。
   因此也没有 `allowHosts`、没有地址推导、没有 `DOMParser` 离线解析。
2. **按「行 → 列 → 课程块」交数据**（`extract.js:192`）：模板交的是「按锚点切好的格子文字」，本校格子不含星期与节次，
   星期来自列位置、节次来自行；`rowspan` / `colspan` 只用来跳过被占用的列（与上游 `pendingRowspans` 一致）。
3. **课程字段解析按上游 `parseSingleCourse`**（`parse.js:454`）：课名在第一行且截到第一个周次 / 节次 / 时间标记之前；
   **紧挨周次前面的 `(单)` / `(双)` 也算周次文本**，不会留在课名里（`高等数学(单)1-8周` → 课名「高等数学」+ 单周，
   后置的 `线性代数1-8周(单)` 同样读对）；周次跟在后面；教师与地点在后面几行，附加行里像教室编号的
   （`A305` / `B12` / `1-101` / `C-203` / `A305-1`）认成地点、不当成人名。模板的「周X第N节{周次}」锚点正则整段删掉。
4. **节次来源两段 + 逐节补齐**：先读课表页每行的「第N节 + 时间」（`parse.js` 的 `sectionNumbers` / `timeRangeOf`
   与建表循环），读不到才回落到上游写死的 11 节表（`SCHOOL_PERIOD_TIMES`，逐节照抄）。课表页**只给了部分节次**
   时，从**第 1 节**到「课表用到的最大节次」与「课表页给了时间的最大节次」里更靠后的那一节，凡是还没有时间的节
   都用学校公布的表**逐节补**（只补缺的、不整表覆盖；学校表里没有或接不上上一节下课的才顺推），提醒里写
   「另有 N 节的节次时间用了学校公布的时间（第 X~Y 节）」（主调度 2026-11-10 决定：应用会给没时间的节次套通用
   默认时间，和本校作息不一样，学生看到的是错时间）。**提醒里点名的第一节一定是课表页真的给了时间的**（没有就用
   学校表第 1 节），不让补出来的时间冒充页面数据。模板只有写死的一套 12 节（两校区）。
5. **周次解析多摘两样**：模板 `weeksOf` 之外，这里先 `stripSections` 把「第3-4节」「(2-3节)」连括号整段摘掉
   （批次三十五 `nwafu` 的坑），并且 `weekTextOf` 要求文字里真的出现「周」或「单 / 双」才解析（否则「1-101」
   这类教室编号会被当成周次 1~30）。
6. **节次区间展开**：`第1-4节` 展开成 1,2,3,4（连续），`第1,3节` 是 1、3 两节（不相邻，要提醒）。模板没有这个区分。
7. **未安排时间的课程**：模板没有；本校上游给 day=0、节次 0（放不进课表），这里点名提醒并说明要自己加。
8. **自定义上课时间**（手册 §4.4）：有节次就按节次导入并提一句；没有节次就找最接近的一节（差 ≤ 1 小时）；
   都对不上就跳过并计数。模板没有这一段。
9. **学期名**：模板用教务下拉框的文字；本校教务不给，按今天的日期推算学年学期，学期名写成
   「学校名 + 学年学期」（`parse.js:684` 起）。
10. **开学日锚点只剩两个**：第一学期 9 月 1 日 / 第二学期次年 3 月 2 日（本校没有短学期）。

## 6. 上游里删掉 / 改掉的东西及理由

| 上游 | 处理 | 理由 |
|---|---|---|
| `showAlert` 确认框、`showToast` 进度条、`saveImportedCourses` / `savePresetTimeSlots` / `notifyTaskCompletion`、`isOnSchedulePage` 里的 `setTimeout` 入口 | 去掉 | 拾光的桥能力；空课由宿主保存，适配器只交数据 |
| `console.log` / `console.error` 大量调试输出 | 不移植 | 不埋点、也不往控制台留数据 |
| `isOnSchedulePage` 用 URL 正则 `jiaowu|jwgl|course|schedule|curriculum` 判断在不在课表页 | 改成：有 `table.CourseFormTable` 就取数；登录页（密码框 / 登录路径）先报错；没有表报「没有找到课表」 | URL 正则会在登录页、门户页上误判为课表页，然后读出一张空表 |
| `parseSingleCourse` 只看第一行找周次，第一行没有周次就整门丢掉 | 第一行没有就往后几行找（`weekTextOf` + 逐行扫描） | 不许静默丢课；真实格子里课名单独占一行的情况很常见 |
| `parseSingleCourse` 的 `sectionMatch` 只认带括号的「(第1-2节)」 | 括号内外都认，也认「第1,3节」这种列表 | 上游写法不全，缺了就只剩行节次，会把 1-2 节压成 1 节 |
| `teacherLine = rest.find(line => line !== positionLine)`：只有一行又是教室编号时把教室当教师 | 加了「只有一行且像教室编号（1-101 / A305）就当地点」的判断 | 不能让教室编号显示成任课教师 |
| `position: positionLine || '待定'`、教师空串原样保存 | 占位词（未知 / 待定 / 暂无 / 无…）一律交 `null`，并按类型汇总提醒 | 手册 §4.7：写「未知」会被当成人名显示；缺项不许静默 |
| 未安排课程 `day: 0, startSection: 0` | 不放进 `blocks`，改为点名提醒 | 载荷要求 `dayOfWeek` 1..7、`startPeriod` ≥ 1；硬塞会整包被拒 |
| `semesterStartDate` 没有、`semesterTotalWeeks` 没有 | 按学期锚点所在周的周一推算开学日；总周数 max(最晚周, 20)，最多 30；两条都写进提醒 | 手册 §4.2 / §4.3 与公共说明第 7 条：推算值必须说出来 |
| `const` / `let` / 箭头函数 / `new Set` / `Array.from` / 展开 / 模板串 / `for...of` / `Map` / `async` | 全部改成 ES5，`Map` 去重改成对象字典 | 旧 WebView 与 Rhino（Rhino 也不支持 async/await） |

新增（上游没有）的：登录页 / 非课表页 / 结构不对三种失败分开报、缺教师 / 缺教室汇总、跳过行的分类计数、
提醒限长、H3 表外节次补齐与页面缺节次时的逐节补齐、连堂合并与完全重复行去重、单双周切段、自定义时间回落、未安排课程点名、`truncated` 提醒。

## 9. 已知风险与未验证项（我们没有本校账号，真机没验过）

1. **页面结构全部来自上游脚本，没有在中南民族大学真机验证**：`table.CourseFormTable`、表头前两格不是星期、
   `<hr>` 分课程 / `<br>` 分行、`table.NoFitCourse` 前三格、节次格的「第N节 + 08:00~08:45」都照上游。
   学校改版会落到「没有找到课表」「课表看起来不完整」或跳过行（有计数提醒），不会静默导入错周次。
2. **格子里课名与周次的位置**：上游假定两者在同一行（第一行）。这里放宽成「第一行没有周次就往后几行找」，
   两种排法都能读；但「课名单独一行 + 周次在第三行以后」仍然只能靠逐行扫描找到周次，若地点行也带「周」字
   会被误当周次（概率很低，见了真页面要核对）。
3. **开学日是推算的**：第一学期 9 月 1 日、第二学期次年 3 月 2 日，各回退到那一周的周一。上游明确不给开学日，
   真实开学日不同会让整学期整体偏移，所以每次导入都有一条提醒让用户去「学期管理」核对。
4. **总周数**：教务不给，按 `max(课表最晚周, 20)`，最多 30。短学期也按 20 周导入，可能偏大。
5. **学期不从页面读**：本校页面（按上游的读法）没有学年学期；如果实际页面有（例如学年 / 学期下拉框），
   我们没有读它 —— 学期名会按今天的日期推算，提醒里已说明。真要读需要拿到真实页面再加。
6. **补齐用的学校时间是静态的**：课表页只给了部分节次时，缺的节用上游写死的 11 节表补（见 §5 第 4 条）。
   这份表来自上游脚本，没有校历原文可对照；学校若临时调整作息（例如改点），页面给了的节次是新的、补出来的
   那几节是旧的，提醒里已写明「另有 N 节的节次时间用了学校公布的时间」并点名补了哪几节。页面完全不给时间时整表都用它。
   补齐范围还包含「课表页给了时间的最后一节」之前的空档（例如页面给了第 4 节、没给第 3 节），所以提醒里列出的
   节数可能比课表用到的多。
7. **`第1-4节` 与 `第1,3节` 的区分是按写法猜的**：前者当连续四节，后者当两节并按首末范围导入并提醒。
   如果某校把「1-4」写成「1、4」的意思，会多算中间两节 —— 提醒里会写「按首末两节之间的范围导入」。
8. **未安排时间的课程没有导入**：载荷放不下「没有星期 / 节次」的课，只点名提醒用户自己加。上游是把
   `day: 0` 交给拾光（我们这边会被载荷校验拒收）。
9. **`allowHosts: []`（主调度已定）**：脚本零请求，声明为空是准确的。经 WebVPN 打开时读的是当前页，
   不需要额外声明主机；`loginUrl` 是 WebVPN 首页，主调度已定不填 `scheduleUrlHint`（令牌路径不稳定）。
10. **登录页判断是启发式**：密码框、路径含 `login` / `/cas/` / `/auth/`。WebVPN 首页若既没有密码框、
    路径也不含这些片段，会走到「没有找到课表」（仍是零请求，提示也说得过去）。
11. **没有 iframe 支持**：上游只读顶层 `document`，这里一致。若教务把课表放进同源 iframe，会报「没有找到课表」。
12. **隐藏元素只认 `hidden` / 内联 / 计算样式 / 排版为空**：用透明度 0 藏起来的文字仍会被当成行内容带出
    （上游同样会带出）。课表格子通常没有人藏个人信息，但这仍是已知边界。
13. **教师字段原样取**：不拆括号备注（如「张三（外聘）」），与上游一致。
14. **`truncated` 上限**：单行 120 字 / 每块 40 行 / 每格 20 块 / 80 行，真实课表远低于这些值；命中会提醒。
15. **教室编号是猜的**：附加行里长得像「字母 / 数字 + 数字」的文字（`A305`、`B12`、`C-203`）都当地点，宁可教师留空
   也不把教室显示成人名；代价是某校若真有这类写法的教师名 / 备注，会被当成地点（提醒里会点名缺教师的课）。
