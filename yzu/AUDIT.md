# 安全审计 —— 扬州大学（yzu，URP 综合教务系统，经网瑞达 WebVPN 访问）

审计对象：`jw-adapters/yzu/` 下的 `manifest.json`、`extract.js`、`parse.js` 与 `fixtures/`。
上游：`shiguang_warehouse` 的 `YZU/yzu.js`（MIT，`adapters.yaml` 维护者 Thanatos，`adapter_id` `YZU_01`）。
上游快照 `baf83fa7972d4be6627c534992f7d2da399a0945`；`git log -1 -- resources/YZU/yzu.js` 核对为 `1fe584c`（2026-08-23），
与任务卡一致，未修改快照。上游 161 行，一个取数接口 + 一套弹窗流程。

## 0. 通读结论与模板选择

模板用同平台已审的 `lnu`（URP 综合教务），WebVPN 前缀归一参考 `gdpu`，登录页门禁与「同一响应外壳只定义一次」的写法参考
`imu`。选 `lnu` 的依据：两者都是「同源 POST 课表接口 → `xkxx` 课程字典 → `timeAndPlaceList` 展开 → `jcsjbs` 节次时间」，
转换层（位串周次切段、占位词、提醒限长、H3 补节次、越界截断）可以整段复用；而取数层、校区、校历、学期选择、节次时间来源都不同，
按本校上游重写。

与模板不同构、按上游重写的地方：

1. **WebVPN 前缀**：本校走网瑞达 WebVPN，教务页面在 `/http<…>/<加密主机>/…` 下（令牌每次登录都变）。上游正则
   `/^(https?:\/\/[^/]+\/http[^/]*\/[^/]+)/` 匹配整条地址；移植改为只取 `pathname` 的 `/(http<…>)/(<加密主机>)` 两段拼音出基址，
   再拼相对路径。没有这个前缀（WebVPN 登录页、门户首页）时**零请求**直接提示。
2. **校区**：上游没有校区概念，模板的 `__ncSelect` 问校区、三套内置节次表全部删除。
3. **校历**：上游没有校历请求；按主调度 2026-11-10 的决定，照同平台已审的 `lnu` 补一个只读 `GET <WebVPN 前缀>/indexCalendar`，
   只从页面文本取 `var rq`（开学日）与 `var skzc`（学期周数），不交整页。取不到或结构不认识就回落「提取日所在周周一 + 20 周」并提醒，
   不把回落说成成功；页面选中的不是当前学期时校历不适用，同样回落并提醒。
4. **学期**：上游弹窗让用户在下拉框选项里单选；移植读同一个 `#planCode` 下拉框的**当前选中项**（用户在页面里选好学期再点提取），
   没有下拉框就让教务按会话里的当前学期给（正文 `planCode=`）。
5. **周次**：只认 `classWeek` 的 0/1 位串（上游 `parseWeeks` 的唯一来源）。位串缺失或不是 0/1 串的安排按「读不出来」计数，
   不再退回文字描述——上游也没有这条兜底。
6. **连续节数**：上游 `classSessions + continuingSession - 1`；`continuingSession` 缺失时会算出无效值。移植按 1 节导入并提醒。
7. **节次时间**：上游从响应 `jcsjbs` 读，取不到用脚本里写死的 12 节表。移植照做，并在提醒里说清用的是哪一种。
8. **地点**：上游 `campusName + classroomName` 直接相连，缺了写「待定」。移植同样拼，占位词交 `null`。

## 1. 请求清单（与代码一致）

`extract.js` 有**两个**请求。地址 = `vpnBase()` + 固定路径，永远落在当前页面同源（WebVPN 映射主机）上；
`credentials: 'same-origin'`，不带令牌、不读 Cookie、不发 `Authorization`。

| 谁 | 方法 | 地址 | 正文 | 干什么 | 失败时 |
|---|---|---|---|---|---|
| `requestSchedule()` | POST | `<当前页 /http<…>/<加密主机>>/student/courseSelect/thisSemesterCurriculum/ajaxStudentSchedule/callback` | `planCode=<下拉框选中值>`（URL 编码）；没有下拉框或值为空 / `no` 时是 `planCode=` | 取本学期课表：`xkxx`、`jcsjbs` | 401/403 → 「教务系统拒绝访问（代码 N）」；其他非 2xx → 「教务系统返回错误（代码 N）」；连不上 → 「连不上教务系统」；回网页（JSON 解不开）→ 「教务系统返回的是网页而不是课表数据」；JSON 但不是课表外壳且没有 `errorMessage` → 「教务系统没有返回课表数据」；有 `errorMessage` → 原样交给 `parse.js` 报「教务系统返回：…」（截 20 字） |
| `fetchCalendar()` | GET | `<当前页 /http<…>/<加密主机>>/indexCalendar` | 无 | 只从页面文本取 `var rq`（开学日 `YYYYMMDD`）与 `var skzc`（学期周数），不交整页 | 任何失败（非 2xx、连不上、两个正则都不匹配）都返回 `null`：`rq` / `skzc` 交 `null`，课程照常导入，`parse.js` 按提取日与 20 周回落并提醒 |

**为什么加校历**（上游没有这一步）：本校是 URP 综合教务，`/indexCalendar` 是学校公开的校历页，只含开学日与学期周数，
**不含任何个人信息**，写法与同平台已审的 `lnu` 相同。没有它，开学日只能按提取日推算、总周数只能按 20 周，而 `firstDay` 决定
「现在第几周」，今日页、提醒、小组件与周视图的列对齐都挂在它上面。主调度 2026-11-10 批准加这一条只读请求。
校历只对教务会话里的**当前学期**成立：页面下拉框选中的不是服务端标了 `selected` 的那一项时，`parse.js` 忽略 `rq` / `skzc` 并提醒。

课表请求头固定三项：`Accept: application/json, text/javascript, */*; q=0.01`、`Content-Type: application/x-www-form-urlencoded; charset=UTF-8`、
`X-Requested-With: XMLHttpRequest`（与上游一致）；校历请求只带浏览器同源 Cookie，不加自定义头。

页面判断（零请求）：`vpnBase()` 为空（登录页 `/login`、门户首页 `/`、任何不在 `/http<…>/<加密主机>/` 下的页面）→
「这里还不是教务课表页：请先在扬州大学 WebVPN 里登录，打开教务系统的「本学期课表」页面后再点「提取课表」」。
没有做「页面上有没有课表格子」的判断：本校课表是脚本请求接口拿的，不依赖页面 DOM。

**不请求**：成绩、学籍、个人信息、缴费、通知等任何其他接口。

## 2. 读了什么、交出去什么

| 数据 | 来源 | extract 输出 |
|---|---|---|
| `#planCode` 下拉框当前选中项的 `text` 与 `defaultSelected` | 页面 DOM | `term: { text, isDefault }`；没有下拉框时 `term: null` |
| `var rq`、`var skzc` | 校历页文本（只取这两个正则命中的值，不交整页） | `rq`（`YYYYMMDD` 或 `null`）、`skzc`（数字串或 `null`） |
| 本机日期 | 浏览器时钟 | `fetchedDate`（`yyyy-MM-dd`，本地时区，不用 UTC），用于推算学期名与开学日 |
| `courseName`、`attendClassTeacher` | `xkxx` 里每个课程对象 | `courses[].courseName` / `.attendClassTeacher` |
| `classDay`、`classSessions`、`continuingSession`、`classWeek`、`campusName`、`classroomName` | 课程对象的 `timeAndPlaceList` | `courses[].timeAndPlaceList[]` 的六字段白名单 |
| `jc`、`kssj`、`jssj` | `jcsjbs` | `slots[]` 的三字段白名单；`jcsjbs` 不是数组时 `null` |
| `errorMessage` | 响应 | `errorMessage`（字符串原样，由 parse 截 20 字报错） |
| 学号、姓名、人员标识、证件号、手机号、课程 ID 等 | 响应里可能夹带 | **不带出**：`pick()` 按字段白名单挑，白名单外的键一律丢弃；冒烟用合成个人信息验证过 |
| Cookie、密码框、`localStorage` | — | 不读取、不带出 |

`parse.js` 只吃上述普通 JSON，无 DOM、网络、存储；日期只用 `fetchedDate`（extract 一定会带；手写输入没带时才按当天算，
与模板 `lnu` 同口径）；输出课名、教师、地点、星期、节次、周次段、
学期名、开学日、总周数与节次时间。教师 / 地点为空或是「未知」「暂无」「无」「待定」「未定」「暂无教师」这类占位词时交 `null`，
课程照常导入并按类型汇总提醒。

## 3. parse.js 的转换规则

- **周次**：`classWeek` 位串，下标 i 为 `1` 就是第 i+1 周（上游 `parseWeeks`）；排序去重后按极大段切：步长 1 → `ALL`，
  步长 2 且起止都是奇数 → `ODD`，都是偶数 → `EVEN`，落单一周 → `ALL`（移植手册 §4.1）。位串缺失、含 0/1 以外字符、
  或一天都没有的安排计入「读不出来」，不猜周次。
- **节次**：`startPeriod = classSessions`，`endPeriod = classSessions + continuingSession - 1`（上游口径）。
  `continuingSession` 缺失或非正数 → 按 1 节，计数并提醒（这是推算的）。
- **去重**：同课名、同教师、同星期、同起止节次、同周次集合、同地点的安排只留一条（上游的去重键，另加地点）。
- **课名 / 教师 / 地点**：课名空则跳过该课程对象；教师照上游 `cleanTeacher`（`*` 清掉、合并空白）；地点照上游「校区名 + 教室名」
  直接相连，占位词的那一半不算（`文汇路校区` + `待定` → `文汇路校区`）。
- **开学日**：校历 `rq` 合法、且选中的是当前学期（`term.isDefault`，或没有下拉框）时用它，回退到同一周周一（不是周一就提醒已对齐）；
  校历没有 / 不能用 / 选的是别的学期时按 `fetchedDate` 所在周的周一推算（移植手册 §4.3）。三种来源各有一句提醒，写清用的是哪一个。
- **学期名**：下拉框选中项文字；没有就「扬州大学 + 按提取月份推的学年学期」（2–7 月算第二学期，8 月–次年 1 月算第一学期），并提醒。
- **总周数**：校历 `skzc` 在 1..30 就用它；没有（或选的是别的学期）按 20；课表排得更晚才抬到那一周，超过 30 截断；
  四种情况（校历给的 / 抬高 / 截断 / 回落 20）各有各的提醒，措辞与真实来源一致（公共说明第 7 条）。
- **节次时间**：教务 `jcsjbs`（`HHmm` / `HHmmss` / `HH:mm` 都认）能用就用；一节都用不了就用上游写死的 12 节表，提醒说明来源。
  坏行（时间格式不对、结束不晚于开始、节次号非正）跳过并计数。
- **超出节次时间表**：第 13 节起按 H3 逐节补——空课默认表里该节开始时间不早于上一节下课就用它，否则按课间 5 分钟、每节 45 分钟顺推；
  顺推越过 23:59 的不补时间但保留课程。补了哪些都写进提醒。
- **越界周次**：整条落在 `totalWeeks` 之后的安排丢弃、跨界的截断，都计数并提醒；一门课一条不剩时点名。
- **提醒**：按类型汇总、课名截 20 字、整条 ≤200 字（同一个 `pushWarning` 出口）、最多 20 条；不写「适配器」「接口」「作息」等词。

## 4. 与模板（lnu）的主要差异

1. 取数：`lnu` 是「学期下拉框 + 校历」两请求；本校相同（POST 课表 + GET 校历），但校历路径、学期判断与回落口径按本校重写。
2. 地址：模板的 `vpnBase()` 认深信服式 `/http/<token>/`；本校按网瑞达 `/http<…>/<加密主机>/` 取两段前缀（上游正则的路径版）。
3. 校区：模板用 `__ncSelect` 问校区、有三套内置节次表；本校全部删除，节次时间只来自教务或上游写死的 12 节表。
   模板的校历（`rq` / `skzc`）整段沿用，但学期判断只靠 `defaultSelected`，没有校区参与。
4. 周次：模板位串优先、`weekDescription` 文字兜底；本校只认位串，认不出的计为读不出来。
5. 学期：模板要判断「是不是服务端默认写了 selected 的那一项」来决定校历能不能用；本校同样判断（`term.isDefault`），但学期名只取选中项的文字，没有校区参与。
6. 提醒：模板有校区、校历、周数来源三条；本校换成开学日推算、总周数来源、节次时间来源三条，并新增「缺教师 / 缺地点」两条按类型汇总的提醒。

## 6. 移植手册 §5 八条逐条结论

1. **不碰凭据**：通过。不读密码框、不读 `localStorage`/Cookie、不发 `Authorization`；Cookie 由浏览器同源自动携带。
2. **不外发**：通过。只有一个同源 POST，无统计、图片信标、WebSocket、第三方地址。
3. **请求域可控**：通过。地址由当前页 `pathname` 的前缀拼出，永远同源；`allowHosts: []`（只有 `loginUrl` 的 `webvpn.yzu.edu.cn` 同源），无通配。
4. **只读课表与学校公开校历**：通过。只请求课表接口与 `/indexCalendar`（公开校历，只取开学日与学期周数两个值）；不请求成绩、学籍、个人信息、缴费。课表响应里夹带的个人信息被字段白名单挡掉（冒烟已用合成学号 / 姓名 / 证件号 / 手机号 / 人员标识验证）。
5. **不埋点**：通过。无统计、上报或遥测。
6. **不动态执行远程代码**：通过。无 `eval`、`new Function`。
7. **不写页面**：通过。只读 `window.location` 与 `#planCode` 的选项文字；不改 DOM、不提交表单、不点击。
8. **不依赖硬编码秘密**：通过。WebVPN 令牌从当前地址推导，不写死；无密钥、无他人学号；fixtures 全是合成课程与「教师甲」等虚构值。

`check.js` 对 `password` 字样的提示：代码里没有 `password`，冒烟里的密码框只出现在假登录页的 HTML 中。

## 11. 已知风险与未验证项

- **没有本校账号，真实教务与真机未验证。** 接口路径、请求体、响应外壳（`xkxx` 数组里「课程 ID → 课程对象」、`jcsjbs`）、
  字段名均以快照代码为依据；合成 fixture 与假站不能证明线上完全一致。
- **WebVPN 前缀只覆盖 `/http<…>/<加密主机>/` 一种形状**（上游正则的路径版）。若学校换成子域重写（`xxx.webvpn.yzu.edu.cn`）
  或别的网关形态，脚本会提示「还不是教务课表页」而不发请求——不猜、不外发，但需要再改。
- **校历页的取值方式未在真机验证**：`/indexCalendar` 与 `var rq` / `var skzc` 两个正则照同平台已审的 `lnu` 写；若本校校历页
  结构不同或不在这个路径上，两条正则都取不到 → `rq` / `skzc` 交 `null`，开学日与总周数回落「提取日周一 + 20 周」并提醒，
  不会静默用错值，但学生每次都要去「学期管理」核对。
- **校历只对当前学期成立**：判断依据是下拉框选中项有没有 `defaultSelected`。若本校课表页的 `selected` 标记习惯与预期不同
  （例如服务端永远标在第一项），用户手选别的学期时可能误用当前学期的校历——表现为开学日/周数与所选学期对不上，提醒里点得出。
- **学期只认页面下拉框的当前选中项**：用户在 WebVPN 里打开的是别的页面（没有 `#planCode`）时，拿到的会是教务会话里的当前学期，
  学期名由 parse 推算并提醒，可能与用户想导入的学期不同。
- **`continuingSession` 缺失按 1 节**是保守推算（上游会算出无效值）；真实数据里若常缺这个字段，会少算连堂节数，提醒里能看出来。
- **只认 `classWeek` 位串**：若某学期教务改成只给文字周次（如 `1-16周`），这些安排会被计入「读不出来」并跳过，不会静默丢课但会少课。
- 上游没有分页代码，本移植也不加；若真实课表分页，可能少课，且无法从响应判断是否分页。
- `scheduleUrlHint` 按任务卡省略：网瑞达映射路径里的令牌每次登录都变，写死会失效。
- 节次时间若教务给的表从中途开始（例如只有第 3-12 节），前面几节没有时间可显示；移植不补，和模板行为一致。
