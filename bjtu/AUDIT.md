## 0. 平台与上游（任务卡分析）

上游 `resources/BJTU/adapters.yaml` 只有一份：`adapter_id: BJTU`，`maintainer: Haooz`，
`import_url: https://mis.bjtu.edu.cn/home/`（翱翔门户），`description` 写明要先登录再进教务系统点导入。**没有第二个上游脚本可取舍。**

本校是 Django 服务端渲染的教学支撑平台：课表页 `GET /course_selection/courseselect/stuschedule/` 整页返回，
页面里 `table.table-bordered` 每行第 1 格是「第N节 [HH:MM-HH:MM]」，第 2-8 格是周一到周日；
课程格子里每个 `td` 直接子 `div` 是一段安排：课名 `span[style*='color:#000']`、教师 `i`、地点 `span.text-muted`，
周次写在教师那层（`i` 的父元素）的文字里；同一个格子里可能放多门（单双周各一段）。学期切换是页面上的
`a[href*='xnxq=']` 链接（`?xnxq=` 参数），标题按钮 `.widget-header button` 里的 `YYYY-YYYY-N` 是当前学期。

与模板（suda）的不同构之处：suda 是**零请求、读当前页**的选课系统；bjtu 要**自己请求课表页 HTML** 再用 `DOMParser` 解析。
所以取数层完全按本校上游重写，只借 suda 的解析骨架（周次解析、连堂合并、提醒限长出口、H3 节次补全、缺教师 / 缺地点汇总）。

入口按主调度给的值：`loginUrl` = 翱翔门户（用户在这里登录），`allowHosts` = `["aa.bjtu.edu.cn"]`。
`extract.js` 只在 `aa.bjtu.edu.cn` 上工作（主机不符就提示先打开教务系统的课表页）。请求地址：当前页就是课表页时用它自己的
`pathname + search`（把用户在教务里选好的 `?xnxq=` 带上，见 §1），否则用课表页默认地址；无论如何都落在同源主机上，
不跨站请求，也不带任何凭据到第三方。

## 1. 请求清单（与代码逐条对应）

| # | 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|---|
| 1 | GET | 当前页是课表页时 = 它自己的 `pathname + search`（如 `/course_selection/courseselect/stuschedule/?xnxq=2026-2027-2`）；否则 `/course_selection/courseselect/stuschedule/`。都打当前页面同源 `https://aa.bjtu.edu.cn`，`credentials: include` | 无 | 拿课表页 HTML：当前学期、学期列表、节次时间、课程格子（`schedulePath` / `fetchSchedulePage`，`extract.js:217`–`226`） | 401/403 → 「还没登录教务系统…」；其它非 2xx → 「教务系统返回错误（代码 N）…」；网络失败 → 「连不上教务系统…」；返回登录页 → 「还没登录教务系统…」 |

只有这一条请求，没有第二个接口、没有备用接口。**不弹窗问学期**：当前页带 `?xnxq=` 时就用那个学期（用户自己在教务里选的），
当前页不是课表页时才用课表页默认打开的学期；提醒里仍告诉用户「要导入别的学期，先在教务系统里切换」——这条现在是走得通的。

不发请求的情形（都在请求之前判断）：
- 当前主机不是 `aa.bjtu.edu.cn` → 「当前页面不是北京交通大学的教学支撑平台…」（`extract.js:237`、`60`）；
- 当前路径含 `/login`、`/cas`、`/sso`、`/authserver`，或当前页面有密码框 → 「还没登录教务系统…」（`extract.js:238`、`65`–`80`）。

提问桥：**一次都不用**。不弹窗问学期（公共口径：用页面默认的当前学期），也不问校区（本校没有校区 / 节次时间分支）。

## 2. 读了什么、交出去什么（逐字段）

`extract.js` 交给 `parse.js` 的对象（`JSON.stringify` 后的字符串，`extract.js:206`）：

| 字段 | 内容 | 来源 |
|---|---|---|
| `semester` | 当前学期 `YYYY-YYYY-N`，读不到为空串 | `.widget-header button` 文字里的 `\d{4}-\d{4}-\d`（`extract.js:114`） |
| `semesters[]` | 学期列表（只留 `YYYY-YYYY-N` 形状，去掉末尾「学期」） | `a[href*='xnxq=']` 的文字（`extract.js:121`） |
| `today` | 提取当天日期（本地日期，不用 `toISOString`） | 本机时钟（`extract.js:55`） |
| `timeSlots[]` | `{number, start, end}`：每节的节次与上下课时间 | 表格每行第 1 格的「第N节 [HH:MM-HH:MM]」；格子少于 8 个的行跳过（`extract.js:132`） |
| `rows[]` | `{day, section, name, teacher, location, weeks}`：一条上课安排；教师 / 地点没有就是空串 | `td` 下直接子 `div`（`courseRowsOf`，`extract.js:160`）：课名去末尾 `[...]`、教师取 `i`、地点原样（含逗号串）、周次取 `i` 父元素的可见文字（没有 `i` 时找块里第一段含「第…周」的文字，`weekTextOf`，`extract.js:149`） |

取数规则：只读**看得见**的文字 —— `hidden` 属性、内联或计算样式把 `display` / `visibility` 关掉的元素整棵子树跳过
（`extract.js:82`、`100`）；`td` 自身被隐藏时整格不读（`extract.js:171`）；每个字段截到 120 字。
块里**只要课名在就交出去**：教师 / 地点缺了（或元素本身被隐藏）交空串，由 `parse.js` 转 null 并按类型汇总提醒
（上游是缺一个就整块丢弃；`missing-fields` 冒烟与对应变异钉住这一点）。
学生个人信息即使被塞在课程格子里（隐藏元素、别的元素里）也不会进输出：冒烟 `hidden` 场景往隐藏格子、隐藏 `td`、
隐藏 `span` 里塞了学号 / 姓名 / 身份证号 / 手机号，输出与载荷里都找不到（§8）。

`parse.js` 是纯函数：不碰网络、不碰页面，输出载荷里的教师名只是课表本来就显示的任课教师，不含学生信息。

## 4. 给学生看的文字

`extract.js` 的报错与 `parse.js` 的 warnings 按 `docs/ux-writing.md` 写：不出现「接口」「载荷」「上游」「脚本」「字段」「JSON」
「HTML」「null」「学期设置」「作息表」；时间表统一叫「节次时间」；改学期名 / 开学日 / 总周数 / 节次时间指向「学期管理」，
改教师 / 地点指向「编辑课程」；状态码写成「教务系统返回错误（代码 N）」。

提醒清单（顺序固定）：① 学期来源（教务页面当前学期 / 按今天的日期推算）；② 开学日是推算的；③ 总周数按 20 周或抬高；
④ 节次时间（照教务页面的表 / 没读到用默认）；⑤ 表外节次的补齐（空课默认 / 顺推 / 补不了）；⑥ 被跳过的行（缺课名 / 星期 / 节次 / 周次，
分类计数 + 认不出的周次原文）；⑦ 缺教师 / 缺地点汇总；⑧ 教学班序号括号 / 备注括号 /
越界周次 / 孤立单双标记 / 单双同写。带课名的提醒课名截到 20 字、最多点名 3 门；每条都经 `warn()`（`parse.js:138`）再截到 200 字以内。
fixture `long-warnings` 钉住这一点。

## 5. 与模板（suda）的差异

借的是解析骨架（周次解析 `weeksOf`、极大段切分 `runsOf`、提醒限长出口 `warn`、H3 节次补全、缺教师 / 缺地点汇总、连堂合并）。
取数层、字段、学期来源、节次时间来源全部按本校上游重写：

1. **一条 GET 取课表页 HTML**（§1，地址取当前课表页自己的 `pathname + search`，带 `?xnxq=`），再用 `DOMParser` 解析；suda 是零请求读当前页。
2. **当前学期**：`extract.js` 读 `.widget-header button`，`parse.js` 解析 `YYYY-YYYY-N`；标题读不到而学期列表只有一项时认那一项
   （`effectiveTerm`，`parse.js:499`，学期列表兜底在 502 行）。suda 是页面下拉框的学年 + 第几学期。
3. **学期名**：由教务的 `YYYY-YYYY-N` 拼成「2026-2027学年第1学期」（`termName`，`parse.js:514`），不从适配器名来。
4. **开学日**：教务不给，按「第一学期 9 月 1 日 / 第二学期次年 3 月 2 日所在周的周一」推算（`estimateStart`，`parse.js:520`），与 suda 同一条规则。
5. **总周数**：教务不给，按 `max(课表最晚周次, 20)`，最多 30（与 suda 相同）。
6. **节次时间**：逐节取教务页面表格里的时间（`parse.js:542` 起），不是写死的表；只有超出这张表时才用空课默认的 12 节表补
   （`parse.js:575` 起）。**没有写死的「内置节次时间」**——本校的上下课时间以教务页面为准，我们拿不到真实值，也不猜。
   H3 补全用的空课默认表（逐节）：1 08:00-08:45 / 2 08:55-09:40 / 3 10:00-10:45 / 4 10:55-11:40 / 5 14:00-14:45 /
   6 14:55-15:40 / 7 16:00-16:45 / 8 16:55-17:40 / 9 18:30-19:15 / 10 19:25-20:10 / 11 20:20-21:05 / 12 21:15-22:00。
7. **周次原文的截取**：上游 `/第(.+?)周/` 会把「第1-16周(单)」后面的单周标记丢掉；这里先取出整段周次原文（连紧跟的单 / 双标记，
   `weekChunksOf`，`parse.js:272`），再交给 `weeksOf`。同一个格子里写了多段「第…周」时上游只认第一段（会丢周次），这里把每一段都取出来、
   用逗号连起来交给 `weeksOf`，周次取并集；本段自己以标记开头时（`(单)1-8周(双)9-16周`）后面那个标记归下一段。
8. **地点**：上游 `split(",").pop()`，这里放在 `parse.js` 做（取最后一段），「地点见通知」这类整句保留。
9. 没有 suda 的 `select#xnd` / `select#xqd`、iframe 课表、花括号周次；也没有 `saveImportedCourses` 之类的拾光桥。

## 6. 上游里删掉 / 改掉的东西及理由

| 上游 | 处理 | 理由 |
|---|---|---|
| `showAlert` 确认框、`showToast` 进度条、`saveImportedCourses` / `savePresetTimeSlots` / `notifyTaskCompletion` | 去掉 | 拾光的桥能力；空课由宿主保存，适配器只交数据 |
| `showSingleSelection` 弹窗选学期（默认当前学期） | 去掉，只取页面默认（当前）学期，提醒里告诉用户去教务系统切换 | 公共说明第 2 条：不弹窗问学期 |
| 七个字段缺一个就 `continue` 整行丢弃（课名 / 教师 / 地点缺一不可） | 课程块只要求课名；教师 / 地点缺元素或元素被隐藏时交空串，由 `parse.js` 转 null 并汇总提醒 | 公共说明第 4 条：不许静默丢课 |
| 只请求课表页默认地址，丢掉当前 URL 里用户选好的 `?xnxq=` | 当前页就是课表页时用它自己的 `pathname + search` 请求；不在课表页才回落默认地址 | 提醒里「先切换学期再提取」必须是走得通的，否则切了学期也导不出那个学期 |
| `parseWeeks` 的 `/第(.+?)周/`（丢掉紧跟的单双标记、多段只认第一段） | 每段「第…周」连同紧跟的单双标记都取出来、用逗号连起来交给 `weeksOf`，周次取并集 | 批次十 / 十八 / 二十八的经验：`(单)/(双)` 丢了会退化成每周都上；只认第一段会丢周次 |
| `defaultIndex` 与学期列表选择 | 只把学期列表交出去做兜底（只有一项时用），不做索引推断 | 不弹窗就没有「默认选中项」的语义 |
| `semesterStartDate` 不存在（上游没有） | 按手册 §4.3 推算并提醒 | `firstDay` 必填，推算值必须说出来 |
| `timeSlots` 无校验直接保存 | 校验 `HH:mm` 与「结束晚于开始」，坏的跳过；一条都没读到就用默认并提醒 | 载荷校验会把坏时间整包拒收 |
| `const` / 箭头函数 / `Array.from` / `new Set` / 模板串 / `for...of` | 全部改成 ES5（用对象当字典） | 旧 WebView 与 Rhino |
| 上游没有任何登录 / 主机判断 | 增加主机判断、登录页判断、返回登录页的判断 | 公共说明第 6 条：登录页上点提取只提示不发请求 |

新增（上游没有）的：缺教师 / 缺地点汇总、跳过行的分类计数、提醒限长、H3 表外节次补齐、隐藏元素过滤、多段周次取并集。

## 9. 已知风险与未验证项（我们没有本校账号，真机没验过）

1. **页面结构全部来自上游脚本，没有在北京交通大学真机验证**：`table.table-bordered`、`td` 直接子 `div`、
   `span[style*='color:#000']` / `i` / `span.text-muted`、`.widget-header button`、`a[href*='xnxq=']` 都照上游；
   若学校改版，会落到「没有找到课表」或跳过行，提醒里会给计数，但不会静默导入错误周次。
2. **课表页地址与同源前提**：请求走站内相对路径（当前课表页的 `pathname + search`），只在 `aa.bjtu.edu.cn` 上工作。`loginUrl` 是翱翔门户
   （`mis.bjtu.edu.cn`，按主调度给的值），用户从门户登录后需要进到教务系统的课表页再点「提取课表」；
   在门户页上点提取会看到「当前页面不是北京交通大学的教学支撑平台」的提示（不发请求）。
3. **开学日是推算的**：教务不给开学日，按「9 月 1 日 / 次年 3 月 2 日所在周的周一」。真实开学日若不同，整学期会整体偏移，
   所以每次导入都有一条提醒让用户去「学期管理」核对。
4. **总周数是假设**：教务不给，按 `max(最晚周次, 20)`；真实学期若是 18 周，课表照常可用，只是「共 N 周」偏大。
5. **节次时间依赖教务页面**：时间逐节取自页面表格；如果某些行没写时间，这些节次会落到 H3 的补齐逻辑并被提醒。
   我们**没有**一份学校公布的写死时间表可对照（拿到真实值时应补成固定表并去掉对页面的依赖）。
6. **学期列表只做兜底**：不弹窗问学期。标题按钮读不到、而列表有多项时按今天的日期推算（并提醒）；这时可能不是用户想要的学期，
   提醒里写了怎么切换。学期列表的 `href` 不交出去（不请求、不切换）。
7. **隐藏元素只认 `hidden` / 内联 / 计算样式**：用透明度 0、移出屏幕等方式藏起来的文字浏览器仍算可见，会被当成内容带出
   （上游同样会带出；这里挡住了最容易藏学号的几种）。
8. **教师字段原样取**：上游不去括号备注（如「张三（外聘）」），这里同样原样，不拆成第二位教师。
9. **`allowHosts` 只有 `aa.bjtu.edu.cn`**：没有声明 `mis.bjtu.edu.cn`（那是门户，脚本不去请求它），也不带通配。
