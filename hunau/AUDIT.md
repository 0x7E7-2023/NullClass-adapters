## 结论

可以进内置库。`extract.js` 只读页面，只向**当前页面同源**的 `/jsxsd/` 下发最多 4 类请求（课表页 GET / POST、教学周历 POST），前缀就是当前页面路径里 `/jsxsd/` 之前那一段（WebVPN 里是 `/https/<十六进制>`）；起手先查主机必须是 `webvpn.hunau.edu.cn`、再查路径，不在 WebVPN 教务系统里、停在 WebVPN 首页 / 统一认证页 / 教务登录页上就直接给大白话提示、**不发任何请求**。不碰凭据、不写页面、不外发。`parse.js` 是纯函数。自检 `RESULT: PASS`（10 对 fixture 全部 MATCH）；浏览器冒烟 25/25 OK（§八）；变异测试 20 处全部变红并已还原（§九）。没有本校账号，真机没验过（§十）。

## 零、模板选择与不同构之处

上游脚本形态（按它**实际请求的路径与解析方式**判，不按注释）：`GET/POST /jsxsd/xskb/xskb_list.do`（课表，DOM 里读 `#timetable` / `#kbtable`）、`POST /jsxsd/jxzl/jxzl_query`（教学周历）、课表行标题 `第N大节 HH:MM-HH:MM` 推节次时间——与 `yssdufe`（教学周历 + `#kbtable` 抓取）、`gzst`（批次十二，`#kbtable` 抓取 + 周次 / 合并 / 提醒限长的新写法）同属强智。

**模板：取 `gzst` 的解析骨架 + `yssdufe` 的取数骨架拼成**：
- `parse.js` 以 `gzst` 为底（批次十二已审计：`weeksOf` 的单双标记归属含「后缀挨着下一段」、`共 N 周` 只剥备注、`第1-第8周`、`periodsOf`、表头补齐、同课两阶段合并、`warn` / `issue` 限长出口、缺教师 / 缺教室汇总、H3 顺推）。`yssdufe` 的 `weeksIn` 比 `gzst` 老（按它的代码推演：`第1-第8周` 会读成只有第 1 周、`1-8周(单)9-16周(双)` 判成「单双同写」），所以不用它的周次层，只借它的**教学周历网格**（`cal` 的列号 / 表头 / 日期格）思路。
- `extract.js` 以 `gzst` / `yssdufe` 的网格还原（`colspan` / `rowspan` → 列号）为底，加上本校特有的：WebVPN 前缀、两份内容分开交（明细 / 简表）、周历、`GET 默认页 → GET 带学期 → POST 表单` 的取数顺序。`gzst` 的路径守卫改成 WebVPN 主机 + `/jsxsd/` 路径判断；`gzst` 的「同源框架」「文字候选里认学期」两块不要（上游没有，见 §五）。
- WebVPN 前缀：参考 `czimt` / `sdipct` 的写法，但本校上游不拼死十六进制前缀、也不补 `vpn-12-o…` 查询片段，而是**取当前页面路径里 `/jsxsd/` 之前那段**当前缀，所以我们照上游，不写死任何十六进制串（也就不用 `allowHosts`）。

与模板的不同构：
1. **一格里有两份内容**（明细 `kbcontent`、简表 `kbcontent1`）：上游两份都读，按「课名 + 周次 + 教室」择优，教室写法不同就会留下两份重复课。本件分开交（`parts` / `briefParts`），parse 里优先用明细，简表里「课名和周次都与同格某个明细块相同」的整块丢掉，简表独有的块照常导入（教师留空并提醒）。
2. **节次时间来自课表行标题**（`第一大节 08:00-09:40`），不是写死表一统：解析成每大节 2 个小节，页面给的不足 6 节或前后对不上时才回落上游写死的 12 节；§四有逐节表。
3. **开学日来自教学周历**（`POST jxzl_query`，第 1 周那一行的日期格），不是 `gzst` 那样一律推算。
4. **教师姓名后连写职称**（「何龙姣讲师」「周小红其他」）：上游逐人去掉常见职称后缀，照搬。
5. **只支持 WebVPN**，前缀从当前路径取；只有当前页就是本人学期课表页（`/jsxsd/xskb/` 下）时才用屏幕上的课表和学期下拉框，班级 / 教室 / 教师课表等其它 `/jsxsd/` 页面一律去取本人的 `xskb_list.do`（那些页面上也有课表表格和 `xnxq01id` 下拉框，不能当成本人课表）。

## 一、上游实际做了什么（对照 `hunau_01.js` 全文，554 行）

1. 若当前路径里没有 `/jsxsd/` → 弹「请先进入教务系统」，结束。
2. `GET <前缀>/jsxsd/xskb/xskb_list.do`（无参数）→ 读 `select[name="xnxq01id"], select#xnxq01id` 的全部选项，学期超过 1 个就弹单选框让用户选（默认项是带 `selected` 属性的最后一项，没有就第 1 项）。
3. 选定学期后 `GET …?xnxq01id=<学期>`，返回里没有 `#timetable` / `#kbtable` 才 `POST` 体 `xnxq01id=<学期>&sfFD=1`（`Content-Type: application/x-www-form-urlencoded`）。
4. 解析课表：`th` 标题 `第N大节 HH:MM-HH:MM` → 每大节 2 小节的节次时间（按时长反推小节数，取不到或不足 6 节就用写死的 12 节）；每个 `td` 里 `div.kbcontent, div.kbcontent1` 逐块解析：课名取第一个含中文的文本节点，`font[title*=周次|节次]` / `[title*=教师|老师]` / `[title*=教室|地点]` 取字段，`------` 分隔一格里的多门课；周次的单双按**整段文字里出现「单」或「双」**一刀切；缺教师写「未知教师」，缺教室写「未知地点」，周次为空的块静默丢；同课按名称 + 周次 + 教室在格内择优；最后做标准的相邻节次合并 / 周次并集。
5. `POST <前缀>/jsxsd/jxzl/jxzl_query`（体 `xnxq01id=<学期>`）→ 取页面第一张 `table`，首列数字 = 周次，第 1 周那一行的第二格（`title`，形如 `2026年08月31`）= 开学日；总周数取 `max(20, 课表最晚周次)`（周历里的最大周号算出来但没有用）。
6. 通过 `shiguangBridge` 弹框 / toast / `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / `notifyTaskCompletion`。**没有**登录页判断、没有读凭据、没有外发、没有第三方域。

## 二、请求清单（与 `extract.js` 逐条对应）

全部是页面同源的相对路径：地址 = `window.location.origin` + 前缀 + 路径。前缀 = 当前路径里**第一个** `/jsxsd/`（不区分大小写）之前的部分；`locate()` 只在主机**恰好是** `webvpn.hunau.edu.cn` 时才放行。登录全程由用户在 WebView 里手工完成。

| # | 方法 | 地址（`<前缀>` 见上） | 请求体 | 干什么 | 什么时候发；取不到时 |
|---|---|---|---|---|---|
| 1 | GET | `<前缀>/jsxsd/xskb/xskb_list.do` | 无 | 读「学年学期」下拉框的默认选中项；这一页本身带着课表时直接用，不再多发 | **当前页是本人学期课表页（`/jsxsd/xskb/` 下）且屏幕上已有课表**时不发；**当前页是该课表页且有合法的下拉框选中项**时不发；其余都发（含停在 `/jsxsd/kbcx/` 班级课表、教学周历页等：那些页面上的课表和下拉框一律不用）。非 2xx → 抛「教务系统返回错误（代码 N）」，401 / 403 → 「教务系统拒绝访问（代码 N）」，网络错误 → 「连不上教务系统」，返回登录页 →「登录状态已失效」，找不到下拉框 → 「找不到学年学期下拉框」 |
| 2 | GET | `<前缀>/jsxsd/xskb/xskb_list.do?xnxq01id=<学期>` | 无 | 取该学期课表页 | 屏幕上没有课表、且 #1 返回的页面里也没有课程格子时才发；错误处理同上 |
| 3 | POST | `<前缀>/jsxsd/xskb/xskb_list.do` | `xnxq01id=<学期>&sfFD=1` | 与上游一致：#2 返回里没有课表表格时的退路 | 只在 #2 没有课表表格时发；仍没有表格 → 抛「教务返回的页面里没有课表」；表格有但没有课程 → 抛「教务返回的课表是空的」 |
| 4 | POST | `<前缀>/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期>` | 教学周历，取第 1 周的日期当开学日 | 取到课表之后才发；**任何失败**（非 2xx / 网络错误 / 没有表格）都交空周历，不影响取课表，由 parse 推算开学日并提醒 |

不发请求的情形（都在发任何请求之前，`Promise` reject）：

| 当前页面 | 结果 |
|---|---|
| 主机不是 `webvpn.hunau.edu.cn`（校内直连的教务主机、别校域名、`evilhunau.edu.cn`、`cas.hunau.edu.cn` 等一律算） | 抛「请通过学校 WebVPN（webvpn.hunau.edu.cn）登录教务系统、打开学期理论课表后再点「提取课表」」 |
| 本校域名下，路径里没有 `/jsxsd/`（WebVPN 首页 `/`、`/login?cas_login=true`、统一认证 `/cas/login`…） | 抛「当前还没有进入教务系统（这里是 WebVPN 或统一认证页面）…」 |
| 路径里有 `/jsxsd/`，但紧跟的是空（教务根路径）、含 `login`（`/xk/LoginToXk`、`login2.jsp`）、以 `sso` 开头（`sso.jsp`） | 抛「当前打开的是教务系统的登录页或入口页…」 |
| 页面上有 `#userAccount` / `#userPassword` / `input[type=password]` 且没有课表 | 同上 |

- `manifest.allowHosts` = `[]`：所有请求都与页面同源，页面就在 `loginUrl` 的 WebVPN 主机上，同源规则已放行；校内直连不支持，所以也不需要直连主机名。
- `manifest.scheduleUrlHint` 不写：WebVPN 的教务入口带学校专属加密串，没有联网查不到；`JwManifest` 要求它必须是网址，写文字会被拒收，所以省略（打开时落在 `loginUrl`）。

## 三、读取面（extract.js 读了什么、交出去什么）

- **课表表格**：`#timetable` / `#kbtable`（与上游一致），都没有就找含 `.kbcontent` / `.kbcontent1` 的那张表。
- **每个 td / th 交出**：`col`（按 `colspan` / `rowspan` 还原的网格列号）、`span`（`colspan`）、`parts`（类名**按词**含 `kbcontent` 的 div 的 `innerHTML`，即明细）、`briefParts`（同样含 `kbcontent1`，即简表）、`text`。
  - `text`：有课的格子留空；其余格子（表头、行标签、备注行）只在 `span === 1` 且是「星期x」或「不超过 40 字、带数字或『节』字」的短标签时才交（`keepText`），备注行（跨列）、合并格一律不交文字。parse 用到的只有表头的星期名与行标签（如「第一大节 08:00-09:40」「第一大节(01,02小节)」）。
  - 文字与明细全空的行整行不交。
- **学期**：`select`（id 或 name 含 `xnxq`）里值形如 `2026-2027-1` 的选中项，交出 `{ code, name, source }`；`source`：`select-selected`（正常）/ `select-first`（取回来的页面里没有任何选项带 `selected` 属性，只能取第一项）/ `page-default`（屏幕上有课表却找不到下拉框，学期取教务默认学期）。
- **教学周历**：只交有文字或有 `title` 的格子的 `{col, text(≤20 字), title(≤40 字)}`（日期挂在 `title` 上，如 `2026年08月31`）。
- **`now`**：提取当天的本地日期，只用于周历取不到时推算开学日。
- **不读**：账号、密码（只看登录输入框存不存在）、cookie、localStorage / sessionStorage、学号、姓名；不写页面；课表表格之外的文字（含页头的学生信息）不读；**页面地址、查询串也不交**（查询串里可能带学号）。
- 交出的 JSON 只交给本机的 `parse.js`，不发往任何地址。冒烟（§八）在页面头部与备注行里埋了学号 / 姓名 / 身份证号 / 手机号，交出的数据与所有请求里都没有。

## 四、节次时间（逐节）

**优先用课表行标题里写的时间**（上游同样如此）：标题 `第N大节 HH:MM-HH:MM` 的 N 取阿拉伯数字或中文数字（一…九、十、十一…），按时长反推小节数 `round((时长+10)/55)`，**只采用反推结果正好是 2 的行**（本校课表都按每大节 2 节，格子里没写节次时按「第 N 大节 = 第 2N-1、2N 节」对应，所以反推出别的数的行不采用，否则编号会对不上）；第 2N-1 节 = 大节开始起 45 分钟，第 2N 节 = 到大节结束为止的 45 分钟（等价于上游「小节之间均分课间」在 2 小节时的结果）。

采用条件（与上游「不足 6 节回落写死表」一致）：
- 页面能推出的节次 ≥ 6 节，且与写死表拼成的 1..12 节前后不倒退 → 用页面的；页面没写到的节次（≤ 12）用写死表补，**课表用到了被补的节次时提醒**（`times-partial` 钉住）；
- 页面给的不足 6 节 → 整张用写死表，提醒「课表页没有给出完整的节次时间…」（`times-fallback`）；
- 页面的时间前后对不上 → 整张用写死表，提醒「课表页上写的节次时间前后对不上…」（`times-conflict`）。

**写死的 12 节**（上游 `HUNAU_FALLBACK_TIME_SLOTS`，逐节与 `parse.js` 的 `FALLBACK_TIMES` 一致，按上游注释是「6 个大节、每节 45 分钟、课间 10 分钟推得」）：
1 08:00-08:45；2 08:55-09:40；3 10:05-10:50；4 11:00-11:45；5 14:30-15:15；6 15:25-16:10；7 16:35-17:20；8 17:30-18:15；9 19:30-20:15；10 20:25-21:10；11 21:20-22:05；12 22:15-23:00。

课表用到第 13 节及以后（统一修订 H3）：在上一节下课后按课间 10 分钟、每节 45 分钟顺推（`CLASS_MINUTES` / `BREAK_MINUTES` 即上游 `HUNAU_CLASS_DURATION` / `HUNAU_BREAK_DURATION`）。第 13 节 23:10-23:55 能补；第 14 节起越过 23:59 补不了，课照常导入并提醒（`times-fallback` 钉住）。

## 六、与模板件（`gzst` / `yssdufe`）的差异（逐条）

1. **取数顺序与前缀**：见 §零、§二。`gzst` 只有一条 GET，路径写死；本件按上游的 `GET 默认页 → GET 带学期 → POST 表单` 取数，前缀从当前路径取，只支持 WebVPN。
2. **登录页 / 入口页判断**：`gzst` 靠路径前缀 + 登录输入框；本件靠 WebVPN 主机 + `/jsxsd/` 路径（空 / 含 `login` / 以 `sso` 开头）+ 登录输入框，并把「WebVPN 首页 / 统一认证」与「教务登录页」分成两条不同的提示。
3. **两份内容分开交**：`parts`（明细）与 `briefParts`（简表）；parse 里明细优先、简表按「课名 + 周次」去重（见 §零 1）。
4. **教学周历**：`gzst` 没有；本件取回周历网格，parse 里按表头认「星期一」所在列，在第 1 周那一行取该列的日期（`title` 优先，其次格子文字）；表头认不出时按上游取该行第二格并**一定提醒**；星期一那格写的不是周一就对齐到所在周的周一并提醒。
5. **教师职称后缀**：上游 `cleanTeacher`，照搬（`TEACHER_TITLES` 的清单与顺序同上游）；`gzst` 没有。教室末尾的 `[01-02]节` 同上游去掉。
6. **节次时间**：`gzst` 写死表；本件优先页面标题（§四）。
7. **学期**：`gzst` 可在页面标题 / 各下拉框文字里认学期；本件只认 `xnxq` 下拉框（上游也只认它），认不出就报错、不猜。`gzst` 的同源框架读取不要（上游不读框架，也是靠 fetch）。
8. **总周数**：同上游（默认 20，课表有更晚的周次才抬高并提醒，上限 30）；**没有**用周历里的最大周号（上游也没用）。
9. **提醒措辞**：全部过同一个限长出口 `capLine`（整条 ≤200 字），点名的课名截 20 字（`shortName`）；缺教师 / 缺教室按类型汇总，指向「编辑课程」；统一叫「节次时间」，不出现「作息表」「内置」「适配器」。
10. 其余同模板：周次 / 节次 / 课程名都在 parse 里解；表头只认出一部分星期时按列序补齐并提醒；合并的「周末」格记在每一天并提醒；一门课都解析不出时报错（不返回空课表）。

## 七、对上游的改动（都是为了不静默出错）

1. **周次单双**：上游只要整段文字里出现「双」就把所有周按双周过滤（出现「单」同理），`(单)1-8周,(双)9-16周` 会被整体当成双周；本件单 / 双标记只跟着自己那一段（前缀贴后段、后缀贴前段，含「后缀挨着下一段」）。
2. **周次写法**：上游把括号整组删掉、「第」删掉、`至` / `到` / `~` 当区间符，其余不认；本件在此基础上补了全角数字与全角标点（`～`、`－`、`，`、`、`）、区间两端的空白、空白分段（`1-3周 5-9周` 是两段）；「共 N 周」只剥备注本身，不删到行尾；括号里纯数字是序号（计数提醒），含别的字的括号是备注（计数提醒）。
3. **缺教师 / 缺教室**：上游写「未知教师」「未知地点」；本件写 `null`，按类型汇总提醒（指向「编辑课程」），课照常导入。
4. **读不出的块**：上游周次为空、课名为空、节次没有时静默丢；本件节次先回落到行标签（第 N 大节 = 第 2N-1、2N 节），再不行**计数并点名提醒**；周次读不出、课名为空同样计数提醒。
5. **星期**：上游按「第几个 `td`」硬算；本件按表头「星期一…星期日」的网格列（`colspan` / `rowspan` 还原）对应，表头只认出一部分时按列序补齐并提醒。
6. **简表 / 明细**：见 §零 1。
7. **节次**：上游取方括号里所有数字的首末当起止；本件认 `01-02`、`01,02`、`0102`、`030405`、`03-04-05`，连排必须逐个相差 1，读不成节次的方括号（课名里的 `[实验]`）不当节次；不连续的节次按首尾记并提醒。
8. **开学日**：上游取第 1 周那一行的**第二格**，格子是星期日时开学日就是个星期日（宿主再回退，会差一周）；本件按表头认星期一那一列，认不出才取第二格并对齐到周一（星期日 → 次日），并提醒。周历取不到时上游「可在软件内手动校准」，本件按提取当天所在周的周一推算并提醒到「学期管理」里核对。
9. **超出节次表**：上游无处理；本件按统一修订 H3 顺推并提醒（§四）。
10. **删掉的**：`alertUser` / `toast` / `selectFromList`（弹窗选学期）/ `window.shiguangBridge*` 的全部调用 / `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / `runImportFlow` 流程；`mergeAndDistinctCourses`（上游的展开 / 排序写法含箭头函数与展开运算符，语义保留为 `dropExactDuplicates` / `mergeStageOne` / `mergeStageTwo`）；`config.semesterTotalWeeks` 等配置对象（变成 `DEFAULT_TOTAL_WEEKS`）。**不弹窗问学期**：取页面上下拉框的选中项（用户在课表页切到哪一学期就导入哪一学期）。

## 八、fixtures（10 对）、桩跑与浏览器冒烟

全部合成数据，期望值先按规范与代码口径手工推演（节次时间、节次、周次切段、单双周、开学日、总周数、学期名、warnings 文本）再与自检比对；不是 parse.js 的输出存档。

1. `basic`：页面节次时间（第二大节写成 10:10-11:50）；明细 + 简表并存只留明细（简表教室写法不同也不重复）；职称后缀逐人去掉；教室末尾 `[05-06]节` 去掉；一格两门课；单 / 双周；同课相邻两大节合成 1-4 节；只有简表的格子取行标签（第四大节 = 第 7-8 节）并提醒教师留空；周历表头「日一二…」，开学日取星期一那一列。
2. `times-fallback`：行标签没有时间 → 整张用写死的 12 节并提醒；`[13-14节]` → 第 13 节 23:10-23:55 顺推、第 14 节补不了并提醒；格内没写节次取行标签括号里的小节号；周历取不到 → 开学日推算并提醒。
3. `weeks-forms`：13 种周次写法（含 `(单)1-8周,(双)9-16周`、`1-8周(单) 9-16周(双)`、`1-8周(单)9-16周(双)`、`第1-第8周`、`1-8周(共8周),9-16周`、`1-16周(1)`、`1-16周 双`…）；周历表头「星期一…」、首列「第1周」、日期 `yyyy-MM-dd` 写在 `title`。
4. `calendar-nohead`：周历没有星期表头，第一个日期格是星期日 → 取该行第二格并顺延到周一，提醒。
5. `calendar-offday`：星期一那格写的不是星期一（日期只写在格子文字里）→ 对齐到所在周的周一，提醒。
6. `partial-header`：表头只认出 5 天 + 跨周六周日的合并格 + 学期下拉框没标选中项（取第一项）+ 周历取不到。
7. `long-warnings`：5 门 25 字左右的长课名，缺教师 / 缺教室合并成一条（点名截 20 字）、周次「待定」认不出、29-34 周截到 30 周并抬高总周数、`[2026节]` 读不出节次，每条 ≤200 字。
8. `times-partial`：页面时间只写了一部分（第五大节按时长是 3 小节不采用、第六大节没写）→ 第 9-12 节用写死表补，课表用到第 9-10 节，提醒这两节是补的。
9. `times-conflict`：第二大节写成 09:00-10:40（比第一大节结束还早）→ 整张改用写死表并提醒。
10. `brief-detail`：简表独有的块（另一段周次、另一间教室）照常导入且教师留空；整格只有简表的两门课（破折号分隔）；周次与节次分写在两个 `font` 里；课名里的 `[实验]` 不当节次；页面上找不到学年学期下拉框（`page-default`）；三门课缺教师合并成一条提醒。

**本校专属边界用例**覆盖情况：节次时间取页面 / 回落（1、2、8、9）；教学周历三种取法（1、4、5）；简表 / 明细（1、10）；教师职称后缀（1）；单双标记归属与「共 N 周」（3）；长课名与提醒限长（7）。

## 十、风险与没能确定的事

1. **真实页面未验证**：没有本校账号，表格形状（`#timetable` / `#kbtable`、`kbcontent` / `kbcontent1` 两份、`font[title=…]`、表头文字、行标题「第N大节 HH:MM-HH:MM」、周历 `td[title]`）照上游代码与同平台写法推断。行标题里时间与「(01,02小节)」是否连在一起不影响读取（都认）。
2. **只支持 WebVPN**：上游的校内直连形态（教务主机名上游也没写）不支持，主机不是 `webvpn.hunau.edu.cn` 一律提示。若学校的 WebVPN 把教务映射成别的子域名而不是路径前缀（`/https/<十六进制>`），会被主机检查挡下，需要更新适配器。
3. **WebVPN 是否需要 `vpn-12-o…` 查询片段**：`czimt` / `sdipct` 的上游把这个片段写在请求地址里，本校上游没有，我们照上游不加。若真机上 WebVPN 对不带片段的同源请求返回登录页，会报「登录状态已失效」，需要补。
4. **开学日**：周历里第 1 周的日期格不是星期一时已对齐并提醒；周历取不到时按提取当天推算并提醒，学期中途导入会差几周，要用户在学期管理里核对。周历表头若不是「日一二…」/「星期一…」也不是单字，会走「取第二格」的备选口径并提醒。
5. **学期**：只认页面（或取回的默认页）上 `xnxq` 下拉框的选中项；要导别的学期，先在课表页切过去再提取。屏幕上的表格与下拉框可能不一致（用户只改了下拉框没点查询），上游同样不处理。
6. **教师职称后缀**：照上游清单去掉（含「其他」「教授」「讲师」…）；姓名恰好以这些字结尾的教师会被多去一截，上游同样如此，只在名字长度大于后缀长度时才去。
7. **登录页判断**：强智的登录页就在系统根路径上，已登录的用户如果恰好停在根路径，会被提示「登录页或入口页」（换到课表页再点提取），属于宁可多拦。
8. **节次时间**：页面给的优先；写死表是上游「推得」的值，课表页本身是否给出标题时间无法核实；第 11、12 节（21:20-23:00）的真实性同样没法核实。
9. **框架页**：外壳页（`xsMain.jsp`）里课表在框架中，`extract.js` 不读框架，靠 `fetch` 取默认页（与上游一致）。
