审计对象：`jw-adapters/jyvtc/` 下的 `extract.js` / `parse.js` / `manifest.json`，以及它们移植自的上游脚本
`shiguang_warehouse` 的 `resources/JYVTC/jyvtc.js`（快照 commit `19a65bf07a3e998fcfc69cee692387cdc0523c1a`，2026-10-19 拉取；
本校脚本最后一次修改 `80e30cf`，`git log -1 -- resources/JYVTC/jyvtc.js` 实测一致；MIT，作者 `星河欲转`）。
上游同目录 `adapters.yaml` 只有一个条目 `JYVTC_01`，`import_url` 为 `https://jwgl.jyvtc.edu.cn/jyvtcjw/`（原样作为 manifest 的 `loginUrl`），
描述写着「非本校开发者适配如果有误建议提交 issue」「添加双季作息」。

审计方式：逐行读上游脚本与移植件；`check.js` 自检（8 对 fixture 用 Rhino 1.8.0 实跑、载荷校验、ES5 与控制字节扫描、`allowHosts` 检查）；
`extract.js` 用 Playwright 起假教务站在 Chromium 里实跑 14 个场景（`.test/port-batch13/jyvtc/smoke.py`，不联网，记录实际请求地址 / 请求体 / 请求头，再把输出交给 Rhino 跑 `parse.js`）；
变异测试 10 处，见第 9 节。扫描结果：

- 绝对 URL：`extract.js` 与 `parse.js` 的文件头各有一处上游仓库地址（注释，不是请求）。`extract.js` 的请求地址由 `window.location.origin` + `/jyvtcjw` 拼出，
  代码里写死的只有教务主机名 `jwgl.jyvtc.edu.cn`（用来判断「当前页面是不是教务主机」，不是请求目标）。
- 网络调用：只有 `extract.js` 里 `post()` 中的一处 `fetch`。`parse.js` 没有任何网络调用。

- 上游 `showAlert` / `showPrompt` / `showSingleSelection` / `showToast` / `saveImportedCourses` / `savePresetTimeSlots` / `notifyTaskCompletion` 等宿主桥调用：移植件不调用任何桥（保存由宿主根据载荷完成）。

## 1. 复制模板与取舍

任务卡给的候选模板 `taru` / `xawl` 是**正方 jwglxt**（POST 返回 JSON 的 `kbList`），而本校上游是**青果**：POST `/jyvtcjw/frame/desk/showLessonScheduleDetail.action`，
返回的是网页片段，课表是 `<tr class="mykb">` 表格行，一行 = 一节，一格里用 `<ul>…<br>…</ul>` 叠着好几门课。两者除了「同一位上游作者」以外**取数层与解析层都不同构**，
`jw-adapters/` 里也没有同款青果件（`masu` 是树维、`xzhmu` 是真 `<table>` 的另一种写法），所以没有复制任何一个目录：
`extract.js` 照上游重写；`parse.js` 取批次十 `swu` 与批次九 `zwu` 里已审计过的部件（周次解析 `weeksOf`、H3 补节次、合并两阶段、缺教师 / 缺教室汇总、提醒限长），
把数据入口换成「表格行 -> 课程」，再补上本校特有的逻辑（第 3 节）。`taru` / `xawl` 的周次解析较旧（没有 `(单)` 前缀归属与「第」处理），所以没有选作周次模板。

## 2. 请求清单（与代码逐条对应）

| 谁 | 方法 | 地址 | 干什么 | 取不到时 |
|---|---|---|---|---|
| `extract.js` `fetchTerm`（经 `post`） | POST | `<base>/frame/desk/showLessonScheduleDetail.action`，体 `weeks=&xnxq=<年份>-<0 或 1>`，请求头只有 `Content-Type: application/x-www-form-urlencoded; charset=UTF-8` | 取课表网页片段（与上游 `fetchAndParseCourses` 逐字一致：同路径、同体、同头） | 状态码非 2xx 抛「教务系统返回错误（代码 N）」；连不上抛「连不上教务系统」；没有任何课程内容且被送回登录页抛「登录状态已失效」 |

`<base>` = 当前页面的 `origin` + 当前路径里 `/jyvtcjw` 之前的前缀 + `/jyvtcjw`（`jwBase()`）：
- 路径里有 `/jyvtcjw/`（或恰好是 `/jyvtcjw`）：取到它为止，前面的反向代理前缀（如 `/http/<token>`）原样保留（冒烟场景 `proxy-prefix` 实测）；
- 路径里没有但主机是 `jwgl.jyvtc.edu.cn`（例如停在站点根 `/`）：补 `/jyvtcjw`（场景 `root`）；
- 其它主机（门户、统一认证）返回 `null`，直接抛「请先登录济源职业技术学院的教务系统……」，**不发请求**（场景 `portal`）；
- 路径含 `/cas/login`（上游 `isLoginPage` 判的就是 `/jyvtcjw/cas/login.action`）：抛「当前打开的是登录页……」，不发请求（场景 `login-page`）。

`manifest.json`：`loginUrl` 为 `https://jwgl.jyvtc.edu.cn/jyvtcjw/`（上游 `import_url` 原样），`allowHosts` 为 `[]`（所有请求都与 `loginUrl` 同源）。
**没有写 `scheduleUrlHint`**：上游没有给课表页地址，请求本身从教务主机上任何已登录页面都能发（只要同源），我们不凭空编一个没验证过的页面地址；缺省时宿主从 `loginUrl` 打开。

与上游的差别（都不牵涉安全）：
- 上游弹窗问「学年（四位数字）」和「学期（第一 / 第二）」再拼 `xnxq`；移植件先在当前页面（含同源内嵌框架）里找名叫 `xnxq` 的下拉框 / 输入框，值必须形如 `2026-0` 才认；
  找不到按今天的日期判断（8 月到次年 1 月 = 第一学期，2 月到 7 月 = 第二学期），并在载荷里标 `source = guess`，`parse.js` 据此在提醒里如实说明。只请求这一次，学期没有课时不改取别的学期。
- 「有没有课」按课表行里有没有课程内容（任一格有列表文字）判断，不看 `mykb` 行是否存在；整学期没有任何课程内容时 `parse.js` 报「这个学期（…）在教务系统里还没有课；如果要导入别的学期，请在教务页面里切换学期后再点「提取课表」」。
- 请求头**没有**加 `X-Requested-With` / `Accept`（其它正方件有）：上游没有加，青果这类服务端有可能因此改变返回格式，宁可与上游一致（冒烟脚本断言了这一点）。
- `parse.js` 不发任何请求。

## 3. 与上游 / 不同构之处（本件的分析）

1. **行即一节**：每个 `mykb` 行是一节课，节次来自行里第一个「开头文字含数字」的单元格（上游 `row.match(/<td[^>]*?>[^<]*?(\d+)…/)`，`extract.js` 把每个单元格的开头文字交出来，`sectionOfRow()` 照同一规则取）。
   星期来自单元格的位置：上游只数**带属性**的 `<td …>`（`/<td\s+[^>]*?>…<\/td>/g`），共 9 个取第 3-9 个、共 8 个取第 2-8 个，其它个数整行跳过。
   移植件交出每格的 `a`（是否带属性）并在 `parse.js` 里数同样的个数；其它个数的行（且行里有课程内容）计数写进 warnings，不再静默。
2. **一格里的一门课**：`课名 教师 (周次 教室)`。上游正则 `(.+?)\s+([^\s(]+)\s*\(([^()]+)\)` 要求三者齐全，再用**最后一个空格**把括号内容切成「周次」与「教室」，缺任何一项就整条丢掉。
   移植件：取**最后一个以周次开头的括号**（括号里再套括号也算在内），括号前面最后一个空白分隔的词是教师（没有空白就没有教师，课名里带空格的如 `Python 程序设计 钱八` 仍把最后一个词当教师——与上游一致）；
   括号内容按「开头若干个像周次的词 = 周次，其余 = 教室」切开，教室里带空格也能保住（上游会把教室截成最后一个词）。
3. **周次**：上游 `parseWeeks` 只认 `1-16`、`1,3,5` 与整串里的 `单周` / `双周`；写了「周」字（`1-16周`）会塌成空数组（`Number('16周')` 是 `NaN`，课被静默地丢周次）。
   移植件沿用 `swu` 的 `weeksOf`（认「周」字、`第1-第8周`、全角、`~` / `至`、`共N周` 备注、教学班序号括号，`(单)` / `(双)` 按位置归属），
   并保留上游口径：整串里恰好出现**一个不在括号里的**「单周」或「双周」（且没有别的单 / 双字）时，对整串里每个**区间**生效、单独的一周如 `10` 不受影响（`weeksOfCell()`）。
4. **节次时间**：上游写死两套（非夏季 / 夏季），弹窗让用户选一套再 `savePresetTimeSlots`。逐节照抄如下（`parse.js` 的 `NON_SUMMER_PERIOD_TIMES` / `SUMMER_PERIOD_TIMES`，已用脚本与上游逐节比对一致）：

   | 节 | 非夏季 | 夏季 |
   |---|---|---|
   | 1 | 08:00-08:45 | 08:00-08:45 |
   | 2 | 08:55-09:40 | 08:55-09:40 |
   | 3 | 10:10-10:55 | 10:10-10:55 |
   | 4 | 11:05-11:50 | 11:05-11:50 |
   | 5 | 14:30-15:15 | 15:00-15:45 |
   | 6 | 15:25-16:10 | 15:55-16:40 |
   | 7 | 16:30-17:14 | 17:00-17:44 |
   | 8 | 17:15-18:00 | 17:45-18:30 |
   | 9 | 19:30-20:14 | 19:30-20:14 |
   | 10 | 20:15-21:00 | 20:15-21:00 |

   上游**没有写**什么时候换季。移植件按导入当天的月份选一套：5-9 月夏季，其余非夏季，今天读不到按非夏季（上游取消选择时的默认值也是非夏季）。
   这个换季月份是**我们的约定**（常见的夏季作息起止），提醒里明说「夏季按 5-9 月估计，具体换季日期以学校通知为准」，并把另一套里不同的几节逐节写出来、指向「学期管理」改节次时间。
   课表用到第 11 节及以后（学校节次时间只有 10 节）时按统一修订 H3 逐节补：空课默认 12 节表里同号节次的开始不早于上一节下课就用它，否则按课间 5 分钟、每节 45 分钟顺推，越过 23:59 就停（课程照常导入），补了哪些、哪些补不了都写进提醒。
5. **开学日 / 总周数 / 学期名**：课表页不给。开学日按学期推算（第一学期 = 9 月 1 日所在周的周一，第二学期 = 2 月 20 日所在周的周一，手册 §4.3 要求回退到周一），总周数取 20 周与课表最大周次中较大者（最多 30），
   两条都写进 warnings；学期名由 `xnxq` 推出（`2026-0` -> `2026-2027学年第一学期`），读不出时用「济源职业技术学院 当前学期」。
6. **合并**：上游排序后只做「连续节次合并」（同课名 / 教师 / 教室 / 周次、节次首尾相接）。移植件前面多一步「完全相同的行只留一条」、后面多一步「同课同节次周次取并集」（只是把相同安排拼成更少的上课安排，不改任何一周），其余同上游。
7. **上游的静默丢课**：缺教师、缺教室、括号里没周次、周次全认不出、排版认不出的行，上游一律不吭声丢掉；移植件缺教师 / 缺教室照常导入（`null`），其余各自计数并点名写进 warnings。

## 4. 读了什么、交出什么（数据面）

`extract.js` 对课表响应只做一件事：找出 `<tr>` 的 `class` 里有 `mykb` 这个词的行（`rowsOf()`，「哪些是课表行」只在这一处定义，`parse.js` 不再重复判断），
对每行的每个 `<td>` 交出：

| 键 | 内容 | 用途 |
|---|---|---|
| `a` | 这个 `<td>` 有没有属性（1 / 0） | 数「带属性的单元格」个数（9 个 / 8 个），决定星期列的位置 |
| `lead` | `<td>` 里第一个标签之前的文字（去空白，最多 40 字） | 读本行的节次号 |
| `ul` | 格内**第一个** `<ul>` 的纯文字（换行标签 / 列表项结尾 -> 换行，其它标签去掉，HTML 实体解码），一行一门课；没有就不带这个键 | 拆成课程 |

另外交出 `term`（`xnxq`、`source` = `page` 或 `guess`）和 `today`（手机本地日期 `yyyy-MM-dd`，只用来选夏季 / 非夏季节次时间）。

**不带出**：响应里 `mykb` 行以外的任何内容（表头、页眉里的学生姓名 / 学号等）、`<td>` 的属性（`onclick`、`id` 等可能带的内部编号）、脚本。
冒烟脚本的假响应里把「学生某 / 学号 2026000001 / 身份证号 / 手机号」放在页眉、非课表行、课表单元格的 `onclick` 属性里，交出的 JSON 里一个都搜不到（有输出的 9 个场景逐个断言）。
教师姓名属于课表内容，随课程原样交出（课表本来就要显示）。

## 10. 已知风险与未验证项

- **没有本校账号，真机没验过；也没有任何一份真实的课表响应样本。** 表格行的结构（`tr.mykb`、带属性的 `<td>`、9 / 8 个单元格、`<ul>…<br>…</ul>`、`课名 教师 (周次 教室)`）
  全部来自上游正则与上游注释的反推；响应里如果还有别的写法（例如 `<li>`、嵌套表格、同一格没有 `<ul>`），移植件会按「读不出的内容」计数提醒，不会静默，但课读不进来。
- **周次写法没有见过真实样本**：上游的 `parseWeeks` 不认「周」字，说明真实数据里周次大概率是 `1-16` 这种纯数字，但 `1-16周` 也已能认；整串「单周 / 双周」的口径按上游实现，真实数据里如果是「每段各带各的标记」会由位置归属规则处理。
- **`xnxq` 控件名是猜的**：上游请求体里的字段叫 `xnxq`，页面上的控件多半同名，但没有验证；找不到就按日期判断并提醒（`source = guess`）。学期编号 `0` / `1` = 第一 / 第二学期是上游注释写的。
- **换季月份是约定**：上游没写，5-9 月夏季是我们的假设，提醒里已如实说明；学期中途换季导入的节次时间可能与实际不符，要学生自己在「学期管理」里改。上游会把两套都存进应用，本件只能导入一张。
- **开学日、总周数是推算的**：课表页不给，提醒里已写；9 月 1 日 / 2 月 20 日所在周的周一不一定与学校相符。
- **教师识别是启发式的**：括号前最后一个空白分隔的词当教师（与上游一致）；课名带空格且没有教师的课（`Python 程序设计 (1-16 机房2)`）会把「程序设计」当教师。
- **只数带属性的 `<td>`**：照上游；如果真实页面的单元格都没有属性，所有行都会被报「排版和预期不一样」。
- 按日期判断的学期可能不是学生想要的（例如假期里新学期还没排课）：只请求一次，没有课就报「还没有课」，提醒里已写明学期是推算的。
- 反向代理 / WebVPN 前缀只验证了 `/http/<token>/jyvtcjw/…` 这种形状；学校的 WebVPN 主机名不在 `allowHosts` 里，经它打开时宿主可能拦截请求，未验证。
