## 本校与模板不同的地方（分析）

1. 节次时间是上游写死的 12 节，不是模板的 11 节。逐节照 `saveAppTimeSlots()` 抄，见下表。
2. 上游节次只认行首 `第N，M节`（中英文逗号），周次文字里不一定带方括号。周次串里有方括号时仍优先用方括号（同一格两门课可以不同节次）；没有方括号才用行首标签（`periodsFromLabel` / `periodsOfRow`）。
3. 周次是文字，不是位串。上游 `parseWeeks()` 在第一个左括号处切开，单双标记会丢。无逗号前置 `(单)1-8周(双)9-16周` 必须读成 1-8 单周、9-16 双周；后置 `1-8周(单),10-16周(双)` 与无逗号后置 `1-8周(单)9-16周(双)` 也要各跟各的。另接「共 N 周」只剥备注、「第1-第8周」按一段。
4. 上游周历最大周号不足 8 就当没读到，改用 20。保留这一条，并写进提醒。
5. 上游弹窗选学期（当前项前后各约 3 个）。改为读下拉框选中项，不弹窗。
6. 登录页、认证页、门户页不发请求。

## 请求清单

只在通过登录页判断之后发请求。取不到时的做法与代码一致。

| 方法 | 地址 | 请求体 | 干什么 | 取不到时 |
|---|---|---|---|---|
| GET | `/jsxsd/jxzl/jxzl_query` | 无 | 读「学年学期」下拉框的选中项（`readTerm`） | 当作没有学期代码；屏幕上已有课表则用屏幕上的学期，否则报「找不到学年学期」 |
| POST | `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期代码>` | 教学周历：开学日、周号（`fetchCalendar`） | 返回空周历，不抛错。开学日按提取日推算，总周数按 20，都写进提醒 |
| POST | `/jsxsd/xskb/xskb_list.do` | `jx0404id=&cj0701id=&zc=&demo=&xnxq01id=<学期代码>` | 当前页没有课表格子时才请求课表（`scheduleBody`） | 格子为空则报「课表是空的」；网络失败报「连不上教务系统」或「教务系统返回错误（代码 N）」 |

登录页判断（`loginHint`，在任何 `fetch` 之前）：路径是 `/jsxsd/`、`/jsxsd/index`、`/jsxsd/login`、`/jsxsd/xk/LoginToXk`，或主机不是 `jwgln.zsc.edu.cn`，直接提示，不发请求。

## 读了什么、交出去什么

读取面只有这些：

- 地址的协议、主机、路径（不要查询串）。
- `select` 里 id 或 name 含 `xnxq` 的选中项：学期代码与显示文字。
- 课表 `#kbtable`（没有这个 id 时，退到最近一张含 `kbcontent` 的表）：每个格子的网格列号、跨列数、可见文字、类名正好是 `kbcontent` 的 div 的原始 HTML。不读 `kbcontent1`。
- 周历表：格子的列号、文字、`td` 的 title（日期）。

不读学号、姓名、身份证号、手机号、隐藏令牌。页面上即使有这些，也不放进交出去的对象。

`extract.js` 交出去的字段：`source`、`pageUrl`、`now`、`term.code`、`term.name`、`screenTermMissing`、`cols`、`calendar`、`rows`（格子只有 `col` / `span` / `text` / `parts`）。

`parse.js` 交出去的载荷：学期名、开学日、总周数、12 节（或补上的）节次时间、课程的课名 / 教师 / 地点 / 星期 / 节次 / 周次段。教师、地点没有就是空，不写「未知」。

## 上游里删掉或改掉的

| 上游 | 本件 | 理由 |
|---|---|---|
| `showAlert` / `showSingleSelection` 选学期 | 读下拉框选中项 | 移植约定不弹窗问学年学期 |
| `saveCourseConfig` / `savePresetTimeSlots` / `saveImportedCourses` / toast / `notifyTaskCompletion` | 删除 | 空课自己组载荷，脚本只读 |
| `parseWeeks` 在左括号处截断 | `weeksIn` 按段判断单双 | 否则单双周变成每周都上 |
| `mergeAndDistinctCourses` 按课名排序再合并相邻节次 | 只按安排去重 | 排序合并会把不该连堂的课并在一起；同一节的重复行由去重吃掉，不会叠成两门 |

| 周历不足 8 周写成空 | 保留，并提醒已按 20 周计 | 与上游同一口径，但不能一声不吭 |
| 教师空着就空串 | 空值，并按课汇总提醒 | 「未知教师」会被当成真名；缺了也不能静默 |

## 已知风险

- 没有本校账号，真页面没验过。行首标签若写成「第一大节（01,02 小节）」这种，行首补节次认不出，要靠周次串里的方括号。
- 占位节次从第 13 节的 20:00 起，和晚上第 10–12 节的真实时间可能重叠，只靠提醒说明。
- 周历第 1 周没有「星期一」格时，会用第一个带日期的格子对齐到周一，或按提取当天推算，两种都会提醒。
- 上游会把连续节次合并成一条；本件不合并，同一门课占两行会是两条安排，不会丢课。
